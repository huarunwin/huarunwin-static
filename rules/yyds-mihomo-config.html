关于 YYDS Mihomo 配置

YYDS 提供 Pro、Lite、Mini 三档 Mihomo 配置模板，帮助你从一份预设结构开始接入自己的订阅或节点。模板会组织策略、规则和其他设置，但不会附送连接服务。

使用边界

只跟踪 mihomo/config/cn 与 en 下的新版模板；legacy 配置、OpenClash 旧覆写和 JS 辅助工具不在此快照范围。README 的 v2 是模板结构说明，不是 GitHub 正式 Release。外部 666OS/rules 是另一个规则仓库，其更新不等于模板更新。原文另有非商业、研究用途、传播与删除期限声明。仓库提供手动清理历史工作流；若重写历史，自动采集保留旧数据并要求重新核验。 图标为 GitHub 仓库所有者头像。

选用与接入指南

适合什么情况

使用 Mihomo 或相应 OpenClash 环境，希望在不同复杂度模板之间选择；愿意阅读模板注释并按自己的订阅修改。

文件怎么选

  • mihomo/config/cn 与 en：分别是中英文新版模板目录；选择同一档次时，先按自己能读懂的注释语言选择。
  • Pro、Lite、Mini 模板：Pro 提供完整策略、测速和负载均衡；Lite 保留常用策略和自动测速；Mini 采用基础分流和手动选节点。legacy 旧配置及其他 JS 工具不在此快照范围。

接入步骤

  1. 备份原配置，阅读 mihomo/config 的 README，按内核版本和所需复杂度选模板。
  2. 根据模板注释填入自己的订阅或节点，核对策略组名和远程规则引用。
  3. 加载配置后先检查核心启动及规则下载，再按自己的需求调整 DNS、策略和可选功能。

怎样确认生效

确认模板中的节点来源已替换为自己的有效来源，各策略组有可选出口，再观察国内外请求命中。模板引用的外部规则仓库也可能独立更新。

常见误区

Pro、Lite、Mini 不是代理服务套餐，README 的 v2 也不是正式软件版本。OpenClash 或旧模板的经验不能直接替代当前新版模板说明。
