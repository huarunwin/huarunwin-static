关于 DustinWin Ruleset & Geodata

DustinWin 按自己的分类方案构建 Mihomo 和 sing-box 使用的数据库与规则集。你可以选整本分类数据库，也可以只加载少量规则类别；两种接入方式需要分别配置。

使用边界

分别跟踪 mihomo-geodata、mihomo-ruleset、sing-box-ruleset 与 compatible 分支；不同 sing-box 版本需选对应格式。它是基于上游数据的定制构建，保留上游许可。 图标为 GitHub 仓库所有者头像。

选用与接入指南

适合什么情况

已有 Mihomo 或 sing-box 配置，希望采用项目定制的分类；需要按客户端版本选择新格式或兼容格式，而不是下载一份文件到处使用。

文件怎么选

  • mihomo-geodata 与 mihomo-ruleset：前者提供 DAT 等数据库，后者提供 MRS 或 list 规则。MRS 和文本规则需要不同的 format 声明。
  • sing-box-ruleset 与 sing-box-ruleset-compatible：提供 sing-box 规则集及兼容渠道；先查看内核版本要求，再决定使用哪一分支。

接入步骤

  1. 确认客户端真实内核版本，并选择 geodata 或按类别加载规则集的方案。
  2. 从对应分支选文件，依 README 设置数据库地址或远程 rule-set/provider。
  3. 在路由段引用所选类别并指定自己的出口，重新加载配置，保留原文件方便回退。

怎样确认生效

分别检查已用分支的资源更新状态、规则格式和实际命中。页面中的四个分支快照独立记录，应查看自己正在使用的那一份。

常见误区

同名类别在不同数据源中的范围可能不同。切换数据库前要核对现有引用，不能把 MRS 当 SRS，也不能忽略 compatible 渠道对应的版本条件。
