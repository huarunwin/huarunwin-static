使用边界

许可来自 README 的 MIT 声明，仓库未另附独立 LICENSE。第三方依赖域名包括共享服务，部分规则范围超出 Claude；导入前需核对原文的可选项。不是 Anthropic 官方项目，也不提供账号、代理节点或地区访问保证。 本次发现 Clash 示例使用 classical 声明而 YAML 中为裸域名/IP，格式不一致，因此不登记 Clash/Mihomo 适配；sing-box 产物也暂不纳入此次核验范围。 图标为 GitHub 仓库所有者头像。

选用与接入指南

适合什么情况

使用 Surge、Surfboard、Loon 或 Quantumult X，希望为 Claude 单独指定出口，并检查访问过程中依赖的其他域名。

文件怎么选

  • dist/anthropic.list：本条目收录的 Surge / Surfboard 入口，按 README 的 RULE-SET 示例引用并替换策略组。
  • dist/anthropic-loon.conf、anthropic-qx.conf：分别面向 Loon 与 Quantumult X，按各自的远程规则语法使用，不能互换。

接入步骤

  1. 确认客户端处于本页已核验范围，先查看 README 对必选和可选域名的解释。
  2. 将对应格式接入远程规则，并把示例代理名称改成你自己可用的策略组。
  3. 将 Claude 专项规则放在可能先匹配它的通用规则之前，再检查网页或 API 实际使用的出口。

怎样确认生效

对一次失败请求查看命中规则、出口和服务返回；网页、API 与更新请求可能是不同域名。规则命中只能证明路由选择，不能证明账号或地区条件已满足。

常见误区

部分依赖是共享服务，扩大匹配范围会影响其他网站。本页暂不登记 Clash/Mihomo 和 sing-box 适配，不能因为仓库存在同名产物就视为已核验可用。
