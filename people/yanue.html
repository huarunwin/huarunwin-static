macOS 菜单栏的优雅常青树：V2rayU 的 Swift 原生拓荒与八年坚守

以原生 Swift 与状态栏极简哲学打破 Mac 工具荒漠，八载春秋筑牢苹果生态自由网络基石

第一幕 · 时代荒漠：Mac 用户的尴尬困境

2018 年秋，Project V / V2Ray 协议已日趋成熟，在翻墙技术生态中展现出超越传统 Shadowsocks 的强大混淆与路由能力。在 Windows 平台上，2dust 打造的 v2rayN 迅速风靡全国；然而在 macOS 生态中，广大苹果电脑用户却长期陷于“工具荒漠”的窘境。

当时的 Mac 用户若想连接 V2Ray，要么只能在终端命令行中手动编写生涩的 JSON 配置文件并配合 shell 脚本启停，要么忍受跨平台封装工具带来的高昂内存开销与充满违和感的操作界面。

苹果平台急切需要一款完全符合 Apple 人机交互指南、轻巧优雅地驻留在状态栏的纯原生图形客户端。[1][2]

第二幕 · 原生拓荒：Swift 与状态栏极简主义

面对这一生态缺口，开发者 yanue 毅然决定以最纯粹的苹果原生方式解决问题。2018 年 10 月 9 日，他在 Xcode 中敲下了最初的代码，创建了 V2rayU。

与当时许多习惯常驻 Dock 栏且频繁弹出主窗口的软件不同，yanue 崇尚“不打扰”的极简哲学：软件没有冗杂的多余窗口，仅在系统菜单栏常驻一个精巧图标。右键呼出清晰的功能菜单，用户便能一键切换节点、开启 PAC 智能分流或直接扫描屏幕上的节点二维码。

在立项初期的社区议题区，面对热心用户的运行环境询问，yanue 留下了极为谦逊而坦诚的极客留言：

「你好，osx10.12 没环境测试，但应该是支持的，最低支持的就是 10.12。另外这个的话，我大致学了下 swift，cocoa 这边的话边摸索边弄的，以上，哈哈。」[2][3][4][5]

第三幕 · 稳健演进：内核平移与 Apple Silicon 架构跨越

随着底层协议生态的剧烈洗牌，从早期的 VMess 到 Trojan、VLESS，再到 2021 年社区因 XTLS 协议引发的核心分立，yanue 始终保持着敏捷而冷静的技术响应。

2021 年 6 月，V2rayU 迎来 3.1.0 关键更新，果断将底层核心平移升级为 Xray-core，全面支持 VLESS 与 Trojan 的二维码导入与分享，大幅降低了节点切换等待时间。

2022 年 8 月，苹果全面推进 M 系列芯片变革，yanue 在 3.3.0 版本中完成了针对 Apple Silicon 的原生 arm64 架构适配，彻底摆脱了 Rosetta 2 转译开销，让客户端在 M1/M2/M3 设备上以极低功耗与毫秒级速度平稳运转。[7][8]

第四幕 · 健壮防御：系统代理自愈与真实 RTT 测速

在桌面代理工程的日常维护中，网络异常与系统代理状态不同步是造成用户“断网 panic”的核心顽疾。当 Mac 笔记本突然休眠盒盖、强行关机或核心意外退出时，残留的系统代理设置往往会导致整机网络瘫痪。

yanue 为此设计了缜密的系统代理状态自愈机制与本地 PAC HTTP 托管服务，并在每次启动与退出时做严格的配置恢复检查，确保用户在任何异常断连后都能一键恢复网络。

而在 2023 年 10 月发布的 4.0.0 架构升级中，他进一步重构了延迟测试模块，摒弃易受干扰的虚假 ICMP 探测，改为计算真实 HTTP 握手响应时间（RTT），并实装了订阅分组与最新的 REALITY 协议支持。[9][13]

第五幕 · 涅槃重铸：SwiftUI 与 sing-box TUN 革命

步入 2026 年，历经八载演进的 V2rayU 迎来了创世以来最宏大的一次技术涅槃。面对老旧 Cocoa 视图层与 UserDefaults 存储的扩展极限，yanue 展现出不输年轻一代开源者的澎湃创新力。

2026 年 6 月，V2rayU v5.1.0 全新 UI 正式版破茧而出。他彻底抛弃了过往的技术包袱，基于现代 SwiftUI 声明式架构与 SQLite3 数据库全面重构了整个应用的前后端交互。

更为关键的是，V2rayU 首次深度集成 sing-box 内核，实装了 macOS 原生 TUN 虚拟网卡全流量接管，彻底打破了传统 HTTP/SOCKS 系统代理无法截获终端命令行、Git 同步、游戏 UDP 与后台守护进程流量的技术藩篱；状态栏托盘更首次支持上下行实时网速与 Ping 值常驻跳动。[10][11][12]

第六幕 · 八载常青：纯粹开源的匠人风骨

从 2018 年 macOS Mojave 时代的一行初创代码，到 2026 年 macOS Sonoma 与 Sequoia 下流畅运行的现代客户端，V2rayU 在 GitHub 斩获了超过两万颗 Star。

在这长达八年的开源长跑中，无数昙花一现的客户端在协议洗牌、版本疲倦与现实压力中悄然删库或转向商业收费，而 yanue 始终恪守着无私奉献的初心。

在每个新版 macOS 发布、每个核心协议变更的节点，他总能默默送上及时的修复与迭代。V2rayU 已成为数十万苹果用户数字生活里不可或缺的一抹剪影，在网络自由的长卷上镌刻下最温润而持久的原生印记。[1][12][13]

编年大事记

2018-10-09

yanue 推送 V2rayU 创世提交

在 Xcode 中创建初始项目并提交代码，正式立项基于 Swift 与 Cocoa 的 macOS 原生菜单栏代理客户端。[2]

2018-11-29

发布 V2rayU 1.0.0 正式版

确立极简菜单栏交互模式，支持二维码一键扫码导入与系统 PAC 智能分流。[4]

2018-12-20

发布 1.1.0 版本确立三态代理切换

实装全局模式、PAC 模式与手动模式三态切换，并完善系统代理自动接管逻辑。[5]

2020-02-09

发布 2.0.0 架构升级版

深度重构节点导入与批量订阅管理体系，提升复杂网络环境下的多节点轮转体验。[6]

2021-06-13

发布 3.1.0 版本平移升级 Xray-core

底层核心由 v2ray-core 平移升级至 Xray-core，全面支持 VLESS 与 Trojan 导入及二维码分享。[7]

2022-08-19

发布 3.3.0 版本原生支持 Apple Silicon

全面适配 M 系列芯片与 macOS arm64 原生架构编译，消除 Rosetta 转译并大幅优化能耗。[8]

2023-10-14

发布 4.0.0 预览重构版

实装真实 RTT 测速、REALITY 协议支持与订阅分组展示，重构 PAC 本地生成引擎。[9]

2026-04-09

发布 5.0.0 架构重构预览版

宣布以全新 SwiftUI 声明式界面与 SQLite3 数据库彻底取代旧版 Cocoa 视图与 UserDefaults。[10]

2026-06-21

发布 5.1.0 全新 UI 正式版与 TUN 网卡接管

基于 sing-box 核心实装 macOS 原生 TUN 虚拟网卡全流量接管，状态栏支持实时网速与 Ping 值显示。[11]

2026-08-02

发布 5.2.0 版本优化系统自愈与路由

改进 TUN 路由排除机制与启动就绪检查，修复工作区休眠与唤醒通知监听，提升极端网络恢复稳定性。[12]
