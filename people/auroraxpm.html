NekoBox for OpenWrt：以提交记录确认的主要维护者

在 OpenWrt 上持续维护 NekoBox、Mihomo 与 sing-box 管理组件

按提交者而不是组织名归属

仓库所有者是 Thaolga，但 Git 根提交和后续绝大多数代码提交均由 Auroraxpm 完成；这是把人物绑定到实际维护者的主要依据。

项目 README 提供了安装脚本、OpenWrt 编译方式和依赖清单，说明其目标是路由器 Web 管理组件。[3][2]

持续更新安装与组件

2024 年的初始化阶段完成 Makefile、PHP 页面和安装脚本；2026 年继续发布版本、调整 Nginx/FastCGI 支持并更新位置数据。

公开记录支持“主要维护者”这一谨慎表述，不足以证明 Auroraxpm 是 Thaolga 账号背后的同一现实人物。[4][5][6]

与上游内核分开记录

NekoBox for OpenWrt 打包 Mihomo、sing-box 等依赖，但这些依赖的内核血缘与 NekoBox 的项目维护关系分开处理。

人物页只关联 NekoBox for OpenWrt，不将 Thaolga 组织下的其他仓库自动扩展进来。[2][1]
