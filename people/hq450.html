把透明代理带进华硕路由器：FancySS 的全架构与嵌入式传奇

坚守华硕梅林路由器透明代理八年，以全架构适配与 Zig 语言嵌入式革新守护近两万星标生态

第一幕 · 时代风暴：家庭网关与软件中心的蛮荒断崖

2017 至 2018 年间，中国家庭宽带迅速迈入百兆乃至千兆普及期，智能电视盒子、海外游戏主机、平板电脑与智能家居设备成批涌入千家万户。

在每一个独立终端上反复安装调试代理客户端既繁琐又不现实，在家庭主路由器上实现“全局无感透明分流”成为了无数极客群体的刚性诉求。

当时，搭载 ASUSWRT-Merlin（梅林）与 Koolshare 改版固件的华硕路由器凭借强悍的硬件配置与“软件中心”生态席卷玩家群体。

然而风云突变，2018 年中，官方软件中心迫于合规压力全面下架并封禁了原有的“科学上网”插件，数以百万计的华硕路由器瞬间断流，用户面临着无法更新规则与配置的巨大断崖。[1][2]

第二幕 · 临危受命：FancySS 诞生与全架构接管

2018 年 8 月 26 日，GitHub 上悄然设立了一个名为 hq450/fancyss 的代码仓库；8 月 30 日，开发者 hq450 推送了标志性的创世提交（commit eeac814: clean commit）。

他正式接过了华硕路由器科学上网的维护火炬，将项目定名为 FancySS，并开辟了独立离线包仓库 fancyss_history_package。

华硕路由器的硬件世界充斥着千差万别的底层架构与混乱的内核环境。hq450 在创世之初便展现了雷厉风行的全架构工程攻坚：

8 月 30 日首发攻克老旧 Broadcom ARMv7 平台（RT-AC68U / RT-AC88U / R6300V2）；9 月 2 日更以一行坚定的提交说明宣告了全新一代博通平台的归属：

「接管ARM架构，hnd平台，linux内核：4.1.27 梅林/官改固件(RT-AC86U/RT-AC5300)固件的科学上网」

通过“离线包一键上传安装”与 Web 后台管理界面的无缝衔接，hq450 挽救了数百万家庭网络的自由之门。[5][6][3]

第三幕 · 协议跃迁：从 Shadowsocks 到 Xray 节点分流

随着底层翻墙协议从传统的单向加密向现代传输载荷演进，FancySS 始终保持着高度敏锐的迭代节奏。

2018 年 9 月，hq450 率先在 arm 与 hnd 固件上实装 V2Ray 二进制与 VMess 订阅解析；2020 年 4 月，在 HND 平台引入 Trojan 协议；

2022 至 2023 年，伴随着 Xray-core、VLESS 与 XTLS 的兴起，hq450 为 FancySS 构建了专属的 Xray 交叉编译与自动化分发流水线（make_latest.sh），针对路由器 CPU 架构以 UPX 压缩将二进制体积压缩至极限；

在 3.5 版本中，他创新性地打通了“节点分流（Node Shunt）模式 7”，支持将不同的国内直连、海外网页、流媒体解锁与游戏加速流量分流至不同的后端节点，在小巧的家用路由器上构建起了工业级流量调度引擎。[7][8][9][11]

第四幕 · 规则编排：chinadns-ng、SmartDNS 与内核级重定向

在路由器网关层实现透明代理，最险恶的暗礁莫过于跨越内核版本鸿沟与对抗极其猖獗的 DNS 投毒。

华硕固件的 Linux 内核跨越了十余年沧桑：从老机型 2.6.36.4 的古董内核，到 4.1.27 与 4.19，再到 Wi-Fi 7 机型的 5.4 现代内核。

hq450 针对不同内核精准匹配 iptables、ipset、ipt2socks、tproxy 以及 redsocks 重定向链条，实现全局 TCP 与裸 UDP 流量的毫秒级拦截。

在 DNS 分流防线，FancySS 深度融合了 chinadns-ng 与 smartdns 双重方案，配合 dnsmasq、gfwlist.conf 与 chnroute.txt 大陆 IP 白名单，首创了动态解析与预解析双模切换机制，结合最高优先级的 BlockList 屏蔽列表，彻底消除了内网终端的 DNS 污染与解析延迟。[3][4]

第五幕 · 硬核深水区：嵌入式微型革命与 Zig 语言重构

步入 2024 至 2026 年，主流代理协议核心体积日益膨胀，Go 语言与 Rust 的现代二进制动辄几十兆，多连接并发时内存消耗激增，在闪存仅有几十兆、内存仅有 256MB/512MB 的弱性能路由器上极易引发 OOM（内存溢出）导致路由器频繁死机崩溃。

面对这一严峻的嵌入式物理桎梏，hq450 做出了令人瞩目的前沿技术革新：全面拥抱新一代系统级编程语言 Zig。

2026 年 5 月，他陆续用 Zig 语言独立研发并开源了一批专为嵌入式环境定制的微型工具链：

anytls-zig 以固定连接池与固定 relay worker 池接管 SOCKS5 转发，显式限制线程栈大小，彻底根除高并发内存泄漏；status-tool 与 statusctl 基于 Unix Domain Socket IPC 实现了高效后台守护，终结了旧版 shell 脚本定时轮询对弱 CPU 的沉重挤占；sub-tool、node-tool 与 geotool 则将大订阅解码与地理规则提取耗时降至毫秒级。

凭借极致轻巧的编译产物，FancySS 成功打破了嵌入式硬件的物理瓶颈，展现了令人叹服的极客造诣。[12][13][4]

第六幕 · 时代余响与极客长青

从 2018 年临危受命接过接力棒，到 2026 年跨越 Wi-Fi 7 与 10G 光网时代，hq450 八年如一日地守护着 FancySS 的每一次版本升级。

FancySS 在 GitHub 斩获近 1.4 万颗星标，其离线安装包在数以百万计的家庭路由器中静默运转，守护着无数电视盒、游戏机与家庭电脑的数据流通。

面对外部环境的波谲云诡，hq450 始终保持低调克制，恪守纯粹的开源技术边界，用一行行扎实严谨的系统级代码，在小小的路由器机箱里筑起了一座捍卫全家网络自由的技术丰碑。[15][16]

编年大事记

2018-08-26

设立 GitHub 代码仓库

在华硕/梅林官方软件中心下架科学上网插件的背景下，设立 hq450/fancyss 仓库，开启离线插件维护。[1]

2018-08-30

提交创世 clean commit

推送 commit eeac814，正式立项 FancySS 并设立离线包分发仓库，首发支持博通 ARMv7 平台。[5][2]

2018-09-02

接管博通 HND 平台

提交 commit a4fdf6f，全面适配 Linux 4.1.27 内核的 RT-AC86U 与 RT-AC5300 梅林/官改固件。[6]

2018-09-07

实装 V2Ray 协议与订阅支持

提交 commit 05439bb，为 ARM 与 HND 平台引入 V2Ray 核心二进制与 VMess 订阅解析。[7]

2020-04-07

引入 Trojan 协议支持

提交 commit ce53fe1，为 HND 平台引入 Trojan 代理二进制并整合进路由器透明转发链路。[8]

2022-06-03

构建多核心自动化编译流水线

建立脚本与 Makefile，实现对 Xray、shadowsocks-rust 与 kcptun 二进制的自动编译与 UPX 压缩。[1]

2023-06-16

发布 FancySS v3.1.3

提交 commit c7e2da8 并发布 release tag v3.1.3，实装 Xray 自动化构建与更新分发脚本 make_latest.sh。[9]

2024-12-10

重构并确立 3.0 分支基准

提交 commit b3055d5，全面整理 3.0 分支代码历史，覆盖 Broadcom、Qualcomm、MediaTek 全平台架构。[10]

2026-03-30

实装节点分流模式 7

提交 commit 1b9f674，正式引入 Node Shunt 模式，支持将不同规则域名的流量精准分流至不同后端代理节点。[11]

2026-05-04

全面引入 Zig 语言微型工具链

提交 commit 1823515 与 80a0fd4，发布 3.5.25，将 anytls-zig、node-tool 等作为子模块引入，根除嵌入式内存瓶颈。[12][13]

2026-05-10

发布 3.5.28 适配新版 Xray

提交 commit f7fbdca，升级自编译 Xray-core v26.3.27 并适配 Hysteria2 finalmask 与 WebSocket 新版配置结构。[4]

2026-05-20

发布 3.5.29 稳定订阅映射

提交 commit 607c153，实装订阅 Profile 身份映射并支持联发科 Wi-Fi 7 旗舰路由器 GS-BE7200X。[14]

2026-06-02

发布 3.5.30 最新稳定版

提交 commit b19e82c，持续优化弱性能机型按需探测链路与 SmartDNS 硬屏蔽，项目收获近 1.4 万星标。[15]
