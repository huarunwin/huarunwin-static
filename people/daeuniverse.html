内核态旁路革命：dae 与 eBPF Linux 高性能透明代理标杆

打破传统用户态上下文切换开销，以 Linux eBPF 技术在内核态实现 O(1) 纳秒级极速分流与 Web 面板 daed

第一幕 · 软中断深渊与传统困境

在 Linux 网关与软路由透明代理的长达十数年的演进史中，iptables REDIRECT 与 TPROXY 曾是不可动摇的行业铁律。

然而，这套机制在现代千兆光纤与海量高并发连接面前逐渐显露出致命的物理天花板。

每一个流经网关的数据包，都必须在内核网络协议栈与用户态代理进程之间经历双向搬运与密集的上下文切换。

一旦瞬时吞吐飙升或遭遇海量 UDP 突发，CPU 的软中断（softirq）便会呈指数级飙升直至跑满核心，导致网络转发速率雪崩、延迟剧烈抖动。

彼时活跃在 v2rayA 项目的核心开发者 mzz2017 敏锐地洞察到：在用户态做性能优化的空间已然消耗殆尽，要想彻底打破宿命，必须将分流逻辑下沉到最深层的 Linux 内核。[1][3]

第二幕 · 破茧而出与大鹅创世

2023 年 1 月 23 日傍晚，mzz2017 在 Git 中推送了创世提交 6fba4f8（init），正式拉开了内核态代理的序幕。

在项目的初版 README 中，作者写下了一段极具极客自豪感与探索诗意的创世宣言：

“dae，中文即‘鹅’，是一款轻量且极高性能的透明代理方案。为了将流量分流性能推向极致，dae 借助 eBPF 在 Linux 内核中运行透明代理与分流套件。通过这一‘魔法戏法’，直连流量完全绕过代理应用的转发，实现真正的直接旁路贯通，几乎毫无性能损耗与额外资源开销。”

最初项目在 v2rayA 体系内孕育（v2rayA/dae），但随着设计思想的决绝进化，dae 毅然决然摆脱了对传统核心的依赖。

2023 年 3 月 14 日，团队推送了 tag v0.1.0（commit a2e176b：chore: transferred to daeuniverse），正式成立独立的 daeuniverse 组织，开启了全速狂飙。[3][4][1]

第三幕 · 内核态魔法与 O(1) 直通

dae 掀起的根本性技术颠覆，在于将现代 Linux 内核最高前沿的 eBPF（扩展伯克利数据包过滤器）与 TC（Traffic Control）子系统深度结合。

借助 eBPF 运行时的 JIT 即时编译，dae 将高效的字节码探针直接钉在网络设备的驱动层出入口。

在数据包抵达物理网卡的最初数纳秒内，eBPF 程序就已在内核态完成了对五元组元数据与 TLS SNI 首包特征的零拷贝嗅探。

对于命中直连规则的海量流量，内核直接返回 TC_ACT_PIPE 或 TC_ACT_OK，让数据包在驱动层瞬间放行旁路直通，彻底绕过了用户态的系统调用与内存跨界拷贝。

从传统的重定向搬运，跃升为 O(1) 复杂度的内核态极速直通，透明代理的技术范式自此被彻底重写。[1][5]

第四幕 · 图形化觉醒与 daed 矩阵

虽然 dae 在性能跑分与网络吞吐上展现出降维打击般的威力，但直接手写基于 eBPF 的规则配置文件，对普通软路由玩家而言依旧横亘着陡峭的技术壁垒。

为了让这头性能猛兽走进千家万户，daeuniverse 团队于 2023 年 3 月 2 日正式开源了全新的现代 Web 仪表盘项目 daed。

daed 采用现代化前后端架构，不仅带来了极具科技感的可视化网络拓扑面板、节点低延迟智能探测矩阵，更首创了交互式路由规则编辑器。

随后，团队甚至孵化出了专门的 dae-lsp 语言服务协议与 dae-editor，构筑起从配置编写、语法高亮到实时运行时诊断的完整生态闭环。

daed 迅速斩获超 2,000 颗 GitHub 星标，让高深莫测的内核网络编程转化为了指尖轻点即可驾驭的优雅体验。[2][6][5]

第五幕 · 内核边界攻坚与 2.0 宏大重构

在内核世界中漫游每一步都如履薄冰。eBPF 字节码必须严格通过 Linux 内核验证器（Verifier）的静态安全审计，稍有指令越界或循环不收敛便会直接加载失败。

团队持续攻坚，跨越了从 Linux 5.x 到 6.x 的多版本内核差异，并攻克了 GCC 15 环境下复杂的 CO-RE（一次编译，到处运行）重定位难题。

2026 年 7 月 8 日，团队正式发布代号为 v2.0.0 的划时代重构版本，全面重构了控制平面与规则调度引擎。

紧随其后的边界修补同样展现了顶尖的系统水准：7 月 31 日，AkinoKaede 提交 commit caa6f5e，成功保护了用户自定义组覆盖下的 DNS 隔离；

8 月 26 日，uJZk 提交 commit 5db27a0，精准排查并修复了多网卡环境下出口路径的直通放行逻辑：“fix(control): return TC_ACT_PIPE on wan_egress pass-through paths”。[7][9][10]

第六幕 · 时代余响与内核态革命

2026 年 9 月 18 日，daeuniverse 团队正式推出了 v2.1.0 与 v2.1.1 稳定版本，完成了与 kdae 数据平面的全量深度同步（PR #1099），更将出站链路推向了抗量子的 REALITY post-quantum 时代；同时 daed Web 面板也迎来了 2.1.1 的同步升级。

截至 2026 年秋，dae 在 GitHub 上收获了超过 6,200 颗星标，在全球软路由与开源网关领域确立了无可动摇的性能霸主地位。

daeuniverse 团队以无可辩驳的工程突破向行业昭示：透明代理的终极演进并不在用户态的多核心拼凑，而在操作系统内核的深邃沃土之中。

这只从 Linux 协议栈内核中破茧而出的“大鹅”，已然成为整个网络抗审查技术编年史上永不磨灭的技术标杆。[8][1][6][11]
