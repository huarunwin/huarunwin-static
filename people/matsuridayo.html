多协议集大成者：从 Matsuri、NekoRay 到 NekoBox 的全能异构矩阵

以 Qt 与跨平台系统级工程力打造多核心集成标杆，让前沿代理协议惠及桌面与移动全端

第一幕 · 割裂年代与移动端破局

2020 年代初，网络代理生态迎来了前所未有的协议大爆发。从 VLESS、XTLS 到 Trojan、Shadowsocks-2022，再到新兴的 NaïveProxy 与 Hysteria，协议层百舸争流，却在客户端层面撕开了一道巨大的鸿沟。

底层内核阵营分立，配置语义彼此割裂。普通用户在桌面与手机端常常需要安装数个不同的专用客户端才能应对各色节点；桌面 Linux 用户更是长期受困于图形化工具的极度匮乏，不得不靠裸跑终端脚本维系连接。

开发者 MatsuriDayo（以 arm64v8a 活跃于 Git 提交中）在 2021 年底接手并分叉 SagerNet 代码，创建了名为 Matsuri（茉莉）的 Android 客户端。他首次在移动端确立了通用的模块化插件架构，将 NaïveProxy、Hysteria 等前沿工具包装为标准插件独立分发，打响了统合多协议体验的第一枪。[1][2]

第二幕 · 跨平台桌面破局：Qt/C++ 的开箱即用

移动端的初步告捷并未让 MatsuriDayo 止步，桌面端的生态贫瘠依然是他眼中的巨大痛点。2022 年 5 月 3 日，他正式在 GitHub 上线 nekoray 项目。

与当时许多开发者沉迷于打包体积庞大、资源占用高昂的 Electron 容器不同，MatsuriDayo 凭借深厚的系统级功底，毅然选择编译原生、启动轻捷的 C++ 与 Qt 框架作为桌面架构基石。在首日推送的 2.5 万行核心代码中，他写下了极其务实直接的项目宣言：

「使用 Linux 系统相信您已具备基本的排错能力，本项目不提供特定发行版/架构的支持，预编译文件不能满足您的需求时，请自行编译/适配。」

在社区议题区，面对老旧 32 位机器的兼容请求，他直接留下标志性的硬核回复：「You should throw away your i386 PC」；面对不合理的功能蔓延请求，他也往往仅以干脆利落的「won't」回应。这种专注核心工程、拒绝任何妥协的极客作风，让 nekoray 迅速赢得了 Windows 与 Linux 高级用户的狂热追随。[4][5][6]

第三幕 · 异构内核与转译深水区：从双核并行到多态中间件

随着 sing-box 的异军突起与 Xray-core 的日臻成熟，开源社区围绕“孰优孰劣”的阵营辩论此起彼伏。MatsuriDayo 展现出了超凡的架构抽象力——他拒绝站队，而是选择用代码构筑通用的桥梁。

2022 年 9 月，他在 nekoray 中推送了划时代的「switch core support」提交，首创 nekobox_core 架构。在 Linux 平台上，他率先引入 sing-box 优雅接管 VPN 与 TUN 虚拟网卡，彻底解决了 Linux 桌面缺少高效系统级透明代理的顽疾。

2023 年 7 月，他又推送了「change core v2ray to xray」提交，顺畅淘汰了陈旧的 v2ray-core，将 Xray 的 uTLS 伪装与 SpiderX 等前沿能力无缝映射进 GUI。他精心设计了跨进程 IPC 与双向配置转译器，将不同内核生涩复杂的 JSON 配置统一抽象为清晰直观的图形化路由与分流表单。[7][8][12][11]

第四幕 · 移动端重铸：NekoBox 的工具链革命

尽管 Matsuri 赢得了庞大声誉，但历史代码积累的技术债务与多进程插件的冗余调度，在 Android 严苛的功耗与内存限制下愈发吃力。

2023 年 3 月，MatsuriDayo 展现出极客最决绝的魄力：宣布 Matsuri 进入维护归档状态，以全新现代化架构立项 NekoBox for Android（NB4A），深度绑定 sing-box 核心。

他将 Go 语言运行时深度嵌入 Android 原生 VpnService，实现了毫秒级路由决策与零冗余内存开销；在 1.3.1 版本中，他率先跟进 sing-box 1.8 规范，以高效紧凑的 rule_set 二进制规则集彻底取代臃肿的旧式 Geo 数据；在 1.4.0 版本中，他又实装了强大的自定义 JSON 配置合并机制（Map 合并与 List 注入）以及 ECH / H3 订阅防污染直连。NekoBox 由此成为 Android 平台上公认的“全功能瑞士军刀”。[9][10][13][16]

第五幕 · 减负收敛与 4.0 绝唱：属于极客的体面告别

多端并进与多核兼容的背后，是单兵作战难以承受的工程负荷。随着社区涌入大量基础薄弱的小白用户，无休止的求助与跨平台兼容琐碎逐步侵蚀着开发热情。

2024 年 7 月，MatsuriDayo 针对桌面端做出了壮士断腕般的战略收敛：nekoray 启动 4.0 架构重构，移除 Xray 兼容支持与多内核切换逻辑，主程序统一更名为 nekobox.exe，全面聚焦于 sing-box 单核的高效调试。

在 2024 年 12 月发布的 4.0.1 终章版本发布说明中，他写下了那段被无数开发者奉为圭臬的赤诚自白：

「本软件为 Windows/Linux 端节点调试工具，适合有一定基础和学习能力的用户使用。机场用户建议使用其他软件。白嫖用户建议去死。」

「您须了解本项目使用并且在 GPLv3 许可下再发行『世界』维护的 sing-box 翻墙核心……本项目较少维护，如有 BUG 请通过 issue 反馈，非重大 BUG 则可能不会修复。」

随后，桌面端代码库正式归档为只读仓库。MatsuriDayo 坦然转身，为 nekoray 长达两年半的高强度演进画上了一个尊严而清醒的句号。[14][15][18]

第六幕 · 坚守移动阵地与开源丰碑

桌面端的封存并未意味着开发生涯的中止。在移动端战场上，NekoBox for Android 依然是一座屹立不倒的技术灯塔。

从 2025 年 9 月发布的 1.4.0 大版本重构，到 2026 年 2 月发布的 1.4.2 稳定版，MatsuriDayo 持续跟进定制化 sing-box 核心，细致打磨订阅覆写保护与高并发直连请求，为全球数十万身处严格网络审查环境的用户提供了坚若磐石的通道。

从 C++/Qt 的跨平台桌面工程，到底层 Go 协程与 Android 系统内核的丝滑交融，MatsuriDayo 用一行行朴实、硬核、高效的代码，诠释了纯粹的技术理想主义与卓越的开源匠人精神。[16][17][19]

编年大事记

2021-11-30

Matsuri 移动端项目创世建立

分叉 SagerNet 代码创建 Matsuri (茉莉) 仓库，探索 Android 平台多协议支持与通用插件化架构。[1][2]

2022-05-03

NekoRay 跨平台桌面客户端立项

在 GitHub 创建 nekoray 仓库并推送初始源码，基于 Qt/C++ 为 Windows 与 Linux 提供轻量高效的开箱即用图形客户端。[4][5]

2022-09-24

nekobox_core 与内核多态架构实装

提交 switch core 支持并引入 nekobox_core 架构，在 Linux 平台上率先集成 sing-box 接管 VPN 与 TUN 网卡。[7]

2022-10-19

NekoRay 发布 2.0 稳定版

升级 sing-box 1.1-beta10，实装核心崩溃自动重启并恢复运行配置机制，优化 VMess/SNI 自动填充。[8]

2023-03-15

NekoBox for Android 源码立项

全面重构移动端技术栈，以现代化 sing-box 核心深度嵌入 Android VpnService，正式立项 NekoBox for Android。[9]

2023-04-03

NekoBox for Android 发布 1.0.0 正式版

集成 sing-box 1.2.2 并启用 gRPC 支持，实装 REALITY 协议解析导入与去重测试，标志着移动端全新工具链成熟。[10]

2023-05-14

NekoRay 发布 3.0 大版本重构

Windows 端升级 Qt 6.5 构建，重构 Mux 多路复用与路由 DNS 对象，全面支持 h2mux、smux 与 yamux。[11]

2023-07-05

NekoRay 内核全面平移升级 Xray-core

推送核心改造提交，将旧版 v2ray-core 彻底替换为 Xray-core，并在图形界面实装 uTLS 指纹与 SpiderX 伪装。[12]

2024-02-24

NekoBox for Android 实装 1.3.1 规则集升级

引入 sing-box 1.8.0 规范，全面以 rule_set 二进制规则集替代传统 geoip/geosite，并实装 Mieru 协议支持。[13]

2024-07-05

NekoRay 开启 4.0 路线更名 nekobox.exe

剥离 Xray 多内核切换逻辑，主程序统一更名为 nekobox.exe，全面聚焦于 sing-box 单核的高效稳定调试。[14]

2024-12-12

NekoRay 发布 4.0.1 终章并正式归档

升级 sing-box 1.9.7-neko1，发布 4.0.1 最终版本并附带坦率的极客告白，桌面端仓库正式进入只读归档状态。[15][18]

2025-09-20

NekoBox for Android 发布 1.4.0 里程碑

升级 sing-box 1.12.8-neko-1，实装 ECH 与 HTTP/3 订阅直连获取、高级 JSON 自定义配置合并与 gVisor TUN 栈。[16]

2026-02-09

NekoBox for Android 发布 1.4.2 稳定版

升级 sing-box 1.12.19-neko-1，优化订阅覆写与本地自定义 JSON 配置保留逻辑，持续构筑坚固的移动端防线。[17]
