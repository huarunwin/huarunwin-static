原生视窗的微光守望：Clash .NET 与 WPF 桌面客户端纪事

以原生 WPF 与 .NET 5 打破 Electron 臃肿垄断，在历史风暴中留下珍贵的技术印记与源码快照

第一幕 · 混沌前夜与 WPF 原生破局

2021 年春，Windows 生态中的 Clash 客户端正处于 Electron 架构（如 Clash for Windows）全面普及的初期。

尽管 Webview 界面功能丰富，但动辄数百兆的内存消耗与庞大的运行时体积，让许多低配置电脑与追求极致轻量的 Windows 极客苦不堪言。

2021 年 3 月 1 日，开发者 CoelWu（以组织账号 ClashDotNetFrameworkDev）在 GitHub 推送了项目根提交（commit 83c2ced），开启了代号为 ClashDotNetFramework 的原生探索。

他下定决心摒弃笨重的 Chromium 外壳，拥抱 Windows 原生 WPF（Windows Presentation Foundation）与 XAML 技术栈，立志打造一款体积不到 30MB 的原汁原味原生客户端。[1][2]

第二幕 · 架构跃升与 .NET 5 全新定位

从最初基于 .NET Framework 4.6.1 的原型起步，CoelWu 迅速将视野拓展至微软刚刚推出的现代开源统一平台 .NET 5。

在 2021 年 5 月 3 日的文档更新中（commit 12dba60），项目正式将产品标语升维为：“A Clash GUI Proxy For Windows Based On .NET 5”。

依托 .NET 5 的自包含单文件发布与更高效的运行时性能，客户端不仅全面向下兼容 Windows 7 及以上全版本操作系统，还将磁盘占用严格压缩在 30MB 以内。

同时，CoelWu 设计了高度现代化的 UI 界面，提供 Classic、Dark 与 Modern 三套原生矢量主题，让 Windows 桌面代理体验兼具美感与敏捷。[5][6]

第三幕 · 硬核深水区：进程级分流与系统网络接管

在工程实现底层，CoelWu 没有局限于简单的系统代理转发或常规 TUN 虚拟网卡配置。

为了解决游戏与各类专业软件的精准分流痛点，他在项目中集成了来自 Netch 与 NetFilter SDK 的核心技术，设计了独具特色的“高级模式”（Advance Mode）。

通过内核驱动级别对进程名字的深度拦截与重定向，Clash .NET 实现了全网首批原生进程级进程代理与 Fullcone NAT 支持。

此外，在系统托盘菜单中，他深度整合了终端代理命令一键复制、Telegram 专属代理一键设定，以及 30 秒平滑滚动的交互式动态测速折线图。[9][7]

第四幕 · 源码开源与工程快照的定格

随着软件在极客群体与技术论坛中收获了数千星标与广泛好评，社区中关于开放源码的呼声日益高涨。

2021 年 7 月 6 日，CoelWu 提交 commit b1a70e3，在 GitHub 郑重上传了客户端完整的工程源代码快照，并在随后追加了 GPL-3.0 自由软件许可证。

工程由核心主程序、FireWallHelper（Windows 防火墙自动化规则模块）与 NetFilterHelper（网络过滤驱动接口）三大模块紧密协同。

在这份珍贵的源码快照中，程序集版本号定格在 0.0.8.0，版权信息清晰地印刻着“Copyright © 2018-2021 Coel Wu”，成为中文社区在 WPF 代理客户端领域的代表性工程遗产。[7][8][9]

第五幕 · 风暴骤起与离场声明

开源世界的平静往往脆弱而短暂。2021 年秋季，随着针对代理软件治理力度的骤然升级，各大开源仓库与社群面临着前所未有的外部风暴。

2021 年 10 月 25 日，CoelWu 的 GitHub 官方代码仓库被清空，只留下了一行平静而沉重的纯文本宣告（commit af41475）：

“Removed according to regulations.”（依照规定移除）。

不久之后，原仓库彻底返回 404 状态，官方 Telegram 频道与群组亦相继关停，作者账号随即隐退沉寂。

面对突如其来的离场，多位开源社区成员（如 Sherman-Liu、sqzxcv、qidd2021 等）通过 Fork 与镜像副本，将这份宝贵的历史文档、提交链条与源码快照永久封存进 Git 的历史档案中。[10]

第六幕 · 时代余响与原生之光的守望

Clash .NET 的生命周期虽然在公开网络上仅仅定格在 2021 年的数月之间，但它所点亮的技术火种却深远地照亮了后来者。

它不仅证明了 C# 与 WPF 在跨协议代理客户端领域的极致性能与开发表现力，更为后来的 Swell Proxy、NekoBox for Windows 等一批 Windows 原生网络工具提供了关键的工程原型与架构启示。

从 30MB 极限身材的优雅，到驱动级进程代理的硬核，CoelWu 在历史长河中留下的这串踏实脚印，始终是 Windows 原生极客软件发展史上不可磨灭的微光。[7][10]
