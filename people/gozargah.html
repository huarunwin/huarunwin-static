边境之地的自由渡口：Gozargah 与 Marzban 的抗审查长城

在断网阴霾中破土而出的“边境守卫”，以 mTLS 分布式集群重筑网络生命线

第一幕 · 凛冬风暴：断网阴霾下的“边境守卫”

2022 年秋，一场前所未有的网络凛冬席卷了伊朗大地。全国范围内的移动网络间歇性切断、国际出口带宽遭受严厉降速，深度包检测（DPI）与基于 IP 黑名单的封锁手段层出不穷。

对于身处重围中的普通民众而言，与外界的通讯连接几乎在瞬间被斩断；而当时社区中广泛流传的传统单机代理面板，在面对服务器 IP 频繁被“定点清除”的现实时，显得极其脆弱而笨拙——一旦单台服务器 IP 被封锁，管理员便不得不重新安装整套系统，所有的用户数据与配置在混乱中荡然无存。

“我们必须为那些无法发声的人构筑一条坚固的通道。”2022 年 10 月 20 日，一个名为 Gozargah（波斯语中寓意“渡口、通道与自由过客”）的组织在 GitHub 悄然成立。

一个月后的 11 月 24 日，核心项目 Marzban 正式推送了第一行代码。在古波斯语中，“Marzban”代表着驻守帝国边疆、御敌于外的“边防长官”或“边境守夜人”。自命名之日起，这个项目便被赋予了守卫网络自由边界的沉重使命。[1][2]

第二幕 · 架构革命：FastAPI 异步基座与 Fallback 艺术

与以往许多依赖 PHP 或松散 Shell 脚本拼凑的面板不同，Gozargah 团队从一开始就确立了极高的工业级工程标准。

他们选用了当时在企业级云原生领域方兴未艾的 Python FastAPI 异步框架，并结合 SQLAlchemy ORM 构建了严密、规范的数据实体模型。非阻塞的异步 I/O 使得 Marzban 能够以极低的内存开销，从容应对成千上万并发连接的实时计量与动态用户策略匹配。

更具突破性的是他们对 Xray Fallbacks（回落机制）的精妙运用。在审查极其森严的阻断环境下，多端口暴露往往等于直接暴露靶子。Marzban 充分利用单端口 Fallback 技术，让 Trojan、VLESS 与伪装 Web 页面共存于唯一的 443 端口之上。

对外界的主动探测而言，这台服务器只是一家再普通不过的静态企业网站；而在正确的 SNI 与协议握手之下，它却化身为一条坚不可摧的数据生命线。[1][2]

第三幕 · 节点星丛：marzban-node 与 mTLS 钢铁防线

然而，单台服务器的伪装再完美，也无法完全避开粗暴的 IP 段封锁。单点故障依然悬在每个运维团队头顶。

为了打破这一宿命，2023 年 4 月 18 日，Gozargah 团队推出了具有里程碑意义的分布式组件：marzban-node。

Marzban 实现了真正意义上的“主从分离”架构：主面板可以安稳部署在未被污染的安全内网或高防数据中心中，仅负责管理用户数据库、Web 界面与 API 认证；而实际承载流量的几十台、甚至上百台边缘服务器，则通过轻量级守护进程 marzban-node 接入集群。

在主控与边缘节点之间，团队采用了金融级严格的双向 TLS 证书认证（mTLS）加密通道。即便某台前哨节点不幸被审查系统封锁 IP，管理员只需在后台一键撤下该节点，用户数据与核心配置毫发无伤，系统随时能在数秒内激活新的节点接入星丛。[3][2]

第四幕 · 薪火相传：AGPL 旗帜下的自由遗产

除了底层架构的坚韧，Marzban 在产品体验与生态开放上也达到了全新高度。它拥有美观现代的 React Dashboard，支持自适应暗黑模式与流畅的移动端交互；内置的订阅转换模块能够智能识别客户端类型，为 Clash、Shadowrocket、v2rayN 动态分发量身定制的最佳配置。

更重要的是，Gozargah 团队自始至终将项目置于严格的 AGPL-3.0 许可证保护之下。这种彻底的开源精神，不仅让 Marzban 赢得了全球超 7300 位开发者的 Star 致敬，更激发了包括 Marzneshin 在内的众多后续分叉与衍生项目。

至 2025 年 1 月发布 v0.8.4 稳定版，Marzban 已成为全球抵御严酷网络封锁的一座不可磨灭的数字丰碑。正如其名字所昭示的那样，这群匿名的极客在网络审查的边境线上，以代码为砖石，为千千万万渴望自由连接的人筑起了一道永不妥协的抗审查长城。[4][2]

代表作品与核心贡献

Marzban

访问作品

基于 Python FastAPI 与 Xray 的统一抗审查代理控制台，提供单端口 Fallback、用户配额与多节点集中管控。

marzban-node

访问作品

Marzban 的轻量级边缘节点组件，通过双向 TLS 认证（mTLS）与主面板安全同步 Xray 配置与流量。

致敬开发者的坚守

代码或许归档，但火种永不熄灭。为推动网络对抗演进与底层工程突破的开拓者献上一份敬意。
