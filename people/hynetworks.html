HyNetworks：项目组织、仓库承载与官方频道

承载 Hysteria、tcp-brutal 与 OpenGFW 的开源项目团队

一、组织身份与时间边界

GitHub API 将 HyNetworks 标记为 Organization，账号创建时间是 2026 年 5 月 23 日。本站因此把它作为开源项目组织/团队收录，而不是把它当成一个新自然人。

Hysteria、tcp-brutal 与 OpenGFW 的 Git 历史都早于或独立于这个组织账号的成立时间。早期提交说明的是今天由 HyNetworks 承载的项目谱系，不能倒推为同名组织当时已经存在。核验时公开成员列表为空，这只说明 GitHub 没有通过该接口展示成员，不能据此推断实际成员或组织所有权。[1][2]

二、当前项目承载关系

HyNetworks 当前是 Hysteria、tcp-brutal 与 OpenGFW 的规范仓库所有者，hysteria.network 则是组织资料登记的项目网站。这里的“承载”只描述当前公开仓库、网站和发布渠道的共同组织身份，不重新讲述 Hysteria 的协议机制，也不把个人技术成果改写成组织成果。

Hysteria 网站仓库的固定配置同时链接了 tobyxdd 的 GitHub Sponsors 页面和 @hysteria_releases。这个组合证明个人贡献者、项目网站与官方频道关系紧密，但仍不足以证明 tobyxdd 是 HyNetworks 的唯一成员、所有者或每条频道消息的个人作者。[4][5][6][10]

三、与 tobyxdd 的关系：创始贡献与组织身份分开记录

Hysteria、tcp-brutal 与 OpenGFW 当前保留的根提交都由 tobyxdd 署名。2026 年 9 月 19 日读取 GitHub Contributors API 时，默认分支统计分别记录 tobyxdd 在三个仓库中有 1024、48 与 83 次贡献，均列首位；这支持将他描述为这些项目的创始者和主要公开技术贡献者。

贡献统计不是成员名册，也不能证明组织的法律所有权或排除其他贡献者。本站继续保留 tobyxdd 的个人档案来记录其协议与代码贡献，同时保留 HyNetworks 的组织档案来记录当前仓库、网站及团队渠道；两者并存但不互相替代。[3][4][5][6][7][8][9]

四、官方频道与发言归属：按原帖逐条判断

2026 年 9 月 19 日，tobyxdd 在 OpenGFW 仓库提交 README 修订；约 7 分钟后，@hysteria_releases 第 129 条消息以“我们”和“内部讨论”等团队口吻宣布重新公开项目。相邻时间与代码署名证明 tobyxdd 直接参与了当天的仓库工作，但该消息没有个人签名，不能据此改写成他的个人声明，本站将它归为 HyNetworks/Hysteria 官方频道的团队声明。

同一频道的第 33 条消息则写着“My response”，并直接链接 tobyxdd 账号下的署名 Gist。这类具备个人署名闭环的内容可以逐帖归到 tobyxdd。频道曾发布个人内容，并不意味着其他所有消息都属于该个人；因此 HyNetworks 保留 feedManualOnly，只允许精确原帖进入人工审核，不自动采集整条时间线。[11][12][13]
