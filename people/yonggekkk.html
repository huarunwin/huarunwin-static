第一幕 · 公开仓库的起点与证据边界

sing-box-yg 当前可达的 Git 历史从 2023 年 10 月 22 日的根提交开始。该提交只新增一行 README 标题，因此只能作为当前保留历史的起点，不能被解释为账号或项目的实际开发起点。

仓库 README 同时列出 VPS 版 Sing-box-yg 与 Serv00/Hostuno-sb-yg 两个脚本入口，并链接到作者博客、YouTube 频道和 Telegram 邀请链接。邀请链接不是标准公开频道主页，本条目不把它登记为 Telegram 自动采集来源。

2024 年 1 月的历史 `sb.sh` 是带有 BZip2 Shell Exec 说明的压缩包装文件；它证明仓库曾上传过脚本快照，但缺少可审计的明文实现，因此不据此推导具体功能或原创代码。[1][15][16][21]

第二幕 · 明文脚本把协议配置落到 VPS

2025 年 2 月 9 日，yonggekkk 以“Create sb.sh”提交了一份可读取的 5184 行 Bash 脚本。脚本包含发行版与 CPU 架构检测、sing-box 安装、证书路径和端口配置，并生成 VLESS Reality、VMess、Hysteria 2 与 TUIC 等配置及分享链接。

固定主分支的脚本还包含面向 Clash/Mihomo 与 sing-box 的配置输出、二维码和节点文件写入逻辑。这里描述的是仓库代码中可核对的输出路径，不把客户端兼容配置写成客户端作者关系，也不把调用 sing-box 写成自研内核。[17][22]

第三幕 · 从四协议说明到五协议与快捷操作

2026 年 3 月 2 日，README 的明确改动把 VPS 脚本从“四协议”说明更新为“五协议”，新增 AnyTLS，并保留 VLESS Reality Vision、VMess WS/Argo、Hysteria 2 和 TUIC v5 的列举。协议名称来自项目自述和脚本配置字段，不能替代对每个发行版本的独立兼容性测试。

2026 年 8 月 20 日，README 增加本地 IP 订阅、Argo 临时隧道、Argo 固定隧道和域名分流的快捷命令示例。它们说明项目把常用操作写成脚本菜单调用；固定隧道仍取决于使用者提供的域名、密钥和运行环境。[18][19][21]

第四幕 · 维护动作与公开教程的范围

2026 年 10 月 22 日的主分支提交“Clean up cloudflared files on Argo stop”在停止临时或固定 Argo 隧道时一并删除 `/etc/s-box/cloudflared`，并显示已安装的 Argo 版本。这是一个具体的清理改动，不能扩展为对全部 Argo 部署状态的安全审计。

作者博客的 sing-box-yg 教程按视频和说明整理了 Argo、Hysteria 2/TUIC v5 端口跳跃、WARP/Psiphon 分流、订阅输出以及多平台客户端配置提示。博客是项目使用文档来源；文档提到的客户端名称只表示配置输出或教程适配，不证明 yonggekkk 维护这些客户端。

仓库根目录的许可证文件为 GPL-3.0。公开许可、教程和脚本可读性不等于本站已完成安全审计，也不替使用者承担 VPS、域名、流量或隧道服务成本。[20][24][23]

代表作品与核心贡献

sing-box-yg

访问作品

面向 Linux VPS 的 sing-box 多协议一键部署脚本，提供配置生成、节点分享和可选 Argo/WARP/Psiphon 组件入口。

argosbx

访问作品

将 Sing-box、Xray 与 Cloudflared-Argo 组合到 VPS、Docker 和容器部署中的一键脚本，仓库 README 还列出 WARP 出站组合与多协议配置输出。

x-ui-yg

访问作品

公开仓库描述的精简 x-ui 脚本，覆盖 Hysteria 2、XHTTP、ENC/MLDSA65、Argo 与 Psiphon 入口，并输出部分聚合订阅配置。

warp-yg

访问作品

WARP 多功能一键脚本，仓库说明列出 warp-go 与 wgcf 切换、配置生成、WARP+／团队账户及 VPS 出站状态检查。

Cloudflare-vless-trojan

访问作品

面向 Cloudflare Workers/Pages 的 VLESS/Trojan 脚本，同时提供可选 ECH-TLS、普通 TLS 或无 TLS 的本地 SOCKS5/HTTP 代理模式。

acme-yg

访问作品

ACME 证书申请与续期脚本，公开说明覆盖 IP/域名证书、单域名/泛域名以及与多个脚本共享证书的用法。

Serv00/Hostuno-sb-yg

访问作品

同一仓库内面向 Serv00/Hostuno 的三协议脚本入口，支持网页保活与订阅配置输出等文档所列功能。
