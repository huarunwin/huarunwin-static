从 MikuBox 双分支到 MikuRay：HatsuneMikuUwU 的 Android 客户端实践

维护 Mihomo 与 sing-box 分支的 MikuBox，并开发基于 v2rayNG 的 MikuRay

同一仓库中的两条内核路线

MikuBox for Android 的仓库于 2025 年 10 月创建，仓库说明称其基于 NekoBox 并加入 Miku 主题。导入仓库的 Git 历史中有更早的上游提交，不能把那些提交当作 HatsuneMikuUwU 的立项时间。

2026 年 7 月的 Miku 分支 README 与子模块指向 Mihomo；UwU 分支 README 与子模块指向 sing-box。两条分支分别构建，不能把两种内核当成同一 APK 的切换选项。[2][3][4][5]

发行版的分支边界

2026 年 2 月 22 日发布的 1.4.3-UwU-2 由 UwU 分支产生，Release 说明写有“sync to latest NekoBox version (1.4.2)”，并说明这个版本停止继续更新。该发行记录只支持描述当时的 UwU 版，不能用作 Miku 分支的版本证据。[6]

MikuRay 的 Xray 构建

MikuRay 仓库创建于 2026 年 5 月。项目 README 将其描述为基于 v2rayNG 的 Android 客户端，并同时提及 Xray 与 v2fly。2.3.1 的 CI 流程取用固定的 AndroidLibXrayLite 子模块及其 libv2ray.aar；该子模块的 go.mod 依赖 Xray-core。因此本站将本发行版可确认的内核记为 Xray，对 README 中的 v2fly 声称保留核验边界。

2026 年 9 月 11 日，HatsuneMikuUwU 账号发布了 2.3.1。说明列出服务生命周期、订阅导入、界面设置等调整；这些是发行说明中的改动项目，不代表本站完成了设备性能测试。[8][9][10][11]
