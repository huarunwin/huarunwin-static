zzzgydi

俗称：GyDi / zzzgydi / Verge 原作者客户端与生态2021 — 2023
Clash Verge 创始开发者

“率先在桌面端引入 Rust + Tauri 轻量架构，以配置覆写脚本与原生服务模式开创现代 GUI 标杆”

在桌面代理客户端普遍被基于 Electron 方案垄断、动辄打包完整 Chromium 导致内存与安装包高度膨胀的时代，开发者 zzzgydi 于 2021 年底敏锐地选用新兴的 Rust + Tauri 技术栈，开创了桌面客户端 clash-verge。他打破常规，借助操作系统原生渲染控件与纯 Rust 进程管控，将体积与常驻内存压缩至原生极简水准；随后攻坚实装 TUN 虚拟网卡、Windows 服务模式与兼具极高灵活性的 Script / YAML Merge 订阅修饰引擎，并率先将新兴的 Clash.Meta 设为默认内核。2023 年底原项目因大环境风暴归档后，社区基于其坚实架构成立 clash-verge-rev 继续演进，他于 2024 年 3 月 23 日明确表示 Rev 不是由他维护；原版贡献与社区后续开发应分别归属。

CoelWu

俗称：Coel Wu / CoelWu / Clash .NET 作者 / ClashDotNetFrameworkDev客户端与生态项目记录：2021
Clash .NET 核心开发者

“以原生 WPF 与 .NET 5 打破 Electron 臃肿垄断，在历史风暴中留下珍贵的技术印记与源码快照”

在 2021 年以 Electron 架构为主流的 Windows 代理客户端时代，开发者 CoelWu 逆流而上，主导研发了基于微软原生 WPF（Windows Presentation Foundation）与 .NET 5 的轻量化客户端 Clash .NET（ClashDotNetFramework）。项目不仅将磁盘体积极致压缩在 30MB 以内，全面向下兼容 Windows 7 及以上系统，还首创性地融合 NetFilter SDK 实现了驱动级进程代理与 Fullcone NAT 支持。尽管原仓库在数月后遵规撤下，但其留存的开源工程快照、现代矢量主题设计以及对 Windows 原生性能的极致追求，为中文开源社区留下了不可磨灭的技术遗产。

收录说明、资料原则与排序逻辑

记录那些为跨越网络边界写下代码、维护工具、分享知识的人。分设「时代先驱与核心创立者」、「活跃开源作者与生态贡献者」与「历史项目开发者」三大专区，从 2011 年的云代理、2012 年的 Shadowsocks 破晓，到现代统一核心演进与新生代跨平台客户端体验重构。这里从可以核实的作品与记录出发，讲述他们的贡献，以及这些工作如何被延续。

本栏目仅基于公开的代码提交记录、官方发布说明与权威第三方报道撰写。使用公开网名与署名，绝不调查、推测或拼接匿名开发者的现实身份与私人信息。

关于排列的说明：活跃作者按本站收录代表作的最高 GitHub Star 数降序排列；同分保留原顺序，暂无数据的排在最后。历史项目开发者列在活跃作者下方，按其原项目仓库最近一次成功获取的最高 GitHub Star 数降序排列，不计后继项目或第三方镜像；同分保留原顺序，暂无数据排在最后。历史分类仅表示所介绍项目的状态，不判断作者在其他项目中的活跃度。时代先驱与站内内核与协议发展史一致，按各开发者代表作公开面世或主导核心演进的时间倒序（从现代向早期追溯）编排，以便读者优先了解当前主流生态所依赖的核心开发者，再逐步逆流溯源历史。时间先后仅用于提供技术史时间线，绝不代表名气、技术高下、贡献大小或任何形式的优劣排行。
