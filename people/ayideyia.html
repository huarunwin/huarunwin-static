Go + Wails 的原生极致：GUI-for-Cores 矩阵与轻量桌面代理革命

斩获逾 11,000 星标，以 Go+Wails 原生内核同构与 Vue 3 极简美学，终结 Electron 内存重负

第一幕 · 时代重压：Chromium 围城与极客的内存困局

2023 年底，桌面代理客户端生态正陷入一场无声的“资源膨胀危机”。随着跨平台前端技术的普及，主流图形客户端几乎无一例外地捆绑了完整的 Chromium 浏览器内核与 Node.js 运行时（Electron）；

即便仅仅是为了在后台静默托管几条代理规则或监控网络流量，客户端也往往瞬间占满数百兆、甚至动辄突破 1GB 的物理内存。在内存紧缺的轻薄笔记本、多任务开发机与嵌入式工作站上，风扇狂转与系统卡顿成为挥之不去的阴影；

为什么一个用 Go 语言编写的高性能底层代理核心，非要套上一层比核心自身庞大数十倍的重型外壳？社区中的极客用户都在苦苦寻求一个真正轻盈、纯粹的原生解决方案。[1][4]

第二幕 · 破局立项：风暴废墟中的 Go + Wails 宣言

2023 年 11 月初，Clash 核心与多款主流 GUI 突遭停更风波，社区面临前所未有的阵痛与真空。

注册 GitHub 不久的开发者 Ayideyia（阿伊的伊啊），敏锐地看到了底层架构重整的历史机遇。既然底层 Mihomo 与 sing-box 核心皆为 Go 语言的原生产物，为何不以 Go 为桥梁，打造一套原生契合的桌面骨架？

2023 年 11 月 25 日，Ayideyia 在代码库提交了初始提交，GUI.for.Clash 横空出世：

「first commit」

他毅然采用基于 Go 语言的现代跨平台框架 Wails v2，前端利用操作系统原生 Webview（Windows WebView2 / macOS WebKit）驱动 Vue 3 极简界面。短短两天后的 11 月 27 日，v1.0.1 闪电发布，宣告了“30MB 内存占用”的轻量化革命降临。[7][1][9]

第三幕 · 同构之美：进程零损耗与管道自愈

Ayideyia 的技术突破，在于充分挖掘了图形外壳与代理内核“同构”的天然优势。

传统的代理 GUI 往往依赖外部 shell 脚本拉起核心，再通过脆弱的本地 HTTP API 进行跨进程轮询，极其容易发生僵尸进程残留、IPC 丢包与内存泄漏；

Ayideyia 利用 Go 语言原生的 Channel（通道）、Goroutine（协程）与系统信号处理，在 Wails 进程内部构建了一条极速管道。内核的启动、重置、日志采集与毫秒级延迟测速，如同在同一神经系统内无缝传导；

面对海量并发连接与日志冲刷，应用不仅毫无卡顿，更拥有坚固的“免守护自愈机制”，彻底根除了桌面代理客户端长期存在的后台假死顽疾。[1][4]

第四幕 · 矩阵诞生：GUI.for.SingBox 与多核宇宙

随着 sing-box 在开源社区的强势崛起，其强大的规则集与实验性协议（Hysteria、TUIC）吸引了大量目光，但复杂的 JSON 配置语法让无数普通用户望而却步；

2024 年 1 月 4 日，Ayideyia 顺势成立开源组织 GUI-for-Cores，并在两天后的 1 月 6 日正式开源 GUI.for.SingBox：

「gui.for.singbox init」

针对 sing-box 的配置痛点，Ayideyia 设计了革命性的可视化配置生成器、出站节点拓扑编辑器与规则集（Rule-set）一键管理，让新手无需手写繁复的 JSON 即可驾驭次世代协议；

随后，GUI.for.Xray 与 Hotkey-API-Bridge 等组件相继补齐，GUI-for-Cores 从单一客户端蜕变为覆盖主流核心的完整生态矩阵。[8][2][3]

第五幕 · 插件中枢：Plugin-Hub 与全平台原生治理

Ayideyia 并不满足于做一款静态的界面，而是致力于将其打造成高度开放的极客控制中枢。

他主导推出了 Plugin-Hub 插件仓库，允许开发者与用户通过标准 JavaScript 脚本动态干预与覆写内存中的配置结构，无需重启客户端即可实现进阶分流与订阅清洗；

在跨操作系统底层适配的深水区，Ayideyia 对 Linux 桌面环境进行了堪称典范的原生抹平：从 GNOME、KDE 到 Cinnamon、Deepin，系统代理与 TUN 虚拟网卡无需用户频繁提权即可自动生效；

与此同时，项目实施了严苛的安全准入机制：内核二进制下载强制 SHA-256 完整性核验，并在官方文档中三令五申告诫用户远离第三方篡改渠道，守护开源分发的安全底线。[5][10][4]

第六幕 · 时代余响：万星长青与极简主义信仰

历经数年如一日的高频迭代与千次 commit 打磨，GUI-for-Cores 家族在 GitHub 上斩获了超过 11,000 颗星标，其中 GUI.for.SingBox 更是收获超 8,100 颗星标，稳居全球 sing-box 桌面生态的前列。

Ayideyia 的作品证明了一个朴素而深刻的真理：优秀的软件不需要依靠庞大臃肿的运行时去堆砌华丽，克制、纯粹与对性能的极致敬畏，同样能打动数以万计的用户；

在无数追求极致响应的极客桌面上，那个静静卧在系统托盘、占用几十兆内存却举重若轻的优雅图标，正无声地诉说着一段关于技术执着与极简主义的开源赞歌。[3][2][1]

Ayideyia 说明节点美化插件清空本地订阅的原因及修复

Ayideyia 在 Plugin-Hub #115 中说明：本地文件订阅的保存路径与源文件相同时，客户端不回写节点，但列表名称已被美化，二者不一致可导致「编辑节点」保存时清空源文件；手动运行插件直接改写订阅记录也会造成不一致。作者称「美化节点名称」v5.0.5 已修复：手动运行改走客户端订阅更新流程，保存路径等于源文件时跳过美化并提示。建议给本地订阅设置单独保存路径，以保持源文件不变并正常美化。
