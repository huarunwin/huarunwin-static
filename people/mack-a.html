极客终端的八合一工具箱：mack-a 与 v2ray-agent

主导开发与长期维护 vasma 命令行多协议综合部署管理脚本

极简终端哲学的诞生

2019 年 11 月，mack-a 在 GitHub 发布了 v2ray-agent 脚本。在 Web 管理面板渐成主流的时期，他选择坚持纯命令行交互模式。

通过封装便捷的 vasma 指令与纯文本菜单，他让服务器管理员无需安装额外数据库或 Web 服务容器，仅凭 SSH 终端即可快速完成全套代理服务初始化。[1][2]

八合一与双核心融合

随着代理技术从单一 V2Ray 演进到 Xray 与 sing-box 并存，mack-a 紧跟生态变化，重构了底层协议模板引擎。

脚本实现了多端口复用、TLS 证书自动申请与无感续订、分流路由与多种常见客户端订阅格式的输出，将复杂的配置过程降维为几项简单的菜单选择。[2][3]

跨越七年的持续维护

截至 2026 年 9 月，mack-a 保持着高频维护状态，项目版本迭代至 v3.5.25，兼容主流 Linux 发行版（Debian、Ubuntu、CentOS 与 Alpine）。

他在文档中持续提醒用户注意测试参数与证书下载安全性，展现出务实、严谨的开源极客作风。[4][2]
