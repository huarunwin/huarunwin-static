Mint Ryu：Mintyx 的个人自托管面板与桌面部署器

围绕个人与亲友共享线路，把服务器部署、访客配额和出口链放进同一面板

个人面板的起点：把部署与第一条线路连起来

Mintyx 当前保留的根提交于 2026 年 11 月 22 日以“feat: start MintYX as an independent Xray panel”为题，实际 GitHub 作者账号为 Link2theWorld。提交和随后保留的源码展示了单管理员面板、Xray 配置及本地部署器；这只能确定可见项目历史的起点，不代表开发者此前没有相关工作。

README 将项目介绍为“一个人用的 Xray 面板，带一键部署器”。用户在自己的电脑上填写 SSH 连接信息，部署器上传面板并配置服务；管理面板默认监听服务器的 127.0.0.1:8088，通过 SSH 隧道访问。Windows 和 macOS 出现在部署器下载列表，实际面板环境仍是使用 systemd 的 64 位 Linux。[1][6][7]

访客与配额：月度重置不替代管理员的手动停用

11 月 22 日的功能提交把界面中的“客户”改称“访客”，说明使用者是管理者的亲友。配额从一次性总量扩展为可选的月度周期，重置日可以设为每月 1 至 31 日，短月份使用月末。源码区分因额度耗尽而暂停与管理员手动停用：新周期可解除前者，保留后者。

同一提交补充管理员密码重置命令。提交说明指出密码只在部署时展示一次，丢失后不应以清空数据库为代价恢复访问；重置记录审计，并让旧密码对应的内存会话失效。这些是已公开的实现取舍，不能替代独立安全审计。[3][8]

出口链与本机记录：把转发路径和观测边界展示出来

Mintyx 将访客、入站线路、出口代理和互联网放入可视化线路图，线路可经一组出口转发。对应提交同时包含出口链接解析、配置生成和路由图实现；这建立的是面板与 Xray 的集成关系，不把 Xray 内核或相关协议的原创贡献归给面板维护者。

攻击页从本机 sshd journal 与 Xray 输出汇总来源，来源记录在最后出现三十天后清理。RDAP 查询默认关闭，启用后注册机构会看到被查询 IP 与服务器地址。连通性检测也默认关闭，启用时使用 Globalping，后者会获得服务器地址；Hysteria2 的 UDP 端口不能由该检测直接验证。生成举报信只提供草稿，由用户决定发送。[3][2][8]

跨平台部署器与公开技术入口

北京时间 11 月 23 日的构建提交把部署器整理为 Windows、macOS 和 Linux 下载，并用 lipo 合并 macOS 两种 CPU 架构。v0.1.0 的 Release 附带这三类文件与 SHA256SUMS.txt；服务器面板的 amd64、arm64 程序由构建脚本嵌入部署器。Release 发布账号是 github-actions[bot]，与代码提交署名分别记录。

个人 README 使用 Mint Ryu 署名，介绍 Windows 桌面软件、实时 AI 语音和音频插件方向，并明确链接 mintryu.com、X 的 Ryusoohow 账号与 YouTube 频道。fand.dev 也展示相同的公开 X 入口，作为另一处个人网站来源；其中的旧 GitHub 地址不足以证明账号更名。[4][5][9][10][11]
