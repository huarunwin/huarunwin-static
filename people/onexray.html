yiguodev：OneXray 按后端区分 Windows DNS 处理，保留 WFP 防泄漏

OneXray 找到桌面 Core wrapper 与 Xray 原生 Windows TUN 的 DNS resolver 重叠配置。待合并的 #269 让 EXE/Wintun 使用 -set-dns=false、由 Xray 处理解析，Microsoft Store/UWP 保持 -set-dns=true，并保留默认 WFP DNS 防泄漏；Windows x64 与定向 CLI/App 测试通过，但报告设备上的完整故障尚未复现，发布后仍需端到端确认。

OneXray：HTTPS 转发代理下的 UDP DNS 已改用 TCP 解析并完成验证

yiguodev 说明，Xray HTTP outbound 不承载 UDP，导致 HTTPS forward proxy 下默认 UDP DNS resolver 失败；OneXray 已在 dev-26.11.3-1 将默认解析器改为 tcp://8.8.8.8、为转发记录使用 rewriteNetwork: tcp，并让高级路由模板通过 proxy balancer 转发非 A/AAAA 查询。作者称已在实体 iPhone 和 Core 层完成 A、AAAA、TXT 检…（节选）

OneXray 作者：开发分支已让 Android 快捷设置磁贴长按打开应用

在 OneXray 的 Android 快捷设置需求中，yiguodev 表示，dev-26.11.2-3 分支的提交 c1d4e83c 已使长按磁贴打开 OneXray，而非应用信息页。单击切换 VPN 的行为不变，应用的启动连接偏好仍被遵守。他称已在 Android 模拟器上分别验证应用运行中及进程停止后的长按行为。
