数据与隐私

隐私政策

本站尽量减少收集的数据，不尝试识别访客的真实身份，也不记录代理节点、订阅地址或网络配置。

匿名访问统计

为了解页面、筛选和官方来源链接是否有帮助，本站通过自己的统计接口记录页面浏览、筛选与重置、排序、搜索、应用与外链点击、分享和纠错提交成功等事件。 Cloudflare Analytics Engine 记录经过校验的页面路径、页面类型、筛选条件、结果数量、经过清理的站内搜索词、外部来源域名和设备类别。 服务器在后台将同一事件及这些统计字段转发到 Google Analytics 4 和 PostHog，转发时还包含页面标题。 纠错统计只记录提交成功、对应资料路径和允许的类别，不发送纠错正文、证据、补充说明或记录编号。

上述页面与交互统计不使用 Cookie，不保存持久访客 ID、IP 地址、完整 User-Agent、精确位置或浏览器指纹。启用 Global Privacy Control 或 Do Not Track 时不会发送这些事件。当前标签页的临时随机标识保存在 sessionStorage，仅用于统计会话；Google 接收由它转换的数字客户端 ID，PostHog 接收由独立命名空间和单向摘要派生的统计标识，不与账号或机场购买会话关联。 PostHog 不创建人物画像，不启用浏览器自动采集或会话回放，并关闭自动 IP 地区推断。 Cloudflare 数据保留三个月，Google 和 PostHog 数据分别按既有属性和项目的设置留存。统计由服务器转发，任一通道失败或超时不会阻塞浏览。

机场购买入口统计

点击机场购买按钮并成功跳转时，本站使用 Cloudflare Analytics Engine 单独记录机场 ID、点击时间、随机事件 ID、按钮来源、目标网站域名、可获得的来源域名和站内来源页、设备类别、浏览器及操作系统类别、首选语言、粗粒度国家与行政区代码、时区和 Cloudflare 边缘机房代码。 可用时记录自动化访问分类及机器人评分；这些信息可能缺失或因代理网络而不准确。

为关联同一浏览器会话点击过的机场，本站在首次此类点击时设置仅限本站、Secure、HttpOnly、SameSite=Lax 的随机会话 Cookie。Cookie 不设置持久有效期，服务器最多认可二十四小时，不与后台账号或其他页面统计标识关联。 它不能识别姓名、账号或跨设备的真实用户；关闭或恢复浏览器、清除或禁用 Cookie 都可能改变统计结果。

此统计不保存 IP 地址、完整 User-Agent、精确位置、完整推广地址、URL 查询参数、其他 Cookie 或登录凭据。 为比较统计结果，本站会在服务器后台将同一点击的随机事件 ID、机场 ID、按钮来源、目标与来源域名、设备类别、粗粒度地区及自动化分类等统计字段转发到既有 Google Analytics 4 属性和 PostHog 项目；不会发送访客 IP、完整 User-Agent 或原始会话 Cookie。 Google 使用由购买会话标识转换的独立数字客户端 ID；PostHog 使用购买专属命名空间和单向摘要派生的统计标识，不创建人物画像或自动推断 IP 地区。两者均不关联本站其他页面的统计标识，也不代表真实账号。 启用 Global Privacy Control 或 Do Not Track 时不写入事件，也不设置统计 Cookie。HEAD、预取、失败跳转和本地预览不计入点击；已识别的自动化访问不设置访客标识。 Cloudflare 数据保留三个月，Google 和 PostHog 数据分别按既有属性和项目的设置留存。三条通道均在后台写入，统计失败或超时不影响跳转。入口点击不代表完成注册、付款或推广佣金入账。

资料纠错

提交纠错时会保存应用、人物或机场的标识与名称，或通用纠错主题，以及纠错类型、原信息、建议内容、证据链接、补充说明、提交时间和处理状态。表单不要求姓名、邮箱、电话或其他联系方式，请勿填写账号、密码、订阅链接或其他个人敏感信息。

纠错记录保存在站点的 MySQL 数据库，仅用于核验和维护目录。新纠错的内容和记录编号会发送至站点的私有 Telegram 运维群，便于管理员处理。AI 已核查、已处理或忽略的记录原则上最多保留十二个月，用于避免重复处理和审计资料来源。

后台登录

管理后台使用仅限后台子域名的 HttpOnly、SameSite=Strict 会话 Cookie，会话最长三十天。密码和会话密钥只保存在 Cloudflare Secret，不发送到主站页面，也不会写入公开代码。

为防止暴力尝试，后台在站点的 MySQL 数据库保存经过单向签名的临时客户端标识、失败次数和封禁时间；不保存原始 IP 地址。

普通账号

注册账号时会保存你主动提供的昵称、邮箱、经过密码哈希处理的密码凭据，以及账号创建和更新时间。邮箱只用于登录、验证邮箱和找回密码；验证和重置链接是一次性、限时令牌，本站只保存其必要的摘要记录。

登录会话保存在 Cloudflare D1，并通过仅限本站的 Secure、HttpOnly、SameSite=Lax 会话 Cookie 识别。认证服务不会把原始 IP 地址、完整 User-Agent、账号邮箱或会话标识写入匿名 Analytics Engine、Google Analytics 4、PostHog 或机场购买统计。登录接口的限流键使用不可逆摘要，避免把原始网络标识保存到数据库。

验证和找回密码邮件由 Cloudflare Email Service 代为发送，发件地址为 noreply@huarun.win。Cloudflare 会按其服务条款和隐私政策处理邮件投递所需的数据。过期令牌不会再被接受，未使用的验证记录会按维护策略清理；为防止滥用而保留的限流摘要会在短期内清理。账号删除入口和数据导出流程上线前，会在本页补充对应说明。

外部网站与广告

点击应用官网、代码仓库、商店或社区后，将适用对应网站的隐私规则。本站目前未启用第三方广告；若未来接入会使用 Cookie 或个性化广告的服务，会在启用前更新本政策并提供必要的同意管理。

安全与变更

公开接口使用同源校验、字段白名单、长度限制和反垃圾字段；管理接口要求有效会话并禁止缓存。数据范围或第三方服务发生实质变化时，本页会同步更新。
