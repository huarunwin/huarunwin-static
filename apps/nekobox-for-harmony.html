项目身份说明

独立的鸿蒙客户端，不是 NekoBox for Android 原项目的官方鸿蒙发行。

由 xiaoli8571 维护，参考 Android NekoBox 架构思路。包名 com.nekobox.app，桌面名称 NekoBox；与本站 Android 和桌面 NekoBox 条目分开收录。

官方变更日志

2.1.8（测速与首页 UI 修复版，release 模式构建）：

测速：
- 默认测速网址改为 HTTP 204（gstatic），与 Clash 系客户端同口径，数值不再因含目标站 TLS 握手而偏高（旧默认值自动迁移，自定义网址不受影响）
- 批量测速提速：超时失败的节点不再重试（死节点收尾时间减半）；并发默认 5→10，上限放宽到 32（可在设置里调）
- 大订阅测速时不再刷爆 UI（延迟结果 300ms 合并刷新），修复测速中界面卡死、点击无反应
- 内核桥接调用加兜底超时，测速标志不会再被挂死的调用永久卡住
- 每轮测速前自动清理上一轮残留会话，杜绝整组假红
- 内核测速起不来回退 TCPing 时会明确提示「测速已降级」
- 测速只测当前选中分组的节点（分组条长按仍可测指定分组）

首页 UI：
- 搜索框移入顶栏（动作按钮行与规则行之间），点搜索图标自动弹键盘；再点一次搜索图标或「取消」均可关闭
- 修复搜索框与状态栏时间重叠的问题
- 修复搜索/测速时订阅分组条遮挡节点卡片的问题
- 顶栏各行间距统一（与节点卡间距一致）
- 底部速率/状态面板加毛玻璃背景，不再与列表文字重叠

- Clash YAML 订阅的 SOCKS 代理(type: socks5,Clash 惯例写法)此前会被静默丢弃,现已正常导入;分享链接(socks5://)、手动新建、sing-box JSON 本就支持

附件为未签名 HAP（release 模式构建，versionCode 2100008）。
