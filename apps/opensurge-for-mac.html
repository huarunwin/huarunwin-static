官方变更日志

简体中文 · English

v0.3 series codename: Verdilion

v0.3.3 主要变化（相对 v0.3.2）

v0.3.3 升级 Mihomo 内核，改善网关异常后的恢复体验，新增可选的域名嗅探与配置来源删除，并让日常操作反馈和连接查看更清晰。

- 升级 Mihomo 内核至 1.19.33：采用 OpenSurge-patched Mihomo 1.19.33-opensurge.1，纳入上游 TLS、DoH 查询及配置重载时 fake-IP 分配状态的修复，同时保留 OpenSurge 的下游 IPv6 接入与本机 IPv6 独立配置能力。见上游更新说明。
- 修复 DNS 恢复错误导致网关无法继续启动的问题：系统 DNS 原设置独立保存，停止、回滚和重启代理引擎时按备份恢复。原网络服务消失后跳过旧记录，恢复失败时保留提醒与备份，并继续清理其他网关资源。（PR #109；#107 — Thanks @yizao）
- 配置有误时仍可执行恢复操作：停止网关、DHCP 恢复和状态诊断不再被无关的部署参数或未应用策略阻断。租约读取失败单独提示；仅重启代理引擎时，也不再要求无关的 DHCP 依赖完整可用。应用新配置仍执行完整校验。见 PR #109。
- 新增可选的 Sniffer 域名嗅探：在“网络设置 → 高级 Mihomo / DNS 设置”中按需启用，默认关闭。当外部加密 DNS 或缓存的真实 IP 导致连接缺少域名映射时，可从 HTTP Host、TLS/QUIC 握手中补充可识别的域名供规则匹配。连接页同步展示嗅探域名，原始目标 IP 与设备规则优先级保持不变。（PR #111；#110 — Thanks @yizao）
- 支持删除不再使用的代理与规则源：来源卡片新增“删除来源”，清理列表记录、托管历史快照和保存的订阅地址；即使文件已在 Finder 中删除，也能移除残留记录。原始 YAML、导出副本和全局附加配置保留。当前选中或仍被引用的来源需先解除使用，删除操作不会重载网关。（#105 — Thanks @Tommytalk）
- 统一操作通知与配置检查反馈：导入、刷新、保存和网络操作使用悬浮通知，减少页面跳动。成功提示自动收起，错误保留供查看、复制和关闭；多条配置问题汇总为可展开摘要，DNS 恢复等子步骤的提醒也会独立保留。见 PR #108、PR #109。
- 改善网关停止时的连接页与本机策略布局：正常停止后显示“尚未启动网络模式”和网络设置入口，保留已知设备信息；重新启动后刷新连接，避免沿用上次运行的数据。本机出口与“仅影响本机”标记的对齐及窄屏布局也更清晰。
- 滚动连接列表时随时切换设备：设备筛选列表保持可见，较长列表可独立滚动；手机等窄屏保留横向滑动选择。设备页“前往网络设置”按钮同步统一外观与间距。

升级说明

- Sniffer 默认关闭；未配置该选项的旧配置保持关闭，已有设置会保留，导入订阅不会覆盖该开关。修改时需停止网关，保存网络配置后重新启动；它不能保证识别 ECH 隐藏的真实域名或其他没有可识别域名的流量。
- Mac 系统 DNS 按接管前备份恢复；接管期间由用户或其他软件修改的 DNS 也会被原备份替换。恢复失败的提醒和已保存的备份会保留供后续重试。
- 下游 IPv6 仍为实验性功能。本次内核升级已在 Apple Silicon 与受控虚拟客户端环境完成基础网络、真实 TUN 和三个下游 IPv6 拓扑的回归；这些结果不覆盖物理客户端、真实 Tailnet 或 Intel 硬件。完整范围见网络回归记录。
- 完整变更：v0.3.2...v0.3.3。
