官方变更日志

Sudodroid v0.3.3

A ground-up rebuild of the interface and the way the app talks to the Sudoku core, now on the official Sudoku v0.5.2.0 and hev-socks5-tunnel 2.19.1.

Core and tunnel

- Component：Version
- Sudoku core：v0.5.2.0 (56ce6f1), wire protocol unchanged and interoperable with v0.5.1 / v0.5.0 servers
- hev-socks5-tunnel：2.19.1: lower memory use (small-packet compaction, idle heap release), faster TCP/UDP paths, UDP fixes

Also in this release (from the release candidates)

- Fixed app UDP traffic (QUIC, voice calls) through the tunnel.
- sudoku:// short links now keep the node name, on import and on copy.
- Fixed idle battery drain.
- The app module no longer pins an NDK version; the NDK is needed only to build the Go AAR.
