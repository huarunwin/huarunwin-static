官方变更日志

OwnBox for Android v26.11.8 正式版

【新增功能】
1. 智能分流升级为应用、域名与 IP 三维国内外自动分流引擎。
2. 核心设置新增智能分流国家与地区选择，支持八大地区即时热生效。
3. 侧边栏新增代理模式控制面板，支持智能分流与全局模式一键切换及状态直达。
4. 规则资产更新支持 GitHub 仓库主页填入、热门规则源一键填入和本地规则集导入多选。
5. 主页新增节点自定义拖拽重排、批量调整、恢复默认顺序与撤销能力。
6. 网络诊断系统重构为极简看板与动态分组流线型卡片架构。
7. 主页置顶机场资产卡片重构为现代仪表盘排版，支持快捷更新与精准流量展示。
8. 新增紧凑配置行与紧凑分组卡片外观选项。
9. 全规格桌面小组件升级为 OwnBox 官方 Logo 与纸飞机连接按钮。
10. 4×2 小组件新增自适应状态药丸徽章，2×2 小组件优化“换节点”文案与边距。

【问题修复】
1. 修复节点测速与正式环境 DNS 解析冲突导致的断网问题。
2. 修复测速偶发 DNS 解析失败、连接超时、假超时和重试判定异常。
3. 修复启动连接服务时偶发 DNS 规则报错。
4. 修复覆盖升级后存量节点失效、需重新更新订阅的问题。
5. 修复双排节点流量统计退出丢失及节点切换、连接时全量闪烁问题。
6. 增强协议自动兼容桥接与全协议出站安全校验，修复核心解码和服务初始化异常。
7. 增强 sing-box 订阅解析兼容性，并支持 gVisor 协议栈自动降级。
8. 修复策略组重复节点/空列表导致内核启动失败。
9. 修复 TUN System 协议栈在非 Root 设备上的兼容异常。
10. 修复 ShadowTLS、Juicity 缺少 TLS 配置及链接解析缺失问题。
11. 修复 AmneziaWG 混淆参数丢失和 VLESS + XHTTP 引擎崩溃问题。
12. 修复 Clash 订阅中 Juicity、ShadowTLS 解析不完整问题。
13. 修复 UI 生命周期 API 过时、编译警告和多语言资源问题。
14. 修复分应用代理重载生效、国内直连路由异常和海外 QUIC 延迟问题。
15. 修复智能分流模式下分应用代理勾选的国内应用被强制直连问题。
16. 修复 Google Play 商店下载/更新卡“等待中”或一直转圈问题。
17. 回滚未经验证的实验性底层改动，恢复核心服务稳定基线。
18. 修复展开侧边栏时按返回键直接退出软件的问题。
19. 修复选择节点等弹窗底部按钮与手机三键导航栏重叠问题。
20. 修复进入用户界面设置时触发的类型转换闪退。
21. 修复分组设置、节点编辑及高级算法等开关无响应或无法切换问题。
22. 修复设置与选项弹窗右侧异常显示小“v”字符及双层圆角冲突。
23. 修复“选择主题颜色”白色选项与分隔线穿透重叠及形变。
24. 修复左上角侧边栏按钮图标被强制覆盖为纯黑色。
25. 修复底栏位移动画原生状态死锁及按钮异常消失问题。
26. 修复弹出菜单点击子项或背景遮罩导致阴影丢失问题。
27. 修复大界面设置下顶栏胶囊遮挡、覆盖标题文字问题。
28. 修复节点二维码分享界面复制按钮文字与图标看不清问题。
29. 修复分组切换栏首末胶囊边缘包裹间隙与几何留白问题。
30. 修复主界面顶栏与分组切换栏交界处背景断层问题。

【体验优化】
1. 顶栏升级为左右悬浮胶囊岛布局，并支持主题动态变色和搜索/排序状态自适应。
2. 顶栏胶囊统一 38dp 等高、8dp 边距、正圆侧边栏按钮和 5 键对称布局。
3. 全面适配 75%—125% 界面缩放，修复重叠、乱码与错位。
4. 侧边栏优化行高、圆角、间距和代理模式胶囊高度，十项功能免滑动展示。
5. 侧边栏选中项、代理模式胶囊及路由状态卡片全面跟随主题色。
6. 分组切换栏升级为双层胶囊架构，并与下方节点卡片垂直对齐。
7. 右上角功能菜单升级 24dp 大圆角、锚点缩放与丝滑过渡动效。
8. 全量弹出菜单统一柔和暗色遮罩、平滑过渡和防抖交互。
9. 节点操作改为长按卡片呼出，并新增触感反馈与靠右弹出定位。
10. 底栏开关联动优化为开启时常驻连接按钮、关闭时仅主页展示。
11. 设置页重构为分级卡片导航，支持一屏尽览和折叠展开。
12. 优化设置页类目间距、卡片内边距和类目小标题呼吸留白。
13. 下拉选项弹窗统一 24dp 圆角，并适配深浅色与纯黑主题。
14. 全面规范并补齐顶栏、侧边栏、设置页及各设置页面（含路由）图标，统一采用 Solar Linear 风格与深石墨灰配色。
15. 主页资产卡片、分组列表卡片优化流量进度、到期时间与紧凑排版。
16. 网络诊断服务图标升级为官方规范矢量图形，并优化分类筛选与单项重测。
17. 桌面小组件新增 800ms 防抖与 3.5 秒流量刷新节流，降低耗电。
18. 优化订阅 User-Agent 下拉样式、节点过滤正则示例和规则集管理体验。
