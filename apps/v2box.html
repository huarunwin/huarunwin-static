官方变更日志

Version 10.1.9

• Implement Kill Switch support.
• Implement Fake DNS support.
• Subscription providers can now lock subscriptions, set how often they auto-update, and add Support and Website links to the subscription menu.
• Fixed several issues with LAN proxy sharing, including connections being refused over Personal Hotspot, settings not applying until reconnect, and traffic dropping when more than one device was connected.
• Fixed WireGuard configurations with a domain name endpoint failing to connect.
• Port 53 routing rules now match the values shown on the DNS screen.
• Fixed a crash when the app was backgrounded while backing up its data.
• Fragment masks now keep their lengths and delays instead of dropping them on import.
• Fixed ping failing on JSON configs while the tunnel interface is running.
• Freedom outbounds keep their domain strategy, and configs using a routing balancer strategy now load.
• Added support for Xray's simplified outbound format, so those configs import with their server and port.
• Hysteria2 configurations are no longer affected by the SNI spoof redirect.
• Configs carrying unexpected values in outbound settings now load instead of failing outright.
• Share links keep values containing "=", such as certificate pins and ECH keys.
• vmess share links now carry the certificate name and pin options.
• WireGuard configurations support FinalMask from share links, and the editor.
• Added a FinalMask field to Hysteria2 configurations.
• A custom Hysteria2 FinalMask now keeps obfuscation, bandwidth, and port hopping settings.
• Subscriptions containing v2rayn:// links now import.
