官方变更日志

What's new

- A new look. The Pixel design is now the default: the core in the middle is the only connect button, and tapping the place, ping or IP opens the connection details right on the card. Settings are rebuilt in Material 3 Expressive, with colour styles, contrast levels and three app designs (Pixel, Portal and the old one) to pick from.
- Tor and Psiphon in VPN mode on Linux. The whole system goes through them now, not only apps that follow the system proxy.
- Chains on desktop. Tor or Psiphon over an Xray chain, and a multi-hop chain as either side of a chain, now connect, also in VPN mode.
- MasterDNS on desktop.
- Routing rules work on desktop. The geo files are downloaded automatically, and Settings › Assets can download or import them.
- Windows VPN mode uses hev by default. zeptun is still there to pick in Settings › VPN.
- Tor on new phones. obfs4, Conjure and Snowflake are built for every Android ABI with 16 KB pages, and x86_64 now has Conjure too.

Fixes

- AmneziaWG configs with custom headers connected but carried no data.
- Export all did nothing on Android when the list was long.
- A locked routing rule could not be unlocked. Tap it to unlock it.
- The buttons of the welcome screens sat under the navigation bar on some phones.
- vmess:// links with a name after # did not import.
- Settings jumped to the end of the list after changing an option.
- A failed connection looked like a normal disconnect. The error and its reason now stay on screen, for example when the local port is already in use.
- Tor with bridges that cannot use a proxy is now refused in a chain instead of connecting around it.
- Snowflake's default rendezvous is now cdn77, because amp no longer answered.
- IKEv2 on Linux failed with NetworkManager's strongSwan plugin.

应用简介

支持订阅与配置导入、链式代理、自动选路和规则分流。

另含 Psiphon、zeddns、OpenConnect 等引擎。支持 Android 7+、Windows 10+、macOS 12+ 与 Linux；各平台引擎和功能存在差异。部分连接方式需自行配置服务器或订阅，Android 的 SNI spoofing 需要 Root。macOS 发行包未公证，首次启动按官方说明操作。Android 已在 Google Play 上架，也可从 GitHub 获取 APK；两个渠道的签名不同，切换前须备份配置。

安装方式、版本要求与最新维护状态请以项目官网或应用商店页面为准。
