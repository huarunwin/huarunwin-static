官方变更日志

What's new

- Bento is the new default design. Home is a set of tiles for the connection, speed, session, map and the active subscription's usage and days left. Seven extra colourful palettes come in light and dark, and the slide-to-connect knob now rides along the wave.
- A new setup. Pick your language and country (suggested from the SIM, the network and the language) and the country's routing rules come with it. Everyone sees it once after this update; your own routing rules stay unless you turn on "Apply rules".
- IP details page with a DNS leak check, and a speed test.
- The widget is rebuilt in three sizes, with a connect toggle.
- Spanish. Closes #72.
- Xray-core v26.10.29 and sing-box v1.14.4, with MASQUE, Cloudflare WARP, XDRIVE and system certificates. Shared protocols can run on sing-box per server, and finalmask can be edited on every protocol.
- Proxy mode for MasterDNS, Psiphon, Tor, SSH and the DNS tunnels on Android, not only VPN mode.
- The Vault locks every engine, subscriptions can use the sing-box user agent, and a per-country local DNS is available (off unless you turn it on).
- Auto-select can skip chosen countries. Closes #69, #78, #79.
- One preset for a whole subscription. Closes #39.
- Windows installs updates from inside the app (closes #62), hev is available on macOS (closes #54), and the app shows up in the Android TV launcher (closes #77).
- A password for the local SOCKS port, a rebuild when the network changes, and a guard against DNS block pages.

Fixes

- WireGuard with an IPv6 address opened only some sites on servers without working IPv6.
- Split tunnels dropped everything else. WireGuard configs with limited AllowedIPs and OpenVPN servers that push only some routes now send the rest of the traffic directly, the way their own clients do. Fixes #37 and #86.
- AmneziaWG 3.1 configs (header protection, random trailers) did not connect.
- WireGuard and AmneziaWG without an MTU were slow or stalled on many networks. They now use 1280 when the config has no MTU.
- WireGuard servers with a hostname, such as WARP or a dynamic DNS name, did not connect in desktop proxy mode.
- Connections over OpenVPN and other sing-box protocols stayed open after the server had closed them.
- .ovpn files: client-side redirect-gateway, route, route-ipv6 and pull-filter are now read.
- WireGuard imports: several Address or AllowedIPs lines, a second [Peer], keepalive ranges, DNS with a port and wg:// links from other apps.
- Hostnames on desktop were resolved outside the tunnel.
- The VPN crashed on Android 7 and 8.
- USB tethering was slow with zeptun.
- Linux DNS leaked around the tunnel on systems without systemd-resolved.
- Windows VPN mode stopped with IPv6 turned off, and the tunnel MTU is back to 1500 on Linux and Windows.
- The chosen proxy port changed after a reconnect. Closes #83.
- The Linux app quit when there was no system tray. Closes #81.
- Picking a locked config in the Vault did not move the live connection to it.
- Desktop lists and sheets scroll by dragging, and the desktop app uses less CPU and memory.

应用介绍

基于 Xray、sing-box 等多引擎的跨平台代理客户端，支持订阅与配置导入、链式代理、自动选路和规则分流。

另含 Psiphon、zeddns、OpenConnect 等引擎。支持 Android 7+、Windows 10+、macOS 12+ 与 Linux；各平台引擎和功能存在差异。部分连接方式需自行配置服务器或订阅，Android 的 SNI spoofing 需要 Root。macOS 发行包未公证，首次启动按官方说明操作。Android 已在 Google Play 上架，也可从 GitHub 获取 APK；两个渠道的签名不同，切换前须备份配置。

安装方式、版本要求与最新维护状态请以项目官网或应用商店页面为准。
