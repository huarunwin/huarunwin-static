Swell Proxy v4.2.0 更新日志 (What's New in v4.2.0)

✨ 新增功能 (New Features)

1. 实验性双核心架构：sing-box + Shoes (Rust 轻量核心)
- 在 「设置 -> 关于与内核 -> 内核与引导管理」 中新增 「代理内核引擎（实验性）」 切换项，默认保持稳定全功能的 sing-box，对普通用户零打扰。
- 安装包 0 体积膨胀（按需获取）：首次切换至 Shoes 时支持 一键在线下载（未开代理时自动回退 GitHub 加速镜像）或 手动导入本地 shoes.exe；核心文件独立存放于 %LocalAppData%\SwellProxy\bin\shoes.exe，客户端升级不会丢失，并与 sing-box 共享同一份本地 .srs 规则集。
- 纯手写零反射 YAML 生成与自愈预检：原生支持 VLESS（TCP / WS / TLS / Reality / Vision）、VMess、Trojan、Shadowsocks（AEAD & 2022）、SOCKS5、HTTP(S)，自动适配新旧版本 Shoes 配置语法并在启动前执行 shoes check 预检。
- 无感自动借用回退：当选用 Shoes 但开启了 TUN 模式 / Tailscale、或切换到 自定义 JSON / 代理链 / ShadowTLS / Hysteria2 / TUIC / AnyTLS / WireGuard 等 sing-box 专属协议时，当次连接会自动无感借用 sing-box 运行并在首页横幅与日志中温和提示，切回兼容节点即自动恢复 Shoes。
- 复用全套原生监控界面：Shoes 通过 127.0.0.1:9090 接口直接驱动软件内置的仪表盘实时速率、活跃连接管理与网络拓扑图。

2. 原生 sing-box 自定义 JSON 配置导入与内置轻量编辑器
- 在 「节点管理」 页新增导入完整原生 sing-box JSON 配置文件及内置代码编辑弹窗（等宽字体、JSON 语法校验、一键格式化、文件导入/另存为）。
- 启动自定义配置时自动在内存中注入客户端所需的本地混合入站端口、控制接口与安全加固项，绝不篡改用户原始 JSON 内容；规则集等相对路径默认解析至 %LocalAppData%\SwellProxy\。

🐛 修复与优化 (Fixes & Improvements)
- 修复手动新建或编辑保存过的 Shadowsocks 节点因默认带有 ObfsType = "none" 而在 Shoes 模式下被误判回退的问题。
- 统一规范化 Shadowsocks 加密算法大小写与 SIP002 别名，自动清理 SS-2022 密钥首尾多余空白字符。
- 增强 SingboxApiClient 对不同内核 /connections 接口字段类型（端口数值/字符串、时间戳格式）的兼容性。
- 完整补齐所有新增功能的简体中文（zh-CN）与英文（en-US）双语本地化资源。
