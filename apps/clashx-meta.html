ClashX Meta 配置位置与流量接管

先确认项目和下载来源

ClashX Meta 是面向 Mac 的规则代理工具，官方 README 列出 Mihomo 内核和 TUN 支持。项目同时明确说明，不提供代理服务器，也没有独立官方网站；下载和问题反馈应从本页列出的 MetaCubeX 官方仓库进入。

ClashX、ClashX Pro 与 ClashX Meta 的名称相近，版本和发布入口不能互相代用。安装或升级前核对仓库、具体标签和附件，再保留当前配置副本。

配置文件应该放在哪里？

在本次核对的 v1.4.46 README 中，默认配置目录是 ~/.config/clash.meta，默认文件名为 config.yaml。自定义文件可以使用其他名称，再通过菜单的 Config 区域选择当前配置。仅把文件放入目录不代表已经切换到它。

官方对端口设置有单独说明：修改客户端生成的 config.yaml 后重新启动；自建或下载配置里的 General 设置会被忽略。出现“已经改了端口，但程序仍连到旧端口”时，应先确认修改的是哪个文件。

浏览器可用，终端仍不可用怎么办？

先区分系统代理与具体程序使用的代理。README 提供从菜单图标按 Option-Command-C 复制终端代理命令的方式；执行前查看命令中的地址和端口是否与当前客户端一致。系统代理可用不表示每个命令行工具都会自动采用它。

TUN 是另一种流量接管方式，不能修复无效节点或错误的 DNS、分流配置。建议先确认当前配置和节点，再核对程序是否使用系统代理，最后按 Mihomo 文档检查需要的接管方式；每次只改一个环节，方便回溯。
