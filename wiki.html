开源内核

Mihomo

Mihomo（曾称 Clash.Meta）是 MetaCubeX 维护的开源规则代理内核，延续 Dreamacro Clash 内核确立的规则分流路线。它用 YAML 连接规则、策略组、节点来源与 DNS：规则可指向具体节点、策略组或直连出口；指向策略组时，再由组内策略选择实际出口。通过 TUN 接入的系统流量也能沿用这套分流过程。

开源内核

sing-box

sing-box 是 SagerNet 独立实现的通用代理平台：同一份 JSON 配置可以组织入站、出站、DNS、规则路由、TUN 与 Endpoint。它适合需要在多种协议之间组合规则、统一透明接管和跨平台交付的场景；核心版本、官方客户端与第三方封装仍是不同发布物。

开源内核

Xray-core

Xray-core 是从 v2fly-core 特定提交分叉后独立演进的 Go 代理核心，围绕 VLESS、XTLS、REALITY 与 XHTTP 组织传输、安全、路由和透明接管。它适合需要 Project X 协议实现或细粒度入站/出站编排的部署；图形客户端是否开放这些字段必须另行核对。

开源内核

V2Ray

V2Ray（现由 V2Fly 维护）是较早把代理协议、传输、路由和二次开发组织成模块化平台的 Go 核心。它保留 VMess 等传统组件，也提供 VLESS、Shadowsocks、Trojan、DNS 和透明接管能力；今天的 V2Ray、V2Fly 与 Xray 是不同版本线，不能用“支持 V2Ray”替代具体核心版本。

开源内核

clash-rs

clash-rs 是 Rust 编写的规则驱动代理核心，采用接近 Mihomo 的 YAML 配置概念，同时保留自己的协议实现、功能开关和控制接口。它适合需要 TUN/TPROXY、远程节点与规则集加载、以及 Rust 交付的桌面或路由场景；“兼容模式”不等于与 Mihomo 的每个字段完全相同。

开源内核

meow-rs

meow-rs 是 Max Lv 维护的 Rust Mihomo 兼容内核，面向 meow 系列客户端。它保留 Clash/Mihomo 的规则、订阅和代理组模型，同时增加 dialer-proxy 链路诊断、持久化 logbook、REST API 和 TUN/TProxy 透明接管；README 明确它是 client-only 内核，不提供服务端功能。

开源内核

Clash

Clash 是 Dreamacro 开源的 Go 规则代理核心；本站当前链接指向 2023 年备份仓库与最后一条正式发行线，不把它与仍在演进的 Mihomo、clash-rs 或其他兼容实现合并。它适合用来理解“规则 + 策略组 + Fake-IP + 透明代理”这一早期统一模型。

开源内核

COW

COW 是一个面向浏览器和移动设备的 HTTP 代理服务器：它先尝试直连，识别失败后把目标交给父代理，并根据访问结果生成 PAC。它解决的是“按站点学习是否需要二级代理”，不是现代多协议核心的通用规则与 TUN 平台。

开源内核

GoAgent

GoAgent 是早期把本地 Python 代理与 Google App Engine 应用部署组合起来的代理工具。当前记录指向删库前抓取的第三方备份，便于理解“本地入口 + 云应用通道”的历史路线，不把备份当作仍在维护的官方发行版。

开源内核

Shadowsocks

Shadowsocks 原始 Python 实现把一个轻量加密隧道拆成本地客户端与服务端：本地程序接收 SOCKS5 流量，服务端以共享密码和加密方法转发 TCP/UDP。后续 Rust、C 和 Go 实现是独立项目，本页只记录原始仓库与 2.9.1 发行线。

开源内核

ShadowsocksR

ShadowsocksR 是独立维护的 Python 分支，在 Shadowsocks 的隧道基础上增加协议插件与混淆参数。它与 Shadowsocks 2022、Shadowsocks-rust 和原始 Shadowsocks 不是同一代码或版本线；当前仓库没有可核验的 GitHub Release。

开源内核

shadowsocks-libev

shadowsocks-libev（仓库已迁移为 shadowsocks-c）是面向 Linux、路由器与嵌入式设备的 C 语言 Shadowsocks 实现。它把 ss-local、ss-redir、ss-tproxy、ss-server 和 ss-manager 拆成轻量程序，适合系统级透明代理和资源受限环境。

开源内核

shadowsocks-rust

shadowsocks-rust 是 Shadowsocks 的 Rust 实现，同时提供 sslocal、ssserver、ssmanager、ssservice 和 ssurl。它把本地 SOCKS/HTTP/TUN/redir、服务器、多跳出站代理、DNS/FakeDNS 与容器/ Kubernetes 交付放进同一项目，但每项能力仍受 Cargo feature 与平台条件影响。

开源内核

go-shadowsocks2

go-shadowsocks2 是 Shadowsocks 官方组织维护的 Go 实现，重点提供 SOCKS5、UDP Associate、TCP/UDP tunnel、Linux/macOS redirect、SIP003 插件和重放攻击缓解。仓库没有可核验的 GitHub Release，本页以固定主分支源码和 README 能证明的能力为准。

开源内核

NaïveProxy

NaïveProxy 复用 Chromium 网络栈，通过标准 HTTPS/HTTP2 形态和应用前置把代理连接放进普通浏览器流量中。它适合已经有域名、证书和可路由 HTTP 前置的部署；服务端通常与 Caddy forwardproxy 或 HAProxy 配合，不能只下载客户端就得到完整服务。

开源内核

Trojan

Trojan 是 trojan-gfw 的 C++ 代理实现，把代理认证放进标准 TLS/HTTPS 服务形态，并在未通过认证时回落到普通 Web 服务。它回答的是“怎样让代理连接表现得像一个 HTTPS 服务”，与 Trojan-Go 的 Go 扩展实现分开记录。

开源内核

Trojan-Go

Trojan-Go 是使用 Go 编写的独立 Trojan 实现，兼容原版配置，同时增加多路复用、WebSocket/CDN 中转、路由、TProxy、MySQL 用户管理与流量统计。扩展字段改变兼容边界，使用原版 Trojan 客户端时只能依赖两者共有的基础协议。

开源内核

Hysteria

Hysteria 是基于定制 QUIC 的代理核心，面向高延迟、丢包链路和 HTTP/3 形态的抗干扰部署。当前仓库的 v2 系列与 Hysteria 1.x 是不同协议线；它同时提供 SOCKS5、HTTP、TCP/UDP 转发、Linux TProxy 和 TUN 等入口。

开源内核

dae

dae 是 Linux eBPF 高性能透明代理：它把连接捕获、直连旁路和流量分流尽可能放进内核路径，只有需要代理的流量进入用户态转发。它适合 Linux 主机、网关和路由器，不是跨平台 GUI 核心，也不等于 v2rayA 的当前内核。
