开源内核

Mihomo

Mihomo（曾称 Clash.Meta）是 MetaCubeX 维护的开源规则代理内核，延续 Dreamacro Clash 内核确立的规则分流路线。它用 YAML 连接规则、策略组、节点来源与 DNS：规则可指向具体节点、策略组或直连出口；指向策略组时，再由组内策略选择实际出口。通过 TUN 接入的系统流量也能沿用这套分流过程。

开源内核

sing-box

sing-box 是独立实现的通用代理平台，统一提供多协议入站与出站、DNS、规则路由、TUN 和跨平台集成能力。

开源内核

Xray-core

Xray-core 是从 v2fly-core 分叉并独立演进的代理核心，重点覆盖 VLESS、REALITY、XTLS 与多种传输和路由能力。

开源内核

V2Ray

V2Ray 是较早形成模块化代理平台路线的核心项目，提供协议、传输、路由和可组合配置能力；现有客户端可能使用 V2Ray 或其后续分支。

开源内核

clash-rs

clash-rs 是以 Rust 实现的 Clash 配置兼容代理核心；它与 Mihomo、原版 Clash 和 sing-box 是不同的实现。

开源内核

meow-rs

meow-rs 是面向多平台代理客户端的 Rust 核心项目，采用独立实现并兼容部分 Mihomo 配置与规则使用方式。

开源内核

Clash

Clash 是 Dreamacro 开源的 Go 规则代理内核，用 YAML 把规则、策略组、Fake-IP DNS 与控制 API 组织在一起，确立了后来由 Mihomo 延续的分流模式。原仓库于 2023 年 11 月停止公开访问；本页以 Go 模块存档、官方知识库与社区代码备份记录其能力边界。

开源内核

COW

COW（Climb Over the Wall）是 cyfdecyf 用 Go 编写的本地 HTTP 代理：自动识别被封锁的网站，只对这类网站使用上级代理，并生成 PAC 让可直连网站绕过代理。它是规则分流普及之前的早期自动化尝试，0.9.8 是仓库中最后一个可核验的正式版本。

开源内核

GoAgent

GoAgent 是依托 Google App Engine 建立代理通道的早期开源工具，由本地 Python 代理与用户自行部署的 GAE 服务端组成。2015 年主要源码仓库被清空，现存备份只用于记录当时的实现方式；它不是 Shadowsocks 或 Clash 的代码前身。

开源内核

Shadowsocks

Shadowsocks 是 2012 年公开的开源代理工具与协议起点，原始公开仓库为 Python 实现。2015 年原作者清空仓库代码后，协议与多种语言的独立实现继续发展；本页只记录原始实现与这次事件，不把后续实现合并为同一项目。

ShadowsocksR

ShadowsocksR 是 Shadowsocks 的分支实现，在协议中引入混淆与协议插件等改动，曾长期由独立的 Python 仓库维护。它与后来的 Shadowsocks 2022 不是同一套设计，本站按仓库提交记录其能力变化。

shadowsocks-libev 是 Shadowsocks 的 C 语言实现，基于 libuv 提供异步 DNS 与可移植的静态构建，长期用于路由器和嵌入式设备。仓库目前以 shadowsocks-c 名称维护，许可证为 GPL-3.0。

开源内核

Trojan-Go 是 Trojan 协议的 Go 语言独立实现，增加多路复用、路由、CDN 中转与 Shadowsocks 混淆插件等能力，采用 GPL-3.0 许可证。它与上游 trojan-gfw/trojan 分开发布与维护。

开源内核

Hysteria

Hysteria 是基于 QUIC 的代理实现，面向高丢包与高延迟链路优化拥塞控制，采用 MIT 许可证；仓库现由 HyNetworks 组织维护。本站协议分类的「Hysteria 2」条目从协议与使用条件角度说明，本页记录实现与仓库。

开源内核

dae

dae 是基于 Linux eBPF 的高性能透明代理实现，直接在内核侧完成流量分流，采用 AGPL-3.0 许可证；项目另有 daed 网页面板。本站「其他内核」客户端分类把它列为独立实现之一。

05

VPS 术语

19 条
VPS 术语

流媒体解锁

「流媒体解锁」是主机与网络行业通行术语，指服务器 IP（或出口网关）能否绕过 Netflix、Disney+、YouTube Premium、TikTok 等主流平台的风控数据库，成功加载当地版权限定视频。平台风控核心依据 ASN 类型（机房 Hosting ASN vs 住宅 ISP ASN）、GeoIP 数据库与同网段并发画像进行动态判别。

亦称 解锁检测 / Streaming Unlock
VPS 术语

原生 IP 与广播 IP

「原生 IP」指 IP 地址在区域互联网注册机构（RIR）的登记归属国与实际机房机架的物理地理位置一致；「广播 IP」（或 BYOIP）指将注册在其他国家或地区的 IP 段通过 BGP 跨域宣告到目标机房使用。广播 IP 易引发 GeoIP 商业数据库定位错位与风控误伤，现代网络通过 RFC 8805（Geofeed 数据格式）与 RFC 9092（Geofeed 发现机制）进行校正。

亦称 原生 IP / 广播 IP
VPS 术语

中国联通 AS4837 普通骨干网

AS4837（China Unicom China169 Backbone）是中国联通的全国普通公众 IP 骨干网，国际出口节点以 219.158.*.* 为典型特征；在境外 VPS 市场中常称「4837 优化回程」或「CUG 优化」，凭借充沛的国际出口总带宽与相对宽松的负载，在性价比上普遍超越中国电信普通 163 骨干网。

亦称 联通 4837 / 中国联通 163
VPS 术语

中国联通 AS9929 精品网 / CU Premium

AS9929（原网通 CNCNet 高端网，现中国联通工业互联网 CUII）是中国联通的高品质政企精品承载网，境外常结合 AS10099（联通国际 CUG）提供服务，国内俗称「联通 A网」或「CU Premium」；其网络定位与电信 CN2 GIA 完全对等，以轻载冗余、低丢包及卓越的欧亚互联著称，路由特征节点为 218.105.*.* 与 210.51.*.*。

亦称 联通 9929 / 联通 A网
VPS 术语

中国移动 CMIN2 精品网 / AS58807

CMIN2 是中国移动国际（China Mobile International, CMI）推出的旗舰级跨境承载网络（AS58807），对标中国电信 CN2 GIA 与中国联通 AS9929；在庞大的国内公众骨干网 AS9808 之外建立独立轻载通道与高优先级 QoS，出口骨干节点以 223.120.*.* 为典型特征，是移动用户跨境 VPS 的顶级直连线路。

亦称 移动 CMIN2 / AS58807
VPS 术语

Anycast 任播网络

Anycast（任播，RFC 1546 / RFC 4786 / RFC 7094）是一种去中心化的网络寻址与路由架构：分布在全球不同数据中心的服务器集群通过 BGP 共同宣告同一个 IP 地址段，公网路由器根据 AS 路径与策略度量自动将数据包导向拓扑距离最近的节点，兼具就近接入、全网 DDoS 流量稀释与平滑故障转移优势。

亦称 Anycast / 任播
VPS 术语

BBR 拥塞控制算法

BBR（Bottleneck Bandwidth and RTT）是由 Google 开发并合并进 Linux 内核的基于物理模型的拥塞控制算法；不同于传统丢包驱动算法（如 Reno、CUBIC），BBR 持续交替测量物理链路的最大传输速率（BtlBw）与最小往返时延（RTprop），在高延迟、高抖动的跨洋长肥管道（LFN）中能彻底避免因非拥塞随机丢包而导致的吞吐量崩塌。

亦称 BBR / BBRv2
VPS 术语

BGP 与多线接入

BGP（边界网关协议，BGP-4）是自治系统之间交换网络可达性信息的策略驱动路由协议，由 RFC 4271 定义；VPS 与数据中心所称的「BGP 多线接入」（Multi-homing）指机房同时与多家运营商建立 BGP 对等互联并广播同一段 IP 前缀，结合 RFC 1998 社区属性与 AS_PATH 调控，实现不同运营商用户的就近访问与单线故障自动秒级切换。

亦称 BGP 多线 / BGP 多 homing
VPS 术语

CN2 与 CN2 GIA / CN2 GT

CN2（China Telecom Next Carrier Network，中国电信下一代承载网，AS4809）是中国电信独立于普通 163 骨干网（AS4134）建设的高等级轻载骨干网络；GIA 与 GT 为国内主机市场对接入等级的通行分级：CN2 GIA 境内外全程走 59.43 节点保证晚高峰极低丢包与低延迟，CN2 GT 仅国际跨境段走 CN2、国内段混入 202.97 普通 163 骨干。

亦称 AS4809 / 电信下一代承载网
VPS 术语

DNS 污染与泄露

DNS 污染指网络路径上的旁路审查设备利用传统未加密 UDP 53 DNS 协议缺乏完整性校验的缺陷抢先返回虚假 IP 应答；DNS 泄露指客户端开启代理后，操作系统或浏览器的域名解析请求仍不慎发送给本地运营商 DNS 或因 EDNS Client Subnet 携带了用户真实子网信息，导致访问意图被旁路记录。

亦称 DNS 污染 / DNS 劫持
VPS 术语

IEPL 与 IPLC 专线

IEPL（国际以太网专线，二层架构）与 IPLC（国际私有租用电路，传统一层时分复用）是运营商提供的跨国点对点私有物理/逻辑电路：全程在电信级内网骨干传输、不经过公网国际关口局，具备零公网丢包与绝对确定性低延迟，是中转类代理服务和跨境金融业务的顶配物理线路。

亦称 国际专线 / 以太网专线
VPS 术语

IPv6-only 与双栈

双栈（Dual Stack，RFC 4213）指主机与网络同时启用 IPv4 与 IPv6 两套独立的路由协议栈；IPv6-only 指仅提供全球唯一单播 IPv6 地址而不分配任何公网 IPv4 的极低成本 VPS，访问纯 IPv4 网络资源需依赖 DNS64/NAT64 状态转换、464XLAT 或挂载 Cloudflare WARP 隧道。

亦称 IPv6 单栈 / 双协议栈
VPS 术语

KVM 虚拟化

KVM（Kernel-based Virtual Machine）是内置于 Linux 内核的硬件辅助完整虚拟化模块：每台 VPS 是一台完全独立的虚拟机，配合 QEMU 与 VirtIO 半虚拟化驱动，拥有独占的系统内核与虚拟硬件空间；用户可自由加载内核模块、启用 BBR 算法、运行 Docker 与 WireGuard，甚至自行重装任意操作系统。

亦称 Kernel-based Virtual Machine / KVM 虚拟机
VPS 术语

LXC 容器虚拟化

LXC（Linux Containers）是 Linux 内核提供的操作系统级轻量虚拟化技术：多个容器共享宿主机的同一个 Linux 内核，依托命名空间（Namespaces）与控制组（cgroups v2）隔离进程与硬件资源；相比 KVM 无虚拟硬件开销、内存密度高且价格亲民，但在内核调优与 TUN 设备访问上受到宿主权限约束。

亦称 LXC / Linux Containers
VPS 术语

MTU 与 MSS

MTU（最大传输单元，RFC 791）是数据链路层单帧所能承载的最大有效 IP 载荷（标准以太网通常为 1500 字节）；MSS（最大报文段大小，RFC 879）是 TCP 层单个数据包能承载的纯应用载荷。在跨国代理、VPN 隧道与拨号网络中，隧道加密报头开销若超过路径 MTU 且遭遇 ICMP 黑洞，会引发恶性分片丢包、TLS 握手假死与测速断流。

亦称 MTU / MSS
VPS 术语

NAT VPS

NAT VPS 指数十甚至上百台虚拟机/容器共享同一个公网 IPv4 地址、由宿主网关依据 RFC 3022 进行网络地址转换（DNAT）并分配特定高位端口区间的极低成本架构；由于无法直接独占 80 与 443 端口，常需结合 SNI 反向代理或隧道穿透建站，其 IPv6 部分通常仍保留独立公网全端口访问。

亦称 共享 IP VPS / NAT 机
VPS 术语

OpenVZ

OpenVZ 是由 Virtuozzo 发起的早期 Linux 操作系统级容器虚拟化平台；它通过修改宿主内核运行多个轻量容器（Virtual Environments），采用 UBC/vSwap 内存记账机制与 ploop 块级镜像，曾长期主导超低价 VPS 市场，但因共用宿主固定内核且易被超卖，目前已逐步被现代 KVM 和 LXC 取代。

亦称 OVZ / Virtuozzo 开源分支
VPS 术语

SNI 与 ECH 加密

SNI（服务器名称指示，RFC 6066）允许客户端在 TLS 握手初期以明文告知服务器目标主机名以实现单 IP 多证书虚拟托管；由于明文 SNI 成为现代网络审查与阻断的核心特征，IETF 推出了 ECH（Encrypted Client Hello，结合 RFC 9180 HPKE 与 RFC 9460 HTTPS 记录），将真实握手信息嵌套加密于公开的外层外壳中，实现 TLS 元数据的全链路隐私保护。

亦称 SNI / Server Name Indication

TUN/TAP 虚拟网卡

TUN 与 TAP 是操作系统内核提供的用户空间虚拟网络接口驱动：TUN 工作在网络层（L3，处理纯原始 IP 数据包），TAP 工作在数据链路层（L2，处理带 MAC 头的以太网帧）；代理客户端通过创建 TUN 虚拟网卡（Linux tun0、macOS utun、Windows Wintun）并接管系统路由表，结合用户态网络协议栈（如 gVisor、lwIP）实现全机全局流量的透明拦截与分流。
