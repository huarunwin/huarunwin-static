Xray-core

亦称 Xray

Xray-core 是从 v2fly-core 分叉并独立演进的代理核心，重点覆盖 VLESS、REALITY、XTLS 与多种传输和路由能力。

GitHub 源码 官方文档 MPL-2.0 42,317 Stars 6,038 Forks

仓库统计采集于 2026-10-25。

内核介绍

从 v2fly-core 分叉

Xray-core 的项目说明确认其 v1.0.0 从 v2fly-core 的特定提交分叉；之后围绕 VLESS、XTLS、REALITY 和 XHTTP 持续独立演进。

协议与传输

Xray 的协议、传输、安全层和路由配置分别演进。支持某个分享链接格式不等于客户端完整支持对应的服务端组合。
