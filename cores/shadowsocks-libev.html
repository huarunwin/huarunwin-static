shadowsocks-libev

开源代理内核 · 亦称 shadowsocks-c / libev 实现

shadowsocks-libev 是 Shadowsocks 的 C 语言实现，基于 libuv 提供异步 DNS 与可移植的静态构建，长期用于路由器和嵌入式设备。仓库目前以 shadowsocks-c 名称维护，许可证为 GPL-3.0。

内核介绍

面向嵌入式与路由器的 C 实现

仓库说明把项目定义为用 C 与 libuv 实现的、自包含的 Shadowsocks 程序，提供异步 DNS 与面向 Linux 等平台的可移植静态构建。这类构建方式使它常被集成到路由器固件与资源受限设备，而不是作为图形客户端的内置组件。

仓库名称与维护现状

GitHub 目前把 shadowsocks-libev 路径重定向到 shadowsocks/shadowsocks-c，仓库仍持续提交；许可证文件也位于该仓库。引用旧名称的教程与软件包仍很常见，核对源码与许可证时应以重定向后的仓库为准。

与其他实现的关系

shadowsocks-libev、shadowsocks-rust 与 go-shadowsocks2 都是按同一协议族分别实现的项目，维护者、语言与发布节奏互不相同；仓库主页把 shadowsocks-rust 列为相关项目，不构成两者共享代码的证据。
