内核介绍

规则与策略组构成核心模型

Clash 的规则可以按域名、IP、进程等条件把请求交给具体代理、策略组、DIRECT 或 REJECT；策略组再执行手动选择、延迟测试、故障回退或负载分配。节点列表和 rule-provider 可以远程更新，但实际字段以该版本配置文档为准。

查看来源

Fake-IP 与透明接管

Fake-IP DNS 为域名建立虚拟地址映射，redir/TProxy/TUN 再把系统连接交回内核，路由器因此仍能按域名规则处理透明流量。部分能力只在 Premium core 中提供；不能把文档中的 Premium 选项写成所有 Clash 构建共有。

当前仓库 README 明确它是 Dreamacro/clash 在 2023 年的备份，来源指向 Archive.org；本站因此把它作为历史实现和最后可核验发行线记录，不把备份仓库的后续提交、下游补丁或 Mihomo 的新协议支持倒填到原版 Clash。
