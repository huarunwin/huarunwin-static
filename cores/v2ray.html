V2Ray

亦称 v2ray-core / V2Fly

V2Ray 是较早形成模块化代理平台路线的核心项目，提供协议、传输、路由和可组合配置能力；现有客户端可能使用 V2Ray 或其后续分支。

GitHub 源码 官方文档 MIT 34,706 Stars 5,088 Forks

仓库统计采集于 2026-10-26。

内核介绍

模块化代理平台

V2Ray 的早期项目说明把协议、传输、路由和复用组织为可组合工具包，并提出了 VMess 等自有协议。

核验来源 ↗

V2Ray、V2Fly 与 Xray

V2Fly 是 V2Ray 生态的后续维护组织；Xray-core 则有明确的代码分叉记录。客户端标注 V2Ray 时仍应核对实际内置项目和版本。

配置与客户端

核心配置、分享链接和图形客户端的支持范围并不完全相同，页面不把“可导入 V2Ray 链接”当作完整核心证据。
