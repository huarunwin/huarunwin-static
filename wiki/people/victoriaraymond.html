02 · 技术贡献与项目演进

本节依据公开时间线和来源记录归纳已核验的技术工作；具体日期、项目和来源以公开时间线为准。

  • 2015-09-05 · V2Ray 初始提交：Project V 与 VMess 开始开发：在 Shadowsocks 与 GoAgent 相继遭外力停更的下架阶段，Victoria Raymond 提交了 v2ray-core 的初始代码（Commit 4c03bf0d），宣布 Project V 诞生并确立模块化工具包设计与 VMess 协议雏形。（来源记录：src-v2ray-initial-commit、src-v2ray-initial-readme）
  • 2015-11-29 · V2Ray 1.0 正式发布：完成第一个可独立运行版本：按照初版路线图，V2Ray 1.0 正式打标发布（Tag v1.0），实现了单服务器模式、TCP 传输与基于 VMess 协议的端到端基础代理功能。（来源记录：src-v2ray-release-v1）
  • 2016-01-22 · 实现动态端口分配（Dynamic Port）机制：提交 dynamic allocation of inbounds 架构（Commit 98d99a1f），提出服务端端口动态随机跃迁先河，有效破解审查系统对固定服务端口的精准阻断。（来源记录：src-v2ray-dynamic-port）
  • 2016-06-13 · 集成 mKCP 传输协议：解决复杂链路高丢包痛点：针对跨国骨干网复杂丢包与高延迟环境，合并 PR #170（Commit 22ce652a），引入基于 UDP 的 mKCP 传输层与自适应重传，明显提升弱网吞吐。（来源记录：src-v2ray-mkcp-pr）
  • 2016-08-15 · 实现 WebSocket 与 TLS 伪装：开启 Web 流量使用公开站点特征范式：合并 PR #238（Commit 667b71aa），V2Ray 正式支持 WebSocket 传输与 TLS 加密包装，率先实现了翻墙流量伪装为标准合规 Web 流量并支持反向代理与 CDN 转发的技术范式。（来源记录：src-v2ray-websocket-pr）
  • 2016-08-20 · V2Ray 2.0 发布：“One year” 一周年版本：在项目成立一周年之际正式发布 2.0 版本（Tag v2.0），支持多服务器模式、mKCP 与 WebSocket 传输通道，奠定多传输抽象架构基础。（来源记录：src-v2ray-release-v2）
  • 2018-03-01 · 实装 HTTP/2 (h2) 传输协议：提交 h2 transport（Commit d207d953），实现基于标准 HTTP/2 协议的多路复用网络传输，进一步丰富了 Web 拟态伪装的技术武器库。（来源记录：src-v2ray-h2-commit）
  • 2018-11-01 · V2Ray 4.0 发布：架构进入成熟工程阶段：V2Ray 4.0 正式发布（Tag v4.0），重新实现入站出站流水线、多用户配额与高级路由规则体系，项目基础设施自动化与跨平台发布能力趋于完善。（来源记录：src-v2ray-release-v4）
  • 2019-02-28 · 完成自动化构建与签名公钥更新，正式交接隐退：Victoria Raymond 合并第 1581 号 PR（Commit 1dab33b0），更新官方发布签名公钥（Commit 8f6637b8）与构建脚本（Commit d21d02d0），完成项目全自动托管后平静淡出公众视野。（来源记录：src-v2ray-last-pr、src-v2ray-gpg-update、src-v2ray-bazel-update）
  • 2019-04-15 · V2Fly 社区成立接力掌舵：为确保 V2Ray 核心的长期维护与生态平稳过渡，社区核心维护者组建 V2Fly 组织接续掌舵，将 V2Ray 精神与代码血脉继续发扬光大。（来源记录：src-v2fly-organization、src-v2fly-announcement）

03 · 代表项目与生态

  • V2Ray (Project V)：具有划阶段意义的模块化代理内核平台，实现 Inbound/Outbound 解耦与路由引擎分流体系
  • VMess 协议：V2Ray 原生安全代理协议，基于 16 字节时间戳鉴权与对称载荷加密，开启防重放与动态端口跃迁先河
  • Web 流量伪装范式 (WebSocket + TLS / HTTP/2)：首次公开将翻墙数据伪装为合规 Web 流量并借力反向代理与 CDN 转发，奠定当前抗审查拟态伪装基础
  • mKCP 传输协议：基于 UDP 的低延迟抗丢包优化传输层实现，在复杂跨国网络环境下保障通信吞吐与抗干扰能力

关联内核纪事记录：v2ray-initial-commit、v2ray-graphical-clients

关联客户端纪事记录：v2rayu-repository-created、v2ray-mobile-desktop-clients
