02 · 技术贡献与项目演进

本节依据公开时间线和来源记录归纳已核验的技术工作；具体日期、项目和来源以公开时间线为准。

  • 2020-01-20 · xiaorouji 注册 GitHub 账号投身路由生态：开发者 xiaorouji（handsomeji）正式开启在 GitHub 的开源探索，投身于 OpenWrt 嵌入式软路由网络分流与透明代理工程。（来源记录：src-handsomeji-github、src-xiaorouji-github）
  • 2020-04-15 · 确立 PassWall 多核心多协议异构编排架构：在 OpenWrt 生态中打破单一核心壁垒，实现 Shadowsocks、V2Ray、Trojan 与 Brook 等多协议组件的统一热调度。（来源记录：src-passwall-repo）
  • 2020-12-31 · 发布 PassWall 4-2 稳定版本：确立 PassWall 4.x 阶段的 LuCI 控制台交互规范与多协议透明代理自动恢复流水线。（来源记录：src-passwall-releases）
  • 2021-04-18 · 落地前置节点链式中继与级联调度：在路由透明代理领域实现链式代理（Chain Proxy），允许将不同出站协议节点组合为流水线中继并跨核心转发。（来源记录：src-passwall-releases、src-passwall-repo）
  • 2021-07-31 · 集成 HAProxy 负载均衡组件：引入工程 TCP/HTTP 负载均衡器，实现节点集群并发分流、低延迟心跳探测与故障自动无感切流。（来源记录：src-passwall-releases）
  • 2022-03-04 · 完成 PassWall 4.x 代码历史重整与版本规范化：提交「luci: Redefine the version (4-1)」，完成代码库历史重组与模块架构提纯，开启高频迭代新纪元。（来源记录：src-passwall-commit-4-1、src-passwall-repo）
  • 2022-03-07 · 正式开源并上线 PassWall 2 1.0 重新实现版：提交「luci: online 1.0」，针对 OpenWrt 次世代防火墙与当前路由特性开辟新的的独立分支与演进工程。（来源记录：src-passwall2-initial、src-passwall2-repo）
  • 2022-03-28 · PassWall 2 确立 Xray 作为主力核心：提交「luci: Use Xray instead of V2Fly」，深化对 VLESS、XTLS 与 TPROXY 较高性能流控的原生支持。（来源记录：src-passwall2-xray、src-passwall2-repo）
  • 2023-05-18 · PassWall 2 完善 OpenWrt 22.03+ nftables 原生规则：适配 firewall4 架构，以原生 nftables 规则替代传统 iptables 脚本，降低内核数据包复制损耗。（来源记录：src-passwall2-releases、src-passwall2-repo）
  • 2024-02-20 · 整合 sing-box 核心与新型 UDP 协议：引入 sing-box 作为主力核心之一，提供对 Hysteria、TUIC 等下一代较高性能拥塞控制协议的原生编排支持。（来源记录：src-passwall-releases、src-passwall2-releases）
  • 2025-08-15 · 合并波斯语本地化拓展国际影响力：完善多语言支持体系，引入波斯语（Persian）完整界面翻译，为伊朗等严重网络审查地区的路由用户提供相关支持。（来源记录：src-passwall2-repo、src-passwall2-releases）
  • 2026-01-05 · 成立 Openwrt-Passwall 官方开源组织：建立 Openwrt-Passwall 官方组织，将 passwall、passwall2 与 packages 软件源归集管理，推进组织化协作维护。（来源记录：src-openwrt-passwall-org）
  • 2026-01-20 · PassWall 2 优化分流规则独立 FakeDNS 控制：提交「luci: FakeDNS can be enabled on the each shunt rules」，实现对各分流规则的独立 FakeDNS 粒度精细调控。（来源记录：src-passwall2-repo）
  • 2026-10-01 · PassWall 与 PassWall 2 同步发布 26.10.1 正式版：双子工程并驾齐驱，同步发布 26.10.1 版本，持续优化 DNS 分流逻辑、锁清理机制与订阅安全性。（来源记录：src-passwall-releases、src-passwall2-releases）
