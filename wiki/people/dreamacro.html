02 · 技术贡献与项目演进

本节依据公开时间线和来源记录归纳已核验的技术工作；具体日期、项目和来源以公开时间线为准。

  • 2018-06-10 · 提交 Clash 初始代码并确立基于规则的轻量设计：Dreamacro 推送根提交与第一个功能提交，以“A rule based proxy in Go.”确立立项信条，首发支持基于 ini 语法的规则分流雏形。（来源记录：src-clash-root-commit、src-clash-first-commit）
  • 2018-06-16 · 实现 url-test 自动延迟测速策略组：提交 url-test 代理组支持，通过定时向目标端点测速自动挑选最低延迟节点，奠定自动恢复网络基础。（来源记录：src-clash-urltest-commit）
  • 2018-06-18 · 创立 External Controller RESTful API 接口：内置基于 HTTP RESTful 与 WebSocket 的外部控制器 API，实当前理内核与图形界面的架构解耦。（来源记录：src-clash-controller-commit）
  • 2018-07-12 · 引入 select 手动节点策略组与规则路由器：实装 selector 策略组与分流规则路由器，完成出站代理、策略组与规则三层解耦的初步闭环。（来源记录：src-clash-selector-commit）
  • 2018-09-26 · 引入 fallback 故障自动主备倒换策略组：实装 fallback 策略组，按优先级定期探测并在首选节点不可用时低延迟无感回落至备用节点。（来源记录：src-clash-fallback-commit）
  • 2018-10-02 · 确立以 YAML 作为标准配置规范：推送破坏性架构升级，正式从 ini 迁移至 YAML 声明式配置，奠定中文代理生态通用的规则描述标准。（来源记录：src-clash-yaml-commit）
  • 2019-02-15 · 引入 load-balance 策略组实现多出口负载均衡：新增负载均衡策略组，支持基于目标域名散列（eTLD+1）或轮询算法在多条代理链路上分摊流量。（来源记录：src-clash-loadbalance-commit）
  • 2019-05-03 · 实现实装 Fake-IP DNS 解析机制：基于 RFC 3089 在本地分配 198.18.0.0/16 虚构保留私网 IP，消解本地 DNS 污染并将握手延迟降至微秒级。（来源记录：src-clash-fakeip-commit、src-clash-docs-dns）
  • 2019-10-18 · 开源许可证升级为 GPL-3.0：提交许可证变更，将 Clash 从早期的宽松 MIT 协议升级为具有强传染性的 GPL-3.0，加强开源代码产权保护。（来源记录：src-clash-gpl-commit）
  • 2019-12-28 · 推出 TUN 模式预编译版本开启系统级透明接管：发布第一个 TUN 模式预编译二进制标签，利用虚拟网卡设备驱动实现免配置系统代理的全局网络接管。（来源记录：src-clash-tun-commit）
  • 2020-05-08 · 正式设立 Clash Premium 闭源增强版：为遏制不当商业分发并探索高级网络特性，正式发布免费的 Clash Premium 核心，实装 TUN 设备、Rule Provider 与动态脚本。（来源记录：src-clash-premium-commit、src-clash-premium-intro）
  • 2020-09-12 · 坚持通用架构边界并拒绝集成 XTLS：面对社区对新兴流控技术的呼声，Dreamacro 在 Issue #896 坚持分流架构明确性，拒绝引入侵入传输层的 XTLS，间接促成了社区 Meta 分支的诞生。（来源记录：src-clash-xtls-issue、src-mihomo-repo）
  • 2022-05-23 · 社区开源分支 Clash.Meta 启动：开源社区成员创建 Clash.Meta（后更名为 Mihomo），继续推进开源规则核心演进。（来源记录：src-mihomo-repo）
  • 2023-11-03 · Clash 原始核心仓库被删除：核心仓库于北京时间 2023 年 11 月 3 日被删除。（来源记录：src-clash-repository-changes）

03 · 代表项目与生态

  • Clash (Open Source Core)：基于 Go 语言的规则隧道核心，定义了当前策略组调度与声明式 YAML 分流语法标准
  • Clash Premium：官方闭源增强版核心，引入了系统级 TUN 虚拟网卡模式、Rule Provider 与动态脚本调度支持
  • External Controller API：基于 HTTP RESTful 与 WebSocket 的标准化外部控制接口，解耦核心转发与前端交互
  • Mihomo (社区接续项目)：由 MetaCubeX 社区在 Clash.Meta 基础上接续演进的当前规则代理核心，继承了 Dreamacro 的架构规范与分流语言

关联内核纪事记录：clash-public-release、clash-repositories-change

关联客户端纪事记录：clash-client-ecosystem-change、clash-verge-rev-created
