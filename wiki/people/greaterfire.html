02 · 技术贡献与项目演进

本节依据公开时间线和来源记录归纳已核验的技术工作；具体日期、项目和来源以公开时间线为准。

  • 2017-10-15 · GreaterFire 提交 Trojan 初始代码：在 GitHub 建立 trojan-gfw/trojan 仓库并提交 Initial commit（1ecc6c1），确立基于真实 HTTPS 拟态的抗审查路线。（来源记录：src-trojan-initial-commit）
  • 2017-10-16 · 发布项目说明与伪装定位：在 README 中首次公开写下“An unidentifiable mechanism to bypass GFW”，确立放弃自制混淆、直面审查的不可识别目标。（来源记录：src-trojan-repo）
  • 2017-10-19 · 系统性阐明特洛伊木马哲学与协议规范：发布设计白皮书与协议规范文档，确立“它本身就是 HTTPS”的哲学宣言、首包 SHA224 散列认证及 Fallback 站点回落机制。（来源记录：src-trojan-overview、src-trojan-protocol）
  • 2017-10-21 · 发布 v0.1.0 第一个公开版本：推出 Trojan 第一个公开发布版本，完成基础客户端与服务端功能，支持真实 TLS 握手与本地 SOCKS5 代理转换。（来源记录：src-trojan-v01-tag）
  • 2017-10-25 · 实装 SNI 与 ALPN 拟态：通过 OpenSSL 原生 API 引入 SNI 域名标识与 ALPN（http/1.1）协议协商支持，减少 TLS 握手特征。（来源记录：src-trojan-sni-alpn-commit）
  • 2018-03-21 · 发布 v1.0.0 正式版本：Trojan 协议与 C++ 异步核心走向成熟稳定，建立跨平台构建体系与系统服务模板。（来源记录：src-trojan-v10-tag）
  • 2018-04-14 · 合并 PR #30 实装 UDP 转发：正式引入基于 SOCKS5 规范的 UDP ASSOCIATE 转发支持与 append_payload 机制，补齐实时网络与游戏代理能力。（来源记录：src-trojan-feat-udp-commit）
  • 2018-08-06 · 开源 trojan-url 并创立 trojan:// 标准：创建 trojan-url 工具库，正式定义并推广 trojan:// 标准 URI 编码规范与二维码分享格式，成为行业通用标准。（来源记录：src-trojan-url-repo）
  • 2019-07-03 · 推出 trojan-quickstart 简化部署：创建官方快速安装脚本，推动自动化申请权威机构 TLS 证书与反向代理配合的最佳实践在社区推广。（来源记录：src-trojan-quickstart-repo）
  • 2019-09-29 · 发布 v1.13.0 支持 Linux NAT 透明代理：引入 Linux 原生 NAT 模式与 iptables 协同机制，使 Trojan 能够自动接入软路由及透明网关环境。（来源记录：src-trojan-v113-tag）
  • 2020-03-22 · 发布 v1.15.0 支持 ALPN 端口分流覆盖：增加 alpn_port_override 特性，允许服务端根据 ALPN 协商结果将 HTTP/1.1 与 HTTP/2 明文分流至不同后端端口。（来源记录：src-trojan-v115-tag）
  • 2020-06-09 · 发布最终官方版本 v1.16.0：完成双向认证与安全策略更新，成为 GreaterFire 掌舵下的最终正式版本，协议范式已深刻融入全生态各大客户端。（来源记录：src-trojan-v16-tag）
  • 2020-11-08 · 完成主线最后一次提交并功成身退：在 trojan 仓库完成 Windows 编译依赖与贡献者名册维护后正式隐退，将特洛伊木马防御体系留给整个繁荣的开源生态。（来源记录：src-trojan-final-commit）

03 · 代表项目与生态

  • Trojan：基于 C++11 与 Boost.Asio 开发的原型核心，实现真实 HTTPS 拟态与 Fallback 请求回落机制，以不可识别范式抵御被动特征识别与主动探测
  • Trojan Protocol Specification：简化较高性能的应用层代理协议规范，定义首包 56 字节 SHA224 密码校验散列、SOCKS5 请求直通与零 RTT 载荷拼接
  • trojan-url：官方 URL 编解码工具，确立并推广了被全行业通用的 trojan:// 节点分享链接常见实现
  • trojan-quickstart：简化自动化部署脚本，推动全真证书申请与本地 Web 站点回落的最佳实践推广

关联内核纪事记录：v2ray-initial-commit、core-triumvirate-established

关联客户端纪事记录：v2ray-mobile-desktop-clients、sing-box-graphical-clients
