03 · 代表项目与生态

  • sing-box-yg：面向 Linux VPS 的 sing-box 多协议一键部署脚本，提供配置生成、节点分享和可选 Argo/WARP/Psiphon 组件入口。
  • argosbx：将 Sing-box、Xray 与 Cloudflared-Argo 组合到 VPS、Docker 和容器部署中的一键脚本，仓库 README 还列出 WARP 出站组合与多协议配置输出。
  • x-ui-yg：公开仓库描述的精简 x-ui 脚本，覆盖 Hysteria 2、XHTTP、ENC/MLDSA65、Argo 与 Psiphon 入口，并输出部分聚合订阅配置。
  • warp-yg：WARP 多功能一键脚本，仓库说明列出 warp-go 与 wgcf 切换、配置生成、WARP+／团队账户及 VPS 出站状态检查。
  • Cloudflare-vless-trojan：面向 Cloudflare Workers/Pages 的 VLESS/Trojan 脚本，同时提供可选 ECH-TLS、普通 TLS 或无 TLS 的本地 SOCKS5/HTTP 代理模式。
  • acme-yg：ACME 证书申请与续期脚本，公开说明覆盖 IP/域名证书、单域名/泛域名以及与多个脚本共享证书的用法。
  • Serv00/Hostuno-sb-yg：同一仓库内面向 Serv00/Hostuno 的三协议脚本入口，支持网页保活与订阅配置输出等文档所列功能。
