02 · 技术贡献与项目演进

本节依据公开时间线和来源记录归纳已核验的技术工作；具体日期、项目和来源以公开时间线为准。

  • 2024-05-11 · morytyann 提交初始代码并确立原生架构：Joseph Mory 提交 commit e68521f（initial commit），开启基于 OpenWrt firewall4 原生 nftables 的 Mihomo 客户端探索。（来源记录：src-nikki-init-commit、src-nikki-repo）
  • 2024-07-18 · 发布 v1.1.0 兼容多 WAN 口 mwan 负载：发布 v1.1.0，合并 pull request #37，原生支持多宽带接入场景下的分流调度。（来源记录：src-nikki-releases）
  • 2024-07-30 · 发布 v1.3.0 适配 IPv6 转发链路：发布 v1.3.0，合并 pull request #47，解决 WAN6 入站排除与 IPv6 策略路由规则映射。（来源记录：src-nikki-releases）
  • 2024-08-25 · 发布 v1.7.3 并命名为 MihomoTProxy：发布 v1.7.3，强化基于 Linux NFTables 的 TPROXY 旁路无损拦截与硬件加速兼容。（来源记录：src-nikki-releases）
  • 2024-11-09 · 发布 v1.10.0 隔离 DNS 劫持与 TCP 流量：提交 commit 817f7d1，精准隔离 DNS 劫持范围，避免其对常规 TCP 流量造成非预期污染。（来源记录：src-nikki-releases）
  • 2025-01-02 · 发布 v1.17.0 引入 DSCP 流量标记绕过：支持 DSCP 差分服务代码点绕过策略，优化局域网内特定高优先级流量的分流通道。（来源记录：src-nikki-releases）
  • 2025-02-09 · 更名为 Nikki 并成立开源组织：morytyann 提交 commit b662c32，因上游许可证政策更名为 Nikki，并正式成立 nikkinikki-org 组织。（来源记录：src-nikki-rename-commit、src-nikki-repo）
  • 2025-03-03 · 发布 v1.20.0 进入独立发布阶段：发布更名后的首批重要稳定版本，改变包名与新的响应式 LuCI 控制台。（来源记录：src-nikki-releases）
  • 2025-04-15 · 发布 v1.22.0 废弃旧有 TProxy 命名残留：提交 commit 0e08f51（refactor: drop MihomoTProxy），完成底层模块代码的归一化。（来源记录：src-nikki-releases）
  • 2025-08-09 · 开源孪生项目 OpenWrt-momo：正式建立 OpenWrt-momo 仓库，将成熟的 NFTables 与 LuCI 架构自动复用到 sing-box 核心。（来源记录：src-momo-repo）
  • 2025-12-29 · 发布 v1.25.0 代码清理与性能改进版：清理冗余 Shell 脚本与系统调用，优化软路由常驻内存与多核负载均衡。（来源记录：src-nikki-releases）
  • 2026-04-10 · 发布 v1.26.0 当前版本：升级基础依赖，引入较较强的策略组排序与在线配置热加载机制。（来源记录：src-nikki-releases）
  • 2026-06-10 · 更新至 Mihomo-Alpha 当前内核：发布 v1.26.1，紧密同步上游 Alpha 内核的抗封锁特性与新型协议混淆。（来源记录：src-nikki-releases）
  • 2026-09-30 · Nikki 突破 5300 星标确立公开项目：OpenWrt-nikki 达到超过 5,300 颗 GitHub 星标，作为当前软路由装机必备透明代理获得社区关注。（来源记录：src-nikki-repo、src-momo-repo）

  • nikkinikki-org GitHub：nikkinikki-org 官方开源组织主页与软路由生态工具链
