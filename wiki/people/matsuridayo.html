02 · 技术贡献与项目演进

本节依据公开时间线和来源记录归纳已核验的技术工作；具体日期、项目和来源以公开时间线为准。

  • 2021-11-30 · Matsuri 移动端项目初始建立：分叉 SagerNet 代码创建 Matsuri (茉莉) 仓库，探索 Android 平台多协议支持与通用插件化架构。（来源记录：src-matsuri-repo、src-matsuri-init）
  • 2022-05-03 · NekoRay 跨平台桌面客户端立项：在 GitHub 创建 nekoray 仓库并推送初始源码，基于 Qt/C++ 为 Windows 与 Linux 提供轻量较高性能的默认配置图形客户端。（来源记录：src-nekoray-init、src-nekoray-upload）
  • 2022-09-24 · nekobox_core 与内核多态架构实装：提交 switch core 支持并引入 nekobox_core 架构，在 Linux 平台上率先集成 sing-box 接管 VPN 与 TUN 网卡。（来源记录：src-nekoray-switch-core）
  • 2022-10-19 · NekoRay 发布 2.0 稳定版：升级 sing-box 1.1-beta10，实装核心崩溃自动重启并恢复运行配置机制，优化 VMess/SNI 自动填充。（来源记录：src-nekoray-release-2-0）
  • 2023-03-15 · NekoBox for Android 源码立项：重新实现移动端技术栈，以当前 sing-box 核心嵌入 Android VpnService，正式立项 NekoBox for Android。（来源记录：src-nekobox-init）
  • 2023-04-03 · NekoBox for Android 发布 1.0.0 正式版：集成 sing-box 1.2.2 并启用 gRPC 支持，实装 REALITY 协议解析导入与去重测试，标志着移动端新的工具链成熟。（来源记录：src-nekobox-release-1-0-0）
  • 2023-05-14 · NekoRay 发布 3.0 版本重新实现：Windows 端升级 Qt 6.5 构建，重新实现 Mux 多路复用与路由 DNS 对象，支持 h2mux、smux 与 yamux。（来源记录：src-nekoray-release-3-0）
  • 2023-07-05 · NekoRay 内核平移升级 Xray-core：推送核心改造提交，将旧版 v2ray-core 替换为 Xray-core，并在图形界面实装 uTLS 指纹与 SpiderX 伪装。（来源记录：src-nekoray-xray-commit）
  • 2024-02-24 · NekoBox for Android 实装 1.3.1 规则集升级：引入 sing-box 1.8.0 规范，以 rule_set 二进制规则集替代传统 geoip/geosite，并实装 Mieru 协议支持。（来源记录：src-nekobox-release-1-3-1）
  • 2024-07-05 · NekoRay 开启 4.0 路线更名 nekobox.exe：剥离 Xray 多内核切换逻辑，主程序统一更名为 nekobox.exe，聚焦于 sing-box 单核的较高性能稳定调试。（来源记录：src-nekoray-rename-commit）
  • 2024-12-12 · NekoRay 发布 4.0.1 最后版本并正式归档：升级 sing-box 1.9.7-neko1，发布 4.0.1 最终版本并附带坦率的开发者告白，桌面端仓库正式进入只读归档状态。（来源记录：src-nekoray-release-4-0-1、src-matsuridayo-docs）
  • 2025-09-20 · NekoBox for Android 发布 1.4.0 版本：升级 sing-box 1.12.8-neko-1，实装 ECH 与 HTTP/3 订阅直连获取、高级 JSON 自定义配置合并与 gVisor TUN 栈。（来源记录：src-nekobox-release-1-4-0）
  • 2026-02-09 · NekoBox for Android 发布 1.4.2 稳定版：升级 sing-box 1.12.19-neko-1，优化订阅覆写与本地自定义 JSON 配置保留逻辑，持续构筑坚固的移动端防线。（来源记录：src-nekobox-release-1-4-2）

03 · 代表项目与生态

  • NekoBox for Android：基于 sing-box 内核的 Android 全功能通用代理工具链
  • NekoRay：基于 Qt/C++ 与 sing-box 的跨平台桌面代理客户端（已归档）
  • Matsuri：基于 V2Ray 与通用工具链的 Android 代理客户端（项目原型，已归档）
