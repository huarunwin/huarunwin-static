02 · 技术贡献与项目演进

本节依据公开时间线和来源记录归纳已核验的技术工作；具体日期、项目和来源以公开时间线为准。

  • 2024-07-30 · Clash Party (Mihomo Party) 项目正式初始：初始化跨平台桌面工程骨架（Commit dc56a69e），确立当前集成桌面架构路线。（来源记录：src-clashparty-init-commit）
  • 2025-08-12 · Memory 提交第一个 Windows 提权修复：提交 Commit 6bdb133c，优化系统管理员权限检测，开启向项目的核心技术维护过程。（来源记录：src-memory-first-commit）
  • 2025-08-23 · 重要内嵌 Sub-Store 运行束：提交 Commit 94183172，处理 ES Module 兼容，实现无需外部依赖的可视化订阅预处理管线。（来源记录：src-memory-substore-bundle）
  • 2025-08-30 · 主导项目品牌跃迁至 Clash Party：提交 Commit 0c38d3eb，统筹 WinGet、AUR 与构建脚本，完成 mihomo-party 向 clash-party 命名升级。（来源记录：src-memory-rename-clashparty）
  • 2025-10-11 · 实现实装交互式可视化规则编辑器：提交 Commit 2bf54446，支持 MATCH、附加参数、拖拽排序与撤销保护，告别手写 YAML 报错。（来源记录：src-memory-visual-rule-editor）
  • 2025-10-22 · 实现 WebDAV 配置备份与多端同步：提交 Commit 55860af9，支持端到端云端备份与本地恢复，实现跨设备自动漫游。（来源记录：src-memory-backup-restore）
  • 2026-08-14 · 发布打磨成熟的 v2.0.2 稳定版本：统筹发布版本小版本，调优复杂订阅下的内存开销与高并发虚拟网卡路由稳定性。（来源记录：src-clashparty-v202-release）
  • 2026-09-20 · 解决 macOS 开发者证书公证流水线：提交 Commit 4ea39d22，自主编写证书导入机制，恢复 macOS 官方签名公证并发布新版本。（来源记录：src-memory-macos-signing）

03 · 代表项目与生态

  • Clash Party (前身 Mihomo Party)：集成 Sub-Store、WebDAV 与 Smart 核心的当前跨平台桌面代理客户端
  • 内嵌 Sub-Store 订阅预处理管线：免除外部 Node.js 运行时的默认配置节点过滤、重命名与规则转换引擎
  • 交互式可视化规则编辑器 (Visual Rule Editor)：支持 MATCH 模式、附加参数、拖拽排序与撤销保护的图形化分流配置中心
