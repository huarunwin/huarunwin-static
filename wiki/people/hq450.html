02 · 技术贡献与项目演进

本节依据公开时间线和来源记录归纳已核验的技术工作；具体日期、项目和来源以公开时间线为准。

  • 2018-08-26 · 设立 GitHub 代码仓库：在华硕/梅林官方软件中心下架科学上网插件的背景下，设立 hq450/fancyss 仓库，开启离线插件维护。（来源记录：hq450-repo）

  • 2018-09-07 · 实装 V2Ray 协议与订阅支持：提交 commit 05439bb，为 ARM 与 HND 平台引入 V2Ray 核心二进制与 VMess 订阅解析。（来源记录：hq450-v2ray-commit）
  • 2020-04-07 · 引入 Trojan 协议支持：提交 commit ce53fe1，为 HND 平台引入 Trojan 代理二进制并整合进路由器透明转发链路。（来源记录：hq450-trojan-commit）
  • 2022-06-03 · 构建多核心自动化编译流水线：建立脚本与 Makefile，实现对 Xray、shadowsocks-rust 与 kcptun 二进制的自动编译与 UPX 压缩。（来源记录：hq450-repo）
  • 2023-06-16 · 发布 FancySS v3.1.3：提交 commit c7e2da8 并发布 release tag v3.1.3，实装 Xray 自动化构建与更新分发脚本 make_latest.sh。（来源记录：hq450-tag-v3-1-3）
  • 2024-12-10 · 重新实现并确立 3.0 分支基准：提交 commit b3055d5，整理 3.0 分支代码历史，覆盖 Broadcom、Qualcomm、MediaTek 全平台架构。（来源记录：hq450-root-commit）
  • 2026-03-30 · 实装节点分流模式 7：提交 commit 1b9f674，正式引入 Node Shunt 模式，支持将不同规则域名的流量精准分流至不同后端代理节点。（来源记录：hq450-shunt-commit）
  • 2026-05-04 · 引入 Zig 语言微型工具链：提交 commit 1823515 与 80a0fd4，发布 3.5.25，将 anytls-zig、node-tool 等作为子模块引入，根除嵌入式内存瓶颈。（来源记录：hq450-zig-submodules-commit、hq450-anytls-zig-repo）
  • 2026-05-10 · 发布 3.5.28 适配新版 Xray：提交 commit f7fbdca，升级自编译 Xray-core v26.3.27 并适配 Hysteria2 finalmask 与 WebSocket 新版配置结构。（来源记录：hq450-changelog）
  • 2026-05-20 · 发布 3.5.29 稳定订阅映射：提交 commit 607c153，实装订阅 Profile 身份映射并支持联发科 Wi-Fi 7 客户端路由器 GS-BE7200X。（来源记录：hq450-profile-commit）
  • 2026-06-02 · 发布 3.5.30 当前稳定版：提交 commit b19e82c，持续优化弱性能机型按需探测链路与 SmartDNS 硬屏蔽，项目收获近 1.4 万星标。（来源记录：hq450-latest-commit）
