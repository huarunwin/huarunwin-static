02 · 技术贡献与项目演进

本节依据公开时间线和来源记录归纳已核验的技术工作；具体日期、项目和来源以公开时间线为准。

  • 2012-12-26 · 向 shadowsocks-libev 提交第一个兼容变更：Max Lv 提交 compatible with latest protocol（Commit 1327d178），以纯 C 语言开启事件驱动的较高性能低内存轻量代理探索。（来源记录：src-libev-initial-commit）
  • 2013-05-27 · 发布 v1.3 并正式支持 OpenWrt 嵌入式路由器：发布 shadowsocks-libev v1.3（Tag v1.3），常驻内存低至数兆字节，直接开启家用路由器与嵌入式透明网关翻墙阶段。（来源记录：src-libev-openwrt-tag）
  • 2014-04-10 · 主导 shadowsocks-android 移动端演进：后续维护并持续推进官方 Android 客户端开发，基于 NDK 交叉编译与 VpnService 开发移动端免 Root 代理基准。（来源记录：src-android-repo）
  • 2015-08-18 · 在在公开争议期间维护 shadowsocks 社区组织与客户端：原作者退出后，Max Lv 随后合并后续提交（Commit 5f6effba）并持续推进 Android 与 libev 版本维护，力挽生态狂澜。（来源记录：src-android-post-storm、src-shadowsocks-continuation）
  • 2017-01-08 · 实装 SIP003 插件机制实现混淆解耦：提交 Add SIP003 plugin support（Commit 61b82c45），将底层网络代理与外置流量混淆解耦为标准子进程通信管道。（来源记录：src-sip003-commit、src-sip003-doc）
  • 2017-01-25 · 确立 SIP004 AEAD 认证加密套件规范：提交 Add SIP004 (AEAD) support（Commit 4ebe5aeb），废除无认证流加密并引入 AEAD 密码套件，根除主动探测漏洞。（来源记录：src-sip004-commit、src-sip004-doc）
  • 2020-02-23 · shadowsocks-android 集成 shadowsocks-rust 核心：提交 Integrate shadowsocks-rust（Commit ee28f971），推动 Android 官方客户端底层使用内存安全的 Rust 实现。（来源记录：src-android-rust-commit）
  • 2026-02-21 · 创立纯 Rust 规则代理内核 meow-rs：Max Lv 发起纯 Rust 较高性能代理内核 meow-rs（Commit 39683554），兼容 Mihomo/Clash 规则并杜绝 GC 内存开销，处理移动沙盒瓶颈。（来源记录：src-meow-rs-genesis、src-meow-rs-repo）
  • 2026-07-09 · macOS 客户端 BaoLianDeng 迁移至 Rust meow-rs：向 BaoLianDeng 提交内核迁移代码（Commit f0a35deb），移除原 Go Mihomo 内核并引入 Rust FFI 驱动。（来源记录：src-baoliandeng-meow-migration）
  • 2026-08-19 · shadowsocks-libev 实装 Shadowsocks 2022 (SIP022)：提交 Add Shadowsocks 2022 (SIP022) ciphers（Commit 46791234），推动常用 C 语言核心支持新一代当前协议规范。（来源记录：src-libev-sip022）

03 · 代表项目与生态

  • meow-rs：纯 Rust 编写的较高性能当前代理规则内核，兼容 Mihomo/Clash 配置并杜绝 GC 内存开销，主导驱动新一代移动端客户端
  • shadowsocks-libev：采用 C 语言编写的较高性能、超低内存开销 Shadowsocks 核心实现，主导了 OpenWrt 与嵌入式路由器生态
  • shadowsocks-android：官方 Android 客户端，支持系统 VPN、ACL 规则分流、SIP003 插件与 Rust 内核当前
  • SIP003 插件标准与 Simple-obfs：定义标准输入输出管道的独立混淆插件体系，为流量混淆与协议扩展奠定模块化架构
  • SIP004 AEAD 加密规范：废弃脆弱的旧流加密，引入具有认证机制的 AEAD 密码套件，解决主动探测重放漏洞
  • Shadowsocks 2022 (SIP022) C 语言实装：在常用 shadowsocks-libev 中实装新一代当前协议标准，推进底层系统的持续演进
