02 · 技术贡献与项目演进

本节依据公开时间线和来源记录归纳已核验的技术工作；具体日期、项目和来源以公开时间线为准。

  • 2018-06-13 · yichengchen 提交 ClashX 初始代码：Commit 8f00a87 标志着公开范围第一个 Clash 图形客户端诞生，确立专为 macOS 定制的纯原生菜单栏常驻架构。（来源记录：src-clashx-initial-commit、src-clashx-repo）
  • 2018-06-14 · 引入系统提权辅助并首次公开发布官方定位：Commit c56aa26 解决系统代理权限检测并引入 Clash 子模块；初版 README 确立“A rule based proxy For Mac base on clash”。（来源记录：src-clashx-repo）
  • 2020-04-11 · 实现网络变动与休眠唤醒健康检测：Commit 615fc5d 实现当网络变动或系统休眠唤醒时，自动对策略组展开延迟测速与节点选优。（来源记录：src-clashx-repo）
  • 2020-04-21 · 重新实现 Privileged Helper 提权维护进程：Commit 60691df 将特权助手解耦为独立模块，通过 SMJobBless 与 launchd 消除系统代理修改时的密码弹窗。（来源记录：src-clashx-repo）
  • 2020-04-25 · 升级自定义视图与延迟颜色色阶渲染：Commit 73d2478 与 aad8b3b 在 macOS 10.15.2+ 启用 NSView 代理渲染，并支持根据延迟数值渲染颜色色阶徽章。（来源记录：src-clashx-repo）
  • 2020-05-23 · 支持 iCloud Drive 跨设备配置同步：Commit 0461db8 引入基础 iCloud 支持，允许用户将分流规则与配置文件安全保存在 Apple 云端跨端共享。（来源记录：src-clashx-repo）
  • 2020-08-10 · 推出 ClashX Pro 与 NetworkExtension 增强模式：基于 Apple NetworkExtension 框架提供透明网络接管，免去环境变量设置，覆盖终端命令行与容器流量。（来源记录：src-clashx-pro）
  • 2020-11-14 · 适配 macOS 11 Big Sur 原生视觉语言：Commit 3e165db 重绘菜单栏图标与圆角列表，契合 macOS 11 新的毛玻璃与控件风格。（来源记录：src-clashx-bigsur-m1）
  • 2020-11-18 · 推出 Apple Silicon M1 通用架构编译支持：Commit a0daee3 引入 Universal Build 脚本，原生支持 M1 芯片 ARM64 指令集，降低能耗。（来源记录：src-clashx-bigsur-m1）
  • 2021-12-03 · 支持 clash://install-config 快捷导入协议：Commit dd25adc 升级 README 并支持自定义 URL Scheme，为各大节点平台一键导入提供标准规范。（来源记录：src-clashx-repo）
  • 2022-03-22 · 发布 v1.91.1 正式版本：Commit 9980dda 完成 1.91.1 版本更新，成为原作者维护周期内最具代表性的稳定收官版本之一。（来源记录：src-clashx-repo）
  • 2022-06-12 · MetaCubeX 社区创建 ClashX.Meta 分支仓库：MetaCubeX 组织在 GitHub 正式建立社区接续仓库，在保留 yichengchen 常用菜单栏界面的同时跟进当前核心演进。（来源记录：src-clashx-meta-repo-metadata）
  • 2023-11-03 · yichengchen/clashX 仓库记录为只读归档：公开记录显示原版仓库转入只读归档状态，社区生态由 ClashX.Meta 等分支持续传承。（来源记录：src-clash-repository-changes）

03 · 代表项目与生态

  • ClashX：公开范围第一个 Clash 图形客户端，专为 macOS 开发的较高性能纯原生菜单栏代理工具，采用 Swift/Objective-C 开发
  • ClashX Pro：率先整合 Apple NetworkExtension 框架的进阶版本，提供免配置全系统透明网络接管的“增强模式”
  • Privileged Helper Tool 提权维护进程：基于 macOS launchd 与 SMJobBless 开发的安全特权助手，消灭切换系统代理时的密码弹窗
  • ClashX.Meta (社区分支)：由 MetaCubeX 社区于 2022 年 6 月创建并延续的 ClashX 分支，保留常用原生菜单栏交互并接续适配当前内核

本站收录的主导作品：

生态关联应用：

  • clashx-meta

关联内核纪事记录：clash-public-release、clash-repositories-change

关联客户端纪事记录：clash-client-ecosystem-change
