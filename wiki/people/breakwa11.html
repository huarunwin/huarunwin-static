  • 2015-09-11 · 提交 add obfs plugin 开启混淆探索：BreakWa11 在 Shadowsocks 分支中提交 add obfs plugin 变更（Commit a723c2f0），首次公开引入混淆插件机制，拉开 ShadowsocksR 独立技术演进路线的大幕。（来源记录：src-ssr-obfs-commit）

  • 2017-07-24 · 发布 SS 被动检测程序引发社区论战：在 GitHub 仓库发布 SS 被动检测程序（Issue #868），就流量指纹识别与协议安全性展开公开辩析，引发社区多个争鸣。（来源记录：src-ssr-passive-detect-archive）
  • 2017-07-27 · 发布 3.4.0 版本并因恶性网络骚扰宣布退隐：提交 3.4.0 版本（Commit fd723a92）后，遭遇恶性人肉搜索与威胁；为保护无辜受牵连人员，BreakWa11 删除了 GitHub 上的全部项目代码并宣布停止维护。（来源记录：src-ssr-last-commit、src-ssr-rfa-report）

03 · 代表项目与生态

  • ShadowsocksR (SSR)：基于 Python 与 C# 构建的独立代理生态，引入协议握手鉴权与流量外观伪装，提升对抗包检测（DPI）的能力
  • Protocol 与 Obfs 正交分层架构：实现协议认证（auth_*）与特征混淆（tls1.2_ticket_auth、http_simple）解耦的双层抗探测模型，从根源上摧毁重放探测漏洞
  • 批量节点订阅格式 (SSR Subscription)：实现基于 HTTP(S) API 接口拉取的节点批量同步规范与 ssr:// 链接标准，直接催生了当前“机场”产业分发范式
  • ShadowsocksR-C# 客户端：Windows 平台推广率极高的大众图形客户端，集成分流路由、二维码扫码、延迟测速与自动订阅更新

关联内核纪事记录：shadowsocks-original-repository-removed、v2ray-initial-commit、apple-removes-vpn-apps

关联客户端纪事记录：shadowrocket-app-store-launch、surge-ios-product-launch
