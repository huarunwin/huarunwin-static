02 · 技术贡献与项目演进

本节依据公开时间线和来源记录归纳已核验的技术工作；具体日期、项目和来源以公开时间线为准。

  • 2011-04-19 · GoAgent 项目在 Google Code 正式创建：Phus Lu 创建开源项目，确立“让获取知识的道路畅通无阻”的免费 GAE 云代理目标。（来源记录：src-google-code-archive）
  • 2011-12-20 · GoAgent v1.0 架构成熟与本地根证书机制实装：引入动态生成 CA.crt 本地自签名根证书，实现透明 HTTPS 解密与流式压缩中继。（来源记录：src-google-code-archive、src-goagent-backup）
  • 2012-05-18 · GoAgent v2.0 发布与多 AppID 自动轮询机制：突破 GAE 单应用 1GB 流量上限，支持 id1|id2|id3 自动故障切换与 IP 优选。（来源记录：src-goagent-backup）
  • 2013-05-10 · 联动 SwitchySharp 掀起平民翻墙启蒙发展：结合 GFWList 规则订阅实现按需分流，成为数以百万计网民认知当前网络的通用工具。（来源记录：src-goagent-backup）
  • 2013-11-15 · GoAgent v3.0 发布并引入传输层加密：实装 RC4 混淆与防明文相关字过滤，优化 Google 公开范围 IP 探测机制。（来源记录：src-goagent-backup）
  • 2014-05-31 · 防火长城封锁 Google 公开范围 IP 与社区 IP 竞争：面对地毯式阻断，社区依托 CheckGoogleIP 展开旷日持久的可用 GGC IP 扫描与阻击。（来源记录：src-goagent-backup）
  • 2015-08-25 · 官方源码仓库清空并发表告别声明：清空 GitHub 仓库源码，修改描述为“Everything that has a beginning has an end”，EFF 随后发表公开范围报道。（来源记录：src-eff-report-2015）
  • 2015-09-05 · 删库事件直接启发 V2Ray 诞生与技术承接：V2Ray 初始提交明确将 GoAgent 被迫停更记录为构建抗摧毁模块化平台的核心动机，并原生兼容 GoAgent 协议。（来源记录：src-v2ray-initial-commit）
  • 2016-03-20 · 发布纯 Go 语言重新实现的较高性能 Goproxy：基于 Go 协程、HTTP/2 多路复用与当前 TLS 重写代理内核，处理旧 Python 架构性能瓶颈。（来源记录：src-goproxy-repo）
  • 2021-08-15 · 开源较高性能的零内存分配 Go 日志库 phuslu/log：在底层较高性能系统编程领域持续深耕，实现纳秒级低延迟与高并发吞吐。（来源记录：src-phuslu-log-repo）

03 · 代表项目与生态

  • GoAgent：基于 Google App Engine 的跨平台 HTTP/HTTPS 代理软件，统治了 2011—2015 年的中文翻墙生态与推广阶段
  • Goproxy：基于 Go 语言重写的较高性能 GAE 代理服务端与客户端实现，使用 HTTP/2 与多路复用
  • phuslu/log：较高性能的零内存分配结构化 Go 日志库，说明了作者在底层系统工程领域的较强造诣
  • phuslu/lru & fastdns：面向高并发网络场景的较高性能并发 LRU 缓存与 DNS 解析套件
