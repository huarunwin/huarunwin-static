02 · 技术贡献与项目演进

本节依据公开时间线和来源记录归纳已核验的技术工作；具体日期、项目和来源以公开时间线为准。

  • 2012-04-20 · GitHub 原始公开仓库建立与 V2EX 初始发布：clowwindy 在 GitHub 创建仓库并在 V2EX 发帖《发一个自用了一年多的翻墙工具 shadowsocks》，确立“穿越防火墙的轻量级隧道代理”核心目标。（来源记录：src-v2ex-genesis、src-ss-python-repo）
  • 2012-10-18 · 创建 shadowsocks-nodejs 实现：发布基于 Node.js 异步事件循环的多平台实现，推动轻量代理的高并发网络吞吐探索。（来源记录：src-nodejs-repo）
  • 2012-12-15 · Shadowsocks Android 客户端核心代码公开：提交核心客户端代码（Commit 2e0a6fc6），利用 Android 4.0 引入的 VpnService 开启免 Root 移动端透明代理新纪元。（来源记录：src-android-initial-commit）
  • 2013-07-08 · 发表 Gist 技术备忘录《为什么不应该用 SSL 翻墙》：剖析公钥证书握手特征在审查对抗中的严重隐患，奠定高随机度对称密文流的设计理论根基。（来源记录：src-gist-why-not-ssl）
  • 2013-11-09 · 确立“项目属于社区”的开源定调：clowwindy 在 Issue #124 坦诚表态“项目属于社区，只要有需求就会一直存在下去”，奠定去中心化传承基调。（来源记录：src-clowwindy-issue124-community）
  • 2013-11-20 · shadowsocks-libev 分支诞生：由 Max Lv（madeye）等社区维护者接力开发的纯 C 语言轻量实现诞生，常驻内存低至数兆字节，开启 OpenWrt 家用软路由阶段。（来源记录：src-libev-repo）
  • 2015-01-29 · 发表澄清声明并深入反思网络审查社会学：在 V2EX 发表 PSA 声明厘清开源项目与商业侵权服务的边界，深刻反思威权审查与用户依赖心理的深层共生结构。（来源记录：src-v2ex-psa-2015）
  • 2015-08-18 · 在 Windows 版 Issue #293 抨击社区分隔现象：痛斥开源社区内部违反协议、搞小圈子“大大”文化的封闭心态，呼吁真正的开放与互相尊重。（来源记录：src-issue-windows-293）
  • 2015-08-22 · 原始代码仓库清空与划阶段告别声明：13:48 提交 commit 938bba3（“remove”）清空源码，并在 Issue #124 发表著名告别留言：“I hope one day I'll live in a country where I have freedom to write any code I like without fearing”。（来源记录：src-github-remove、src-ios-issue124-farewell、src-clowwindy-twitter-farewell）
  • 2015-08-28 · 电子相关基金会（EFF）发表公开范围专题报道：EFF 刊文《Speech that Enables Speech》，记录维护者受压清空仓库及抗审查开源软件的法律与人权背景。（来源记录：src-eff-2015）
  • 2015-08-29 · V2Ray 初始提交开启生态接力：Victoria Raymond 提交 V2Ray 初始代码（Commit a4d4c5c2），明确将 Shadowsocks 与 GoAgent 的被迫关停记录为构建新一代复合平台的动力。（来源记录：src-v2ray-initial-commit）
  • 2017-02-01 · 社区引入 SIP004 / AEAD 认证加密规范：Shadowsocks 协议引入带有关联数据的认证加密（AEAD），根除针对无认证流密码的主动探测与重放漏洞。（来源记录：src-sip004）
  • 2022-05-10 · 社区发布 Shadowsocks 2022 规范：重新实现握手报文与会话独立密钥派生，提供较强的抗重放攻击与多用户管理能力。（来源记录：src-ss-2022-spec）

03 · 代表项目与生态

  • Shadowsocks (Python)：最初的原型与参考实现，奠定了本地 SOCKS5 结合远端轻量对称加密流的抗审查通信规范
  • Shadowsocks Android：早期与社区共同推进的移动端开源客户端探索，奠定基于系统 VpnService 的移动代理基准
  • Shadowsocks iOS：早期 iOS 平台的网络扩展探索，见证了不可抗力事件下的历史告别声明
  • Shadowsocks (Node.js)：早期基于 Node.js 异步事件循环的多平台并发实现探索
  • 为什么不应该用 SSL 翻墙：阐释密码学设计目标与对抗流量嗅探差异的常用技术备忘录
