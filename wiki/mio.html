条目导读

Mio 是由 GitHub 账号 xkrfer 发布的 macOS 代理客户端，使用 MyGo 提供原生界面，使用 Mihomo 处理代理连接。公开正式发行提供 Apple 芯片和 Intel 两种安装包。

本页依据 2026-11-26 核验的 v0.0.9 正式发行及其固定提交整理，按“概览 → 使用方式 → 内核关联 → 版本发行 → 下载生态 → 来源与边界”说明产品事实与使用条件。

01 · 词条概览

项目 公开资料
应用名称 Mio
项目仓库 xkrfer/mio
支持系统 macOS 12 或更高版本
发行架构 Apple 芯片（arm64）、Intel（amd64）
界面与代理内核 MyGo、Mihomo

费用 核验时公开安装及完整使用流程不要求购买软件或付费授权；代理节点与订阅另行配置

项目公开 Go 应用、界面、特权辅助工具和发行构建材料。系统及架构要求以正式版对应的中文 README和发行工作流为依据。

02 · 使用方式

订阅、菜单栏与规则

Mio 接受 Clash / Mihomo YAML 配置和订阅，支持管理多个订阅，在菜单栏选择策略组，以及通过界面查看规则、连接和流量信息。节点与订阅需要使用者自行提供；软件安装包不等于网络服务。

系统代理与 TUN

项目提供系统代理和 TUN 增强模式。TUN 需要管理员授权安装特权辅助工具；这是影响安装与运行权限的条件，具体操作以正式版安装说明为准。

03 · 内核关联

Mio 的代理内核为 Mihomo。这一关联来自正式发行的构建链：发行工作流为 macOS 的 arm64 与 amd64 架构构建应用，并通过 fetch_mihomo.py 获取和打包 Mihomo 核心。MyGo 提供原生界面框架，二者在产品中承担不同职责。

应用的 YAML 导入能力本身不作为内核身份依据。本页不将框架或内核的作者、上游项目与 Mio 的公开所有者合并为同一开发者身份。

04 · 版本发行

v0.0.9

本次核验的正式版为 v0.0.9，发布时间为 2026-11-26 01:43:13 UTC，固定标签提交为 08fa44e1e00a0bb61a78260767b51d168b7823db。该发行在 GitHub 标记为非预发布版本。

安装包名称分别为 mio-0.0.9-arm64.dmg 和 mio-0.0.9-amd64.dmg。版本、架构和下载入口以该正式发行的实际附件为依据，不由模板中的其他平台注释推断移动端或其他操作系统支持。

05 · 下载生态与安装条件

双架构安装包

  • Apple 芯片安装包：29,364,736 字节。
  • Intel 安装包：33,312,768 字节。

软件后续版本和当前收录的下载入口见 Mio 应用页面。本页的固定发行记录不自动代表项目此后最新版本。

签名与官方预览

官方安装说明称发行包采用临时签名且未公证，首次打开可能受到 macOS Gatekeeper 拦截。此处记录官方披露的安装条件，未独立验证安装包签名或执行安装。

仓库的界面预览由项目脚本生成和合成，并使用演示数据；预览图不证明实际连接、速度或当前发行版的实测结果。
