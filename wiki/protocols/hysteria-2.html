词条概览与核心定位

01

Hysteria 2（简称 Hy2）由开发者 Tohru 及 HyNetworks 团队主导研发[1]，是对早期 Hysteria 1 的彻底重构。 在国际跨境公网传输中，国际骨干出口在晚高峰常出现 10%~30% 甚至更高的突发丢包。传统 TCP 协议的拥塞控制算法（如 Cubic 乃至 BBR） 在检测到丢包或延迟抖动时，会主动缩减拥塞窗口，导致吞吐量断崖式下跌至几百 Kbps。

Hysteria 2 核心设计哲学是「以带宽换可用性」：采用基于 UDP 的定制 QUIC 栈[3]， 客户端与服务器协商指定带宽（如上行 50Mbps、下行 200Mbps），Brutal 算法忽略常规丢包信号，严格按预设速率强行发包与重传， 在极高丢包率下依然能跑满物理宽带上限。

定位结论

Hysteria 2 是针对晚高峰高丢包、高抖动普通跨境线路的最强提速利器。但对于 UDP 严重限速或完全阻断的局域网环境， 需配合端口跳跃或回退至基于 TCP 的协议（如 VLESS + REALITY 或 NaïveProxy）。

分层架构与三层核心原理

02
1. 传输与拥塞控制层（QUIC + Brutal CC）深度定制 quic-go 底层栈，摆脱 TCP 单连接队头阻塞与内核态切换瓶颈； 独创 Brutal 拥塞控制算法，根据两端配置以恒定速率发包，弱网丢包不降速。
2. 混淆与抗 QoS 限速层（Salamander + Port Hopping）Salamander 算法对 UDP 报文头进行加盐伪随机变换，破坏 QUIC 规范协议指纹； 支持单端口与范围端口跳跃，定时在多端口间轮转切换，避开运营商单连接流量惩罚。
3. 认证、伪装与透明回落层（HTTP/3 Masquerade + Fallback）应用层协议帧模拟标准 HTTP/3 语义，携带安全密码摘要； 遭受非授权的主动扫描或探测时，服务端直接代理返回真实目标网站的 HTTP/3 响应，不暴露代理特征。

传输工作流程与状态转移

  1. 客户端发送定制 QUIC 握手包若启用 Salamander 混淆，数据包经前置加盐异或随机化，外层表现为无规则 UDP 流量。
  2. TLS 1.3 握手与凭据校验服务端解密并校验认证密码帧；未通过认证的主动探测流被路由至伪装网站（HTTP/3 Fallback）。
  3. Brutal 速率协商与自适应发包双端确认上传/下载带宽上限，Brutal 状态机启动，以固定速率无视丢包持续发包与快速补发。
  4. 定时端口跳跃（可选）客户端依据双方约定的伪随机序列或多端口映射表，平滑迁移目的端口，规避 ISP QoS 封锁。

为什么 Brutal 能提速？

普通 BBR 或 Cubic 算法将网络丢包视为“网络拥塞”，主动减半发包速率； 但在跨国长肥管道（Long Fat Network）中，丢包多由国际出口路由抖动引起。 Brutal 逆向设计：丢包越多，重传发包越密集，直接以冗余发包抵消信道丢包！

适用场景与网络边界限制

05

最推荐使用场景：

  • 晚高峰国际骨干网高丢包线路：普通美西、欧洲等无优化公网 VPS，丢包率在 15%~40% 时仍能维持高速播放 4K 视频。
  • 移动网络蜂窝数据环境：针对 4G/5G 基站弱信号与弱网抗抖动性能卓越，连接漫游切换平滑。
  • 需要大吞吐单线程测速与下载：彻底突破单 TCP 连接因拥塞控制导致的窗口受限瓶颈。

不适用或受限场景：

  • 局域网 / 校园网 / 酒店强行封锁 UDP：部分企业防火墙、校园网仅开放 TCP 80/443，UDP 会被全量 DROP。
  • 当地运营商 UDP QoS 极度严苛：部分地区运营商对大流量 UDP 连接采取直接熔断或限制到 1Mbps 以下策略。
  • 前置 CDN 反向代理需求：标准 CDN（如 Cloudflare 免费版）不支持此类定制 QUIC 协议直接回源代理。

安全假设、QoS 对抗与局限性

06

1. 证书与域名要求：与 REALITY 的“免自备域名”不同，Hysteria 2 标准模式下需要服务端配置有效的 TLS 证书。 虽然客户端可以配置不校验自签证书，但建议使用 Let's Encrypt 证书以实现最逼真的 HTTP/3 伪装效果。

2. 运营商 UDP 封锁应对策略：当遭遇运营商 QoS 限制时，最佳实践是开启端口跳跃（Port Hopping），利用 iptables/nftables 将服务端大段端口映射到 Hy2 监听端口， 让客户端在传输过程中持续变换端口，避免单一连接触发流量配额监管。

3. 机器资源与发包开销：Brutal 算法在丢包极高时会发出大量重传包，相较传统 TCP 协议消耗更多的服务器带宽与 CPU 运算量； 在低配置 VPS（如 512MB 内存以下单核机器）上跑满千兆时需开启 UDP GSO 优化。
