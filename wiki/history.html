历史里程碑 · 20112011 年GoAgent 发布与 GAE 云代理时代 →Phus Lu 发起基于 Google App Engine 的开源代理工具 GoAgent，开创早期利用公共云平台 IP 池与证书重签的翻墙时代。历史里程碑 · 20122012 年Shadowsocks 开源与轻量代理范式确立 →clowwindy 在 GitHub 正式开源 Shadowsocks，以轻量对称加密流替代沉重的传统 VPN 握手，确立跨平台开源代理的基石架构。历史里程碑 · 20122012 年Shadowsocks Android 移动端分发 →Max Lv 等开发者将 Shadowsocks 移植至 Android 平台，首度实现移动端 VPNService 虚拟网卡底层透明代理接管。历史里程碑 · 20152015 年Surge 首创 iOS Network Extension 代理范式 →Yachen Liu 借助 iOS 9 开放的 Network Extension API 开发 Surge，首创规则分流、本地 DNS 劫持与 MITM 调试架构。历史里程碑 · 20152015 年V2Ray 项目启动与 VMess 协议诞生 →Victoria Raymond 发起 Project V 并设计 V2Ray，推出具备时间戳认证与多路复用能力的 VMess 协议，开启复杂多入站多出站路由时代。历史里程碑 · 20152015 年ShadowsocksR 分支与混淆对抗期 →breakwa11 发起 ShadowsocksR 分支，引入协议混淆（obfs）以对抗 GFW 基于包长分布和熵值的深度包检测（DPI）。历史里程碑 · 20162016 年v2rayN Windows 图形客户端普及 →2dust 开发 v2rayN，为 Windows 用户提供开箱即用的多内核图形界面、订阅解析与 PAC 分流管理，成为最广泛的桌面客户端之一。历史里程碑 · 20172017 年Trojan 协议与标准 TLS 伪装范式 →GreaterFire 团队提出 Trojan 协议：放弃自定义混淆，直接使用真实合法 TLS 握手特征与 Web 服务回落，开创模仿真实 HTTPS 流量的全新抗审查路线。历史里程碑 · 20182018 年Clash 发布与声明式规则订阅生态 →Dreamacro 开源发布 Go 语言编写的 Clash，确立声明式 YAML 配置、策略组自动测速优选与远程规则集生态，彻底改变客户端交互格局。历史里程碑 · 20202020 年VLESS 协议发布：精简架构与性能飞跃 →rprx 提出去中心化鉴权的 VLESS 协议，彻底移除服务端状态与额外加密层，由外层标准 TLS 负责传输安全，实现极简与极致吞吐。历史里程碑 · 20202020 年Xray-core 分支创建与 XTLS 原生流控 →社区由于 XTLS 许可争议与发展理念分歧从 V2Ray 分支创建 Xray-core，全面推进 XTLS 原生流控与内核级零拷贝网络加速。历史里程碑 · 20222022 年sing-box 通用代理平台发布 →nekohasekai 发布 sing-box，以现代 Go 语言构建跨全平台的通用代理内核，深度融合原生 TUN 虚拟网卡与极高性能规则集路由。历史里程碑 · 20222022 年REALITY 借壳伪装方案诞生 →Xray 团队发布 REALITY 协议扩展，消除自签 TLS 证书的主动探测指纹，通过借用正规境外网站证书与 SNI 伪装实现服务端零域名证书配置。历史里程碑 · 20232023 年Hysteria 2 协议与 Brutal 拥塞控制 →Tobyxdd 等发布 Hysteria 2，基于魔改标准 QUIC 协议结合用户态 Brutal 速率控制，彻底解决跨洋恶性丢包弱网下的单线程吞吐瓶颈。历史里程碑 · 20232023 年Clash 生态删库事件与 Mihomo 社区重构 →Clash 核心与主流客户端仓库归档，社区迅速由开源组织接力维护 Mihomo（Clash.Meta）内核及新一代 GUI 客户端，完成去中心化生态重生。
