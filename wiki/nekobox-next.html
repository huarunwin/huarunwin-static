条目导读

Nekobox-Next 是 GitHub 用户 shixiaoheia 维护的 Android 代理客户端，基于 NekoBox for Android 开发，集成 sing-box、Xray 与 Mihomo 三种代理内核。

本页以 v1.6.5 正式发行及其对应源码为依据，介绍应用用途、内核关系、下载架构与从旧测试包迁移的条件。当前版本和官方下载入口见 Nekobox-Next 应用页面。

01 · 词条概览

项目 公开资料
名称 Nekobox-Next
项目仓库 shixiaoheia/Nekobox-Next
平台 Android 7.0 及以上，构建配置 minSdk 为 24
正式包名 shixiaoheia.nekobox.next，自 v1.6.0 起使用
代理内核 sing-box、Xray、Mihomo
源码与许可 应用、核心桥接及构建材料公开；LICENSE 声明 GPL-3.0-or-later
软件费用 公开下载和使用流程不要求软件购买，节点及订阅由使用者自行配置

项目是 NekoBox for Android 的社区分支，拥有自己的包名、签名声明和发行渠道。仓库首页继承的上游归档网址属于原项目资料，不能据此将其视为本分支独立官网。

02 · 使用方式

节点、订阅与路由

应用提供分享链接、订阅及配置导入，支持 Clash / Mihomo YAML、sing-box 与 Xray 出站 JSON 等输入。实际协议由应用配置及所选内核处理，配置格式支持和代理内核分别判断。

v1.6.5 的内核管理页提供协议默认内核选择，并保留单节点设置和协议兼容性约束。应用支持自定义路由、分应用代理及 Meta 规则分流；正式发行说明给出的优先级为自定义路由、分应用强制代理、Meta 自动分流。

界面与配置迁移

项目提供液态玻璃与怀旧两种界面，以及多语言和主题设置。软件需要使用者自行准备节点或订阅，下载客户端不等于获得网络服务。

从 v1.5.5 及更早测试包迁移时，应先在旧版导出备份，再安装采用独立包名的新版本并导入。包名变化使新版不能直接覆盖旧测试包。v1.6.0 起的同渠道正式版沿用新的包名和签名，官方提供应用内更新流程。

03 · 内核关联

固定发行源码的 libcore/go.mod 声明 sing-box v1.14.4、Mihomo v1.19.34，以及 libXray 和 Xray-core 依赖。核心构建脚本 将 Go 核心绑定为 Android 库，仓库内包含相应的协议和内核桥接材料。

这些内核身份来自依赖与构建链。项目在应用层进行内核调度及协议适配，不能将分支中的扩展能力一概归为上游 sing-box、Xray 或 Mihomo 的通用能力。内核背景可分别参阅 sing-box、Xray、Mihomo。

04 · 版本发行

v1.6.5 正式版 于 2026-11-26 08:44:39 UTC 发布，标签对应提交 667633291ba87570bc82a0bf4fea70c8ea8780d6。该版提供四种 ABI 的 APK，版本码为 325。

发行附带的 release-manifest.json 记录 APK 名称、长度、SHA-256、包名、签名证书指纹和对应源码提交。文件摘要可用于核对取得的安装包；发行清单中的签名声明与实际设备或本地签名工具验证是不同的验证范围。

预览版使用单独标签，早期版本还使用 NekoBox-... 文件名前缀。本站当前正式渠道只跟踪 vX.Y.Z 和 Nekobox-Next-X.Y.Z-ABI.apk，不混用预览包、上游包或旧测试包。
