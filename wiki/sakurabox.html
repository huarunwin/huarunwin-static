SakuraBox for Android

翻墙应用商店 · 2026-11-19 · 更新于 2026-11-19

SakuraBox 是 xingmingname 维护的 Android 代理客户端。README 说明它基于 NekoBox for Android 修改；GitHub 的 fork 元数据 对应上游 MatsuriDayo/NekoBoxForAndroid。当前含 Nakis 的发行渠道是 v1.0.3-beta.2 预发布版。

1. 项目定位与谱系

README 的原话为：

SakuraBox 是基于 NekoBox for Android 修改的 Android 网络代理客户端，该项目为开发者为满足自己的需求而开发，如有bug请见谅

直属仓库创建于 2026 年 10 月 14 日；完整 Git 历史保留上游提交。应用界面、继承功能、宿主核心和新增协议适配分别有来源，不能把继承历史全部归为当前维护者原创。

2. 使用与平台

客户端提供节点、订阅及 Android VPN 相关界面，需要使用者自行提供节点或自建服务端；本站不提供连接服务。标签源码的 构建配置 使用最低 API 21（Android 5.0）。包名配置 为 app.sakurabox.client，应用版本 1.0.3-beta.2、基础版本代码 50，由构建规则乘以五。

最低 API 是配置事实，不等于所有 Android 设备已安装或连通实测。官方发行提供 ARM64、ARMv7、x86 和 x86_64 四种 ABI 的独立 APK。

3. 核心与扩展协议

BUILDING.md 固定 sing-box v1.14.3 的提交 7054cac5124465ffdb145870d7c01885566711b1，并列出 libneko、gomobile、补丁和 AAR 生成流程。libcore/go.mod 的 replace 指向相对构建依赖目录，核心由这些源码和本地适配组合。

3.1 Nakis

libcore/nakis 实现客户端出站，Android 侧提供节点字段、设置与分享链接解析。构建文档把协议参考固定到上游 33eb35178ad6c6774144baf562f589d612578603，并记录旧服务端基线与 UDP 拒绝测试入口。应用使用自带适配；没有证据将其写成依赖 sing-nakis。

3.2 Sudoku

v1.0.3-beta.1 的 发布提交 说明加入 Sudoku；后续 Nakis 版继续保留。构建文档说明该扩展随固定 sing-box 和本地补丁构建，面向官方 sing-box 的导出仍拒绝扩展协议。应用内部支持不等于上游核心的正式能力。
