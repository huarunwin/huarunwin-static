Nakis 命令行程序

翻墙应用商店 · 2026-11-19 · 更新于 2026-11-19

Nakis 命令行程序是 Nakis 协议 的 Go 参考实现，由 nyarvex 维护。它同时包含客户端和服务端；本站目录把面向本地应用的 SOCKS5 客户端作为入口，关联机制介绍见 参考内核。

1. 获取与分发

官方仓库 未发布 GitHub Release 或官方二进制资产。目录的版本 b867d97 是 完整提交 的缩写。它不代表发行标签、协议版本或已打包应用。

go.mod 声明 Go 1.24，无额外模块依赖；Makefile 列出 Linux amd64/arm64、macOS arm64 和 Windows amd64 目标。使用者需自行编译；这些目标不证明其他架构已经测试。

2. 客户端和服务端

命令帮助 提供：

nakis client -c client.json
nakis client -l LINK [-listen ADDR]
nakis server -c server.json

客户端默认在 127.0.0.1:1080 监听无认证 SOCKS5，需要代理的应用显式接入该地址；服务端依配置监听并连接目标。参考程序没有系统 VPN/TUN 接管或图形界面。上述命令展示帮助文本，不代表本站已经部署服务或完成连通性测试。

3. 证书、链接与订阅辅助命令

cert 生成自签名证书并输出 pin；ech 生成 ECH 密钥和配置片段。link 在客户端/服务端配置与 nakis:// 分享链接之间转换；sub 可以列出订阅节点，或输出选中节点为客户端配置。精确参数见 main.go 和 link.go。

分享内容包含连接所需的身份和参数，应按配置资料处理；本文不保存用户节点、UUID、私钥或订阅地址。

4. 配置与使用边界

服务端地址、UUID、TLS、SNI/pin 和 UDP 支持应与对端一致。tls_pins 使用 SPKI 摘要匹配取代标准证书链校验；关闭 TLS 不提供载荷机密性。默认本地监听可限制访问范围，改为所有网卡后无认证 SOCKS5 的暴露面随之变化。配置文档 是字段依据。

并行流量使用多条隧道，单条隧道顺序复用。作者公开的 NAP 特征分析 应与填充和连接池说明一起阅读；不将 README 的性能或抗识别用语作为独立实测结论。

5. 相关项目与许可

SakuraBox 提供 Android 图形入口；sing-nakis 是开发者集成库。参考程序的 LICENSE 为 MIT。官方 README 链接 Nakis 项目频道，它不作为人物本人发言归属依据。
