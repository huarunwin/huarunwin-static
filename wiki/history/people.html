RPRX

俗称：R主席

协议与传输

2020 — 至今

Project X 与 Xray-core 创始人

“主导 VLESS、XTLS 与 REALITY 协议革命，以极致性能与拟态伪装开创现代网络代理新范式”

2020 年夏，开发者 RPRX 在 V2Ray 社区首次提出 VLESS 协议与 XTLS 流控理念，振聋发聩地指出：当隧道内承载的流量本身已是标准 TLS 密文时，外部代理隧道的重复加密是一种纯粹的算力浪费与性能罪恶。因开源许可证商业限制与社区治理哲学产生深刻分歧，他在争议风暴中毅然率队分叉，独立创立 Project X 与 Xray-core。此后，他以敏锐的工程直觉先后推出 XTLS Splice 内核零拷贝直通、抵御握手特征阻断的 xtls-rprx-vision，以及彻底颠覆自购域名依赖的 REALITY 拟态伪装体系。在 GitHub 社区中，围绕其许可证约束、“前向安全”宣传口径及与跨生态项目的公开论战始终伴随着强烈的两极评价；但其坚决的工程自信与绝对的带队铁腕，也让他被追随者尊称为“R主席”，一手带领 Xray 生态与 Clash、sing-box 共同筑起了当代对抗网络审查的技术三极。

规则与核心

2021 — 至今

sing-box 创始开发者与 SagerNet 核心维护者

“以严谨的工程抽象打破协议与平台割裂，用通用代理架构开拓跨全平台的现代网络中枢”

2022 年中，中文代理生态在经历多年演进后面临着明显的碎片化与历史包袱：老旧核心代码膨胀且难以维护、部分核心走入高级闭源双轨制，而各平台图形客户端与底层核心的割裂更让新技术的落地步履维艰。开发者 nekohasekai 在深度主导 Android 端全能客户端 SagerNet 研发后，毅然从零启动了新一代通用网络平台 sing-box。nekohasekai 秉承对 Go 语言架构与零开销抽象的极致追求，首创了以完全解耦、严格类型化 JSON 配置为特征的高性能网络管道，并在开源生态中率先实现对 WireGuard、ShadowTLS、TUIC、Hysteria 2、VLESS Reality 等前沿协议栈的统一原生支持。更具开拓性的是，他打破了传统“核心只管命令行、界面交给第三方”的脱节模式，带领团队将 Android、Apple（iOS/macOS/tvOS）、Windows、Linux 官方图形客户端纳入同一体系，不仅在 tvOS 17 推出之际率先将规则代理带入 Apple TV 电视大屏，更与 Mihomo、Xray 共同筑就了后 Clash 时代中文互联网对抗网络审查的技术三极。

tobyxdd

俗称：Toby

协议与传输

2015 — 至今

Hysteria 协议与核心开创者

“打破传统 TCP 代理面对丢包被动减速的陈旧范式，自研 Brutal 算法与工业级定制 QUIC，以纯粹速度撕开跨国弱网与审查封锁”

在长达十余年的翻墙技术演进中，绝大多数代理协议均构建于传统 TCP 与单向 TLS 封装之上。然而在跨国长肥网络（Long Fat Network）与运营商严酷的国际出口 QoS 限制下，只要遭遇 5% 到 10% 的丢包，传统基于 Cubic 的拥塞控制便会触发严重的减窗惩罚与队头阻塞，导致千兆带宽断崖式暴跌至龟速。开发者 tobyxdd（Toby）早在 2015 年受 IBM Aspera 启发自研 UDP 传输协议 Dragonite，并在 2020 年正式开创了划时代的代理协议 Hysteria。他跳出传统 TCP 框架，基于针对不可靠网络深度定制的标准 QUIC，自研了独树一帜的 Brutal 拥塞控制算法——摒弃丢包减速的被动逻辑，通过精准测量与固定发包在恶劣弱网中强行跑满物理带宽。从初代 Hysteria 到推倒重构的 Hysteria 2、开源 Linux 内核模块 TCP Brutal，再到反向解构审查机制的 OpenGFW，tobyxdd 以纯粹的极客风骨推动中文代理技术走向 UDP 极速时代，成为现代翻墙生态无可替代的核心支柱。

协议与传输

2019 — 至今

NaïveProxy 创作者

“放弃修补脆弱的模拟指纹，直接以世界级浏览器底层网络栈让审查者面对整座 Chromium 巨构”

当防火长城对代理流量的识别从粗暴的关键字阻断全面升级为基于 TLS Client Hello 握手特征、JA3/JA4 指纹及机器学习主动探测的微观审查时代，绝大多数代理软件陷入了“修补一个特征、暴露一个新漏洞”的被动追逐战。开发者 klzgrad 在 2019 年给出了颠覆性的工程破局方案——NaïveProxy。klzgrad 彻底摒弃了在开源代理工具中以 Go 或 C++ 手工拼凑 TLS 握手的修补路线，而是开创性地直接将代理核心嵌入到 Google Chrome 的工业级底层网络栈 Chromium Cronet 中编译运行。这意味着 NaïveProxy 在密码套件协商、扩展字段排列、ALPN 顺序、HTTP/2 多路复用甚至连接重试与 Padding 填充机制上，与全球数十亿普通 Chrome 浏览器用户在二进制层面实现绝对一致。这种“寄生于主流互联网巨构”的极致拟态设计哲学，树立了现代抗审查技术的新标杆。
