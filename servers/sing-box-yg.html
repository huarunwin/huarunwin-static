项目简介

关于 Sing-box-yg

面向 Linux VPS 的 sing-box 多协议部署与管理脚本，提供本地订阅生成、Argo 隧道和证书配置。

公开 sb.sh、Serv00/Hostuno 专用脚本与 GPL-3.0 许可证，VPS 主程序从 SagerNet 获取 sing-box。可选 WARP/Psiphon 使用仓库提供的 sbwpph 二进制，仓库中未见其对应构建材料；主脚本源码与这些预编译附件分别判断。

版本自动检查仅同步 GitHub 发布或提交信息；上述源码、部署和许可说明保留资料核验时的证据，不代表已对新版本重新审计。

  • yonggekkk仓库所有者与脚本维护者 · GitHub 账号

能力范围

主要功能

  • VLESS Reality、VMess WS、Hysteria 2、TUIC v5 与 AnyTLS 配置
  • 节点、Clash/Mihomo 与 sing-box 订阅本地生成
  • Argo 临时及固定隧道
  • 证书切换与域名分流
