项目简介

关于 Hiddify Manager

组合 Xray 与 sing-box 的服务端部署和管理工具箱，提供用户管理、多域名配置及备份能力。

主仓库公开部署脚本、Xray / sing-box 配置与 Docker 材料；面板源码子模块 Hiddify-Panel 已重定向到 hiddifypanel，固定提交仍可访问。

版本自动检查仅同步 GitHub 发布或提交信息；上述源码、部署和许可说明保留资料核验时的证据，不代表已对新版本重新审计。

  • Hiddify项目团队 · GitHub 组织

能力范围

主要功能

  • Xray 与 sing-box 多内核管理
  • 用户时间和流量限制
  • 多域名配置与用户页面
  • 自动更新与定期备份
