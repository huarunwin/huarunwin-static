项目简介

关于 3m-ui

基于 Mihomo 的自托管服务端 Web 管理面板，用于管理监听入站、用户、订阅及多机节点。

v1.3.6 公开 Go 后端、React 前端、依赖锁文件及 Docker 构建材料。完整包和 Docker 镜像使用清单固定的 Mihomo v1.19.31，面板与内核版本分开；支持输出 sing-box 等订阅格式不表示使用对应内核。本次核对公开材料，未执行安装或部署实测。

版本自动检查仅同步 GitHub 发布或提交信息；上述源码、部署和许可说明保留资料核验时的证据，不代表已对新版本重新审计。

  • kazeyukiro主仓库维护者 · GitHub 账号

能力范围

主要功能

  • Mihomo Listener 与路由配置
  • 用户流量限额、到期管理与按节点计量
  • 多格式订阅与远程面板节点同步
  • SSL / ACME、备份恢复与运行状态管理

部署与运行信息

运行环境Linux（完整包 amd64 / arm64）
访问方式Web 管理界面（浏览器访问，不等于移动端代理客户端）
部署方式安装脚本 · Docker Compose · 发布包 · 源码部署
部署说明完整 Linux 安装包支持 amd64 / arm64，原生安装需要 root 及 systemd 或 OpenRC；其他架构仅提供独立面板，需自行配置兼容内核。首次登录须修改随机初始密码，对外访问应配置 HTTPS；默认 HTTP 端口不代表已启用 HTTPS。
