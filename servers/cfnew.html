项目简介

关于 cfnew

部署于 Cloudflare Workers 或 Pages 的 JavaScript 代理服务端，提供 Web 配置管理、多协议转发与多格式订阅生成。

v3.1 提供明文 JavaScript 源码与混淆版本，发布流程将明文文件打包为 Pages.zip 中的 _worker.js。转发代码使用 cloudflare:sockets；“Cloudflare Workers”是本站运行平台分类，不是独立代理内核。输出 Clash、sing-box 等配置不表示服务端运行对应内核。本次核对公开材料，未独立部署、安全审计或验证发布包与源码逐字节一致。项目图标为编辑制作的 CF 字母占位图。

版本自动检查仅同步 GitHub 发布或提交信息；上述源码、部署和许可说明保留资料核验时的证据，不代表已对新版本重新审计。

能力范围

主要功能

  • VLESS、Trojan 与 XHTTP 转发
  • KV 持久化配置与 Web 管理界面
  • 多客户端订阅生成与优选地址管理 API
  • SOCKS5、HTTP / HTTPS 出站代理配置
