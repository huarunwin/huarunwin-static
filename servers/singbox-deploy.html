项目简介

应用介绍

面向 Linux VPS 的 sing-box 多协议部署脚本，提供 sb 命令行管理菜单、节点链接生成，以及 VLESS Reality 入站转发到 Shadowsocks 落地机的中转配置。

主入口为 install-singbox-yyds.sh，仓库未发布正式 Release 或标签，按 main 提交快照跟踪；脚本快照与 sing-box 核心版本分别判断。核心通过 sing-box 官方安装器或 Alpine 软件包获取。图标采用仓库所有者的公开账号头像。

  • caigouzi121380仓库所有者与脚本维护者 · GitHub 账号

能力范围

主要功能

  • Shadowsocks、Hysteria 2、TUIC、VLESS Reality 与 AnyTLS Reality 自选部署
  • 随机生成密钥、密码与端口，支持自定义 Reality SNI 和连接 IP / DDNS
  • sb 菜单查看节点链接、重置端口与管理系统服务
  • 生成线路机安装脚本：VLESS Reality 入站转发至 Shadowsocks 落地节点
  • Alpine / OpenRC 与 Debian、Ubuntu、CentOS、RHEL、Fedora / systemd 安装分支

部署与运行信息

运行环境Linux
访问方式SSH / Bash 交互菜单（sb）
部署方式安装脚本
部署说明需要自行准备 Linux 服务器和 root 权限，安装会写入 /etc/sing-box 并管理系统服务。Hysteria 2 / TUIC 默认使用自签名证书，生成链接带 insecure=1；主脚本配置检查失败时仍继续执行。安装获取的 sing-box 核心未固定版本，部署前需核对兼容性。
