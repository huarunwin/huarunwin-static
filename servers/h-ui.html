项目简介

关于 H UI

面向 Hysteria 2 的 Web 管理面板，支持用户流量与设备数限制、订阅输出和配置管理。

v0.0.25 公开 Go 后端、Vue 前端和构建材料，面板从 apernet/hysteria 获取独立 Hysteria 2 程序。该正式版尚未包含 2026-08-07 对端口跳跃命令执行方式的安全修复，修复位于后续源码提交中；关联安全公告当前不可读，完整影响范围未核实。

版本自动检查仅同步 GitHub 发布或提交信息；上述源码、部署和许可说明保留资料核验时的证据，不代表已对新版本重新审计。

主要功能

  • 系统与 Hysteria 2 状态监控
