项目简介

关于 S-UI

基于 sing-box 的 Web 管理面板，集中配置入站、出站、路由和用户流量限额。

前端位于独立的 s-ui-frontend 子模块，稳定版固定其提交；主仓库公开后端及前后端 Docker 构建流程。

版本自动检查仅同步 GitHub 发布或提交信息；上述源码、部署和许可说明保留资料核验时的证据，不代表已对新版本重新审计。

  • alireza0主仓库维护者 · GitHub 账号

能力范围

主要功能

  • 多协议入站与路由配置
  • 用户流量与到期管理
