项目简介

应用介绍

面向个人、家庭与小型团队的自托管代理管理面板，集中管理多节点、用户配额和订阅，提供节点检测与签名更新。

发行版公开 Go 面板、节点 Agent、Web 前端及构建材料，采用 SQLite。服务端集成 Xray、Hysteria 2 与 AmneziaWG；Mihomo YAML 和 sing-box JSON 为订阅输出格式，协议支持范围依客户端而异。

  • MistGate官方项目组织 · GitHub 组织

能力范围

主要功能

  • 浏览器 SSH 安装节点与多节点集中管理
  • 用户与分组、流量配额、有效期、设备数与限速
  • 按客户端输出分享链接、Mihomo YAML、Xray JSON 与 sing-box JSON
  • Hysteria 2、Xray VLESS/REALITY 与 AmneziaWG
  • 客户端视角健康检查、节点诊断与 Telegram 告警
  • 签名更新、灰度发布与回滚
  • Web 管理界面、CLI、API 与 MCP
