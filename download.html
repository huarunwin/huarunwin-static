v0.7.0

2026-10-24
更新日志

- 内容来源统一支持自动、华润赢网站、GitHub 镜像、GH-Proxy 和 jsDelivr；GitHub 更新信息与文件下载按来源直连、代理或自动回退。
- 优先从网站独立版本页面读取已收录的版本与全平台附件，减少 GitHub 页面请求，并保留缺失资料时的回退和“载入更多版本”。
- Android 支持选择下载文件夹，原始 APK 下载完成并校验后自动保存副本；支持手动保存、取消和失败重试，已有文件保留原位置。
- 统一下载目录设置，支持查看、复制、修改、恢复默认和打开目录；Android 默认目录可在文件管理器中浏览，桌面默认使用系统下载目录下的 HuaRunWin Downloads。
- 精简设置首页，下载目录仅保留入口，默认平台筛选重置移至高级设置，Telegram 群组和频道移至帮助与反馈。
- 改进应用详情，平台名称增加分隔，预览图移到更新说明之前，移除预览图左右切换按钮，保留滑动浏览和放大。
- 导航统一使用“发现”，修复桌面中等宽度窗口底部页签缺失，保留发现、应用库、VPS、机场和设置入口。
