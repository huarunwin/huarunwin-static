pengchujin：Aerial 1.72–1.74 需手动安装新版，才能获得安装器回退

pengchujin 在 Aerial #1004 中说明，1.72 起应用内升级改用安装会话，部分电视接到会话却不弹确认页；1.75 已增加会话数秒无反应时转用系统安装器的退路。但升级运行的是当前已安装版本的代码，1.72–1.74 尚无这项退路，因此需先手动覆盖安装一次新版，之后才能在电视上直接升级。作者转述用户确认：重装 1.75 后，升级至 1.76 数秒后出现了安装界面。

作者原文@pengchujin

@cww-lgtm 原因找到了：1.72 起，应用内升级为了让装完就是编译好的（更流畅），从「打开系统安装器」改成了「安装会话」。海信这类电视接了会话却不弹确认页，所以下载完就没反应。1.75 加了退路：会话几秒没反应，就改用系统安装器。

但升级时跑的是电视上现在这个版本的代码，1.72–1.74 里还没有这个退路，所以从 1.74 升 1.76 依然会卡住。这一次需要手动装一下，之后就好了。@Saintlord77 已经确认过：重装 1.75 后，1.75 → 1.76 几秒后就弹出了安装界面。

手动装一次最新版（任选一种，覆盖安装，设置都保留）

1. 交给 Agent（最省事，Windows 也行）：把下面这段发给能在电脑上运行命令的 Agent（WorkBuddy、豆包电脑版、千问电脑版、Trae、Claude Code、Codex 等；手机上的聊天只会告诉你步骤，不会执行）：

请帮我把开源电视桌面 Aerial 升级到最新版（覆盖安装），并保持它是开机进入的桌面。
电视 IP：<电视IP>
保持 ADB 常开：要

安装说明在这里：https://aerial.qust.me/agent.md
（打不开时用 https://raw.githubusercontent.com/pengchujin/aerial-tv/main/site/agent.md ）

请先完整读完安装说明再动手，然后在我的电脑上亲自运行命令，不要只把步骤告诉我。需要我在电视上操作时提醒我。
最后按说明里的「验收」，把这几条命令的原始输出原样贴给我：
- adb shell "cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME"
- adb shell settings get secure enabled_accessibility_services
- 按主页键后的 adb shell "dumpsys window | grep mCurrentFocus"

2. 一行命令（macOS / Linux），把 IP 换成电视的：

curl -fsSL https://aerial.qust.me/install.sh | KEEP_ADB=1 TV=192.168.1.20 bash

3. 手动 adb：下载 aerial-standard.apk，然后：

adb connect 192.168.1.20:5555
adb install -r aerial-standard.apk
adb shell pm grant app.orchard.tv android.permission.WRITE_SECURE_SETTINGS
adb shell cmd notification allow_listener app.orchard.tv/app.orchard.tv.guard.RevivalListener
adb shell appops set app.orchard.tv SYSTEM_ALERT_WINDOW allow
adb shell am start -n app.orchard.tv/.MainActivity
adb shell cmd package compile -m speed -f app.orchard.tv

最后一条让 Aerial 更流畅：等 Aerial 显示出来、过 5 秒再运行，要几十秒。

只有无线调试、要配对码的电视（比如索尼 BRAVIA 的 Android 14），先按 README 第 1 步 配对，连上后运行一次 adb tcpip 5555 再用上面的命令；交给 Agent 的话它会引导这一步。

装好 1.75 或更新的版本后，以后就能在电视上直接「有新版本」→「下载并安装」了。
