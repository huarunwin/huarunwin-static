NextBox for Android v1.1.3 发布

已发布 v1.1.3，以下为官方变更日志。

官方变更日志@

新功能
• 删除重复节点：节点页「更多」里一键检查所有分组，连接参数完全一样、只是名字不同的节点只留一个；删除前列出保留和删除的节点，链式代理和策略组会自动改用保留的那个
• 更新订阅时，同一个订阅里的重复节点自动去掉
• 自定义主题色：除了预设颜色，还可以用取色板或 HEX 自选，最近用过的颜色会记住；颜色偏浅时提示并可一键加深
• 和 NextBox for Windows 2.2 的备份兼容：主题色、最近用过的颜色、服务目录的规则和规则页显示方式都会原样保留

修复
• 添加规则或选择节点时，轻微下拉弹出面板会来回抖动，有时停不下来

其他
• 代码清理和小优化

安装
• 一般手机下载 arm64-v8a；需要 Android 10 及以上
• 可以直接覆盖安装旧版本，节点和设置会保留

————————

New
• Remove duplicate nodes: "More" on the Nodes page checks all groups and keeps one of each set of nodes whose connection settings are the same and only the names differ; it lists what is kept and what goes first, and chain proxies and policy groups switch to the kept node
• Subscription updates leave out duplicates within the subscription
• Custom accent color: besides the presets, pick your own with a color panel or HEX; recent colors are remembered; a too light color is pointed out and can be darkened in one tap
• Backups compatible with NextBox for Windows 2.2: the accent color, recent colors, rules set from the service catalog and how the rules page looks are kept

Fixed
• Pulling the sheet slightly when adding a rule or picking nodes made it shake, sometimes without stopping

Other
• Code cleanup and small optimizations

Install
• Most phones need arm64-v8a; Android 10 or later
• Installs over older versions and keeps your nodes and settings
