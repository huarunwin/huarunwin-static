Maintainer review + fix-up before merge:

Changes pushed to this branch

  • Rebased onto main (a423904). Resolved conflicts:
  • scripts/build-adhoc.sh: kept main's current Ad Hoc profile UUIDs (6b66d5ed… / 52586a3b…) and added WIDGET_PROFILE.
