Leadaxe 说明 LxBox 手机到电视传输限制，不计划 Web UI 或云同步

Leadaxe 在 LxBox #163 中说明，v2.25.16 已提供手机向电视发送备份：电视在“备份与恢复 → 从手机接收”展示二维码，手机扫描后选择发送内容，电视以常规导入预览确认。两台设备须在同一局域网；内容使用二维码携带的一次性密钥加密，二维码有效 10 分钟且仅可传输一次。作者明确不计划提供 Web UI 或云同步；接收页和导入预览的遥控导航修复随下一版本提供。官方 v2.25.16 Release 另注明，该传输尚未在真实设备上核验。

作者原文@Leadaxe

Done in v2.25.16. On the TV: Backup & restore → Receive from phone shows a QR code. On the phone: Backup & restore → Send to TV, scan it, pick what to send. The TV shows the usual import preview, confirm with the remote. Same local network only; the content is encrypted with a one-time key from the QR, the code lives 10 minutes and is good for one transfer. No web UI and no cloud sync — not planned. Remote-control navigation fixes for the receive screen and the import preview land in the next release.
