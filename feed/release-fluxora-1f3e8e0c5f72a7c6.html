Fluxora v1.1.2 正式发布

Fluxora 1.1.2

🎨 界面与材质

  • 四种材质：经典、磨砂玻璃、液态玻璃、轻量，另有「曜石玻璃」主题
  • 液态玻璃支持实时光学折射，透镜强度和通透度分开调
  • 桌面侧栏在 208px 图文版和 68px 图标版之间切换，移动端用浮动导航
  • 首页组件可以增删和排序，连接按钮一直在原位
  • 节点卡片固定行高，长名字换行不再把状态行挤下去
  • 日志时间戳在窄屏不再溢出，浮动按钮不再挡住列表底部
  • 动效跟随系统的「减少动画」设置

🌈 主题取色

之前自选颜色只影响按钮和文字，背景、卡片、分隔线一直是固定深蓝，选什么颜色看起来都差不多。现在整块界面都会跟着变，品牌配色仍保留原来的样子。

Android 上换完壁纸回到 App，取色会重新读取，不用重启。Android 11 及以下没有这个能力，「系统」选项会置灰并说明原因。

🖼 品牌图标

八套图标，每套都有独立的深色和浅色版：官方默认、经典、水色、高级版、极速、天空、日落、蓝夜。在「设置 → 主题 → 应用图标」里切换，图标配色和页面主题分开设置。

Android 可以换桌面图标。桌面端会换应用内标记，系统安装图标跟着安装包走。通知栏、托盘、快捷磁贴统一用单色标记。

原来的标记是两条细线加一个小点，缩小后容易糊成一团。现在改成实心形状，深色和浅色分别配色，不再是简单反相。

🌐 代理与节点

  • 节点导出补齐 9 个协议：ssr、tuic、hysteria v1、anytls、snell、ssh、shadow-tls、wireguard、direct。trojan 不再丢 ws/grpc 传输，带 TLS 的 HTTP 代理不再导出成明文
  • 新增重复节点清理

🚀 性能

  • 优化桌面端启动和重启速度，冷启动 4047 → 647 ms（−84%，控制端口文件清理移入 await 链，不再叠加 3×1 s 探测超时，重启 4391 → 946 ms（−78.5%）
  • 延迟排序 O(n log n) → O(n)：300 节点 1404 → 73 ms，800 节点 10789 → 459 ms。节点多时"测速完不排序、点一下才排"随之消失。

🛠 修复

  • Android 退出后内核没有真正释放，端口和 TUN 一直被占着，其他代理工具起不来
  • 清除不可用节点时提示「已删除 N 个」，实际可能一个都没删，现在会报真实数量
  • 端口避让的提示每次启动都弹，改成开发者选项里的开关，默认关闭，避让本身照常生效
  • 批量测速时排在后面的节点会因排队超时，现在限制了并发槽位
  • Linux 上系统 DNS 在切换网络后失效，该功能会一直空转
  • WARP 诊断补上了响应超时，诊断结束会释放连接
  • 首页组件的添加和排序在部分情况下保存不下来

⚠️ 需要注意

  • macOS 安装包没有签名和公证，首次打开需要右键 →「打开」，或在系统设置里手动允许

⬆️ 升级

从 v1.1.1 直接覆盖安装即可，配置和订阅格式没有变化。

装好后建议到「设置 → 主题」看一眼材质和图标，这次外观改动比较大。
