Leadaxe：LxBox develop 修复探测会话竞态并调整 Direction 与 DNS 预览

Leadaxe 在 issue #171 更新进展：这些修改已进入 develop，作者称 0e5ce7cb 的 CI 通过，计划随下个版本发布，均未做真机验证。VPN 关闭时的“Test servers”现为每轮保留独立会话；Stop 会断开客户端以中断测量，关闭探测内核最多等 3 秒，旧一轮结束前显示“Stopping…”。“Register detour in auto group”开关已接入构建；组 DNS 的 JSON 预览采用与构建相同的成员筛选，并列出被剔除成员。空文件夹或未匹配规则导致自动节点丢弃、Auto 折叠使其不可达时会报告警告，自动节点池也沿用 Direction 池的门槛。过滤预览改从构建器计算，可在 VPN 关闭时使用。Direction 的通知、首页、编辑器与连接信息展示 label 并保留 tag；支持拖拽排序，拒绝破坏“只能引用上方 Direction”的移动。

作者原文@Leadaxe

Status update. The following items are fixed in develop (CI green on 0e5ce7cb) and ship with the next release. None of it has been verified on a device yet.

17 — fixed. (task 669) The symptoms match "Test servers" in a folder or subscription with the VPN down, not the mass ping with the tunnel up. Three defects in the probe session: Stop only set a flag and up to six in-flight measurements ran to their timeout; closing the probe core waited for every WireGuard node to tear down with no ceiling (10–17 s); and a run that was still winding down closed the session of the run you started after it, which is why the second Start did nothing. Now each run owns its session, Stop disconnects the client so in-flight measurements abort at once, the close is capped at 3 s, and the button shows "Stopping…" until the old run is actually gone.

8 — fixed. (task 670) "Register detour in auto group" has been a dead toggle for a long time: the builder recorded it and nothing read the result, so the auto group followed the first toggle alone. It works now, its caption names the Direction's auto group, and it is disabled while "Register detour servers" is off. A folder shows both toggles only when it actually has chain links, i.e. a member used as a detour by another member of the same folder. A folder whose nodes detour to WARP or to a node from a subscription has nothing to register, and that is almost certainly what you were looking at.

18 — fixed. (task 671) The JSON preview of a group DNS server (dns_shield and the like) now applies the same member filter as the build, and names the dropped members under the preview.

9 — partly. (task 675) Nothing in the code breaks the folder auto node unconditionally, but it could vanish silently: an empty folder or a Rule that matches nothing dropped the group without a warning, and folding the same folder as "Auto" made it unreachable, also without a warning. Both cases now report in the build warnings. The auto node's pool also went around the gates that Direction pools apply (chain links, Tailscale without an exit node); it uses the same gates now. If your case is something else, the details asked above still apply.

12 — fixed. (task 674) The filter preview is computed from the builder, not from the running core, so it works with the VPN off.

19 — fixed. (task 672) The tag stays immutable, as before. What changed: the notification, the home row of a nested Direction, the editor title and the Stats/Live chain and detour rows now show the label, with the tag next to it, instead of the bare tag.

21 — fixed. (task 673) Directions can be reordered on the Directions tab by drag. The rule "Other directions may name only directions above" stays, so a drop that would break an existing reference is refused: the rows you cannot drop onto are tinted while dragging, and a refused drop explains which direction includes which. The Debug API enforces the same rule and answers 409 with the conflicting pairs.
