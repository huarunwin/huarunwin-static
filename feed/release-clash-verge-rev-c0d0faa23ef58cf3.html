Clash Verge Rev v2.5.4 发布

已发布 v2.5.4，以下为官方变更日志。

官方变更日志@

v2.5.4

🐞 修复问题

  • 修复首页代理组和节点下拉菜单：再次点击无法收起或误选、小窗口显示不全、切换模式后意外展开
  • 修复系统代理切换失败后，开关状态显示错误的问题
  • 修复代理守卫失败后反复重试且没有提示的问题
  • 修复未开启系统代理时，启动仍提示代理错误的问题
  • 修复恢复备份后未按备份设置关闭系统代理的问题
  • 修复服务模式下操作超时后，后续操作报错或状态异常的问题
  • 修复部分节点显示「Unknown」或无法测试延迟的问题
  • 修复 PASS-RULE 节点被错误隐藏的问题
  • 修复重启内核后未恢复上次所选节点的问题
  • 修复部分代理组和首页图标无法显示、页面报错的问题
  • 修复同时修改端口、TUN 等设置时，部分修改丢失的问题
  • 修复 TUN 模式下 IPv6 Fake-IP 默认地址范围错误的问题
  • 修复切换节点时应用可能卡住的问题
  • 修复订阅文件被误删、删除或排序后列表异常的问题
  • 修复订阅自动更新失败无提示、重启后更新时间延后及状态误报的问题
  • 修复订阅编辑器因节点名称为空而崩溃、因格式错误而丢失内容的问题
  • 修复 DNS 编辑器空内容报错、初始值覆盖已有设置的问题
  • 修复关闭自动检查更新后，手动检查更新无效的问题
  • 修复应用冷启动或从轻量模式打开界面时, 系统代理被重复设置的问题

🖥️ Windows

  • 修复 Windows 管理员运行时，服务权限校验失败后无法继续使用代理的问题
  • 修复 Windows 便携版或 Scoop 安装后服务内核无法启动的问题
  • 修复 Windows 系统代理设置偶发失败的问题
  • 修复 Windows 关机被应用阻止的问题
  • 修复 Windows 服务模式下 TUN 使用 system/mixed 堆栈时无法接管流量的问题，防火墙放行规则改为自动添加
  • 修复 Windows 配置中 GEO 规则较多时，首次启动内核失败的问题

🍎 macOS

  • 修复 macOS 内核更新失败后无法启动的问题
  • 修复 macOS 需要管理员授权或开机自启时，系统代理设置失败的问题
  • 修复 macOS 切换显示器后托盘速率样式不同步的问题

🐧 Linux

  • 修复 Linux 安装或卸载服务时授权失败的问题
  • 修复 Fedora 等启用 SELinux 的系统更新后服务无法启动的问题

🍎/🐧 macOS/Linux

  • 修复 macOS/Linux 系统代理绕过规则未正确生效的问题
  • 修复 macOS/Linux 因旧版服务缓存权限异常而无法记住节点的问题

✨ 新增功能

  • 新增混合代理端口自动避让，被占用时临时使用其他端口
  • 新增系统代理和 TUN 权限引导，可直接安装服务并恢复原设置
  • 新增服务模式多用户隔离，支持旧版服务升级迁移
  • 新增手动取消节点固定功能
  • 新增代理组标题栏拖动调整，可交换组名和工具栏的位置
  • 新增前置规则与后置规则互相移动功能
  • 新增 DNS 覆写保护：订阅含自定义 DNS 时先确认，订阅更新后自动关闭覆写
  • 新增代理页排查提示，方便检查订阅和内核状态
  • 新增订阅更新频率提醒，间隔不足 24 小时时提示
  • 新增启动失败提示，显示原因并保存启动日志
  • 新增 TUN「Mips」堆栈选项，需配合 mihomo v1.19.31 及以上内核

🍎 macOS

  • 新增 macOS Liquid Glass 风格图标
  • 新增 macOS 多用户启动保护，避免多个实例冲突

🐧 Linux

  • 新增 Linux 系统主题跟随，自动切换深浅色外观

🚀 优化改进

  • 优化首页节点菜单关闭时的刷新性能
  • 优化 TUN 配置优先级：界面设置优先，其他选项仍可通过订阅、覆写和脚本调整
  • 优化 DNS 覆写：仅覆盖已填写的字段和已开启的开关，留空或关闭的项保留订阅设置
  • 优化系统代理失败后的恢复流程，保持系统设置和界面状态一致
  • 优化错误提示，支持复制完整原因，托盘和快捷键操作失败时也会提醒
  • 优化代理列表刷新、排序和页面切换速度
  • 优化首页节点操作，显示节点固定状态
  • 优化外部链接检查，仅允许打开 HTTP/HTTPS 网页
  • 优化更新说明排版，支持表格和提示框
  • 优化搜索框聚焦、界面字体和拖动排序动画
  • 优化后台连接和托盘刷新，降低资源占用
  • 优化解锁检测，支持同时检测多个项目并逐项显示结果
  • 优化日志记录，减少重复信息
  • 移除便携模式，统一使用系统应用数据目录
  • 优化繁体中文、俄语翻译及语言名称显示

🖥️ Windows

  • 优化 Windows 自动更新，跳过安装语言选择

🐧 Linux

  • 优化 Linux 系统代理设置，减少额外命令依赖，并明确提示缺少的命令
