Max Lv 在自己提交、并于 2026-09-29 02:22Z 关闭（未合并）的 madeye/BaoLianDeng PR #119「Drop unused FirebaseAnalytics to fix experiment-fetch crash」下留言：该崩溃已被判定为 Firebase 服务端的 sdk-exp 事故（firebase/firebase-ios-sdk#16728），不是 SDK 或应用本身的缺陷，因此不再按原计划移除未使用的 FirebaseAnalytics，改为保留 Analytics 并添加用量事件（usage events）。PR 正文此前把崩溃归因于 FirebaseApp.configure() 自动启动 Analytics 后，后台 A/B 实验拉取（APMETaskManager → GULMutableDictionary）触发「-[__NSDictionaryM setObject:forKeyedSubscript:]: key cannot be nil」；他随后于 02:26Z 提交 PR #120「Add Firebase Analytics usage events and Crashlytics context」（仍 open）。BaoLianDeng 是基于 meow-rs 内核的 macOS VPN 代理客户端，最新发布版 v5.5 为 2026-05-09，此更正未随任何正式版发出。
