Bettbox v1.19.9 发布

已发布 v1.19.9，以下为官方变更日志。

官方变更日志@
  • 新增节点库与落地节点管理，支持从剪贴板、二维码、本地文件、手动输入（URI / Base64 / YAML）导入单节点及一键注册 Cloudflare WARP 生成 WireGuard 节点；
  • 支持为落地节点指定前置代理（自动维护 dialer-proxy 并在切换前置时自动重测延迟）、自由选择注入的代理组、单配置注入或全局应用到托管模式，以及拖拽排序与连通性检测
  • 代理节点菜单新增「配置信息」，支持生成节点分享二维码、复制 URI 分享链接（支持 SS / SSR / VMess / VLESS / Trojan / Hysteria / Hysteria2 / TUIC / AnyTLS / Socks5 / HTTP / Mieru）、查看或编辑节点 YAML 配置及复制 YAML 片段
  • 新增应用内更新下载与覆盖安装（支持断点续传与 SHA-256 安全校验），可在应用设置中开启「自动下载更新」；
  • 仪表盘标题栏新增更新进度与 状态角标，支持 Android、Windows、macOS、Linux 四端应用内一键升级并在安装失败时自动恢复服务状态
  • 规则覆写新增「应用到全局托管模式」开关，支持在所有托管模式配置间共享自定义覆写规则（目标代理组不存在时自动回退至默认代理）
  • 托管模式下展开的 proxy-providers 新增 expanded.json 清单维护，保留外部资源页面展示、订阅流量信息同步、手动更新/上传及按 interval 周期后台自动更新
  • 优化内置托管脚本：移除远程在线同步并统一使用内置脚本与路由目录（保留自定义编辑与备份恢复）
  • 引入新的 Phosphor 图标包，安卓端默认开启
  • 优化移动端主页标签页切换，支持左右滑动切换与过渡快照缓存，并在系统内存压力下自动释放非活跃页面
  • 全局提示支持点击或右滑关闭；内核错误日志弹窗提示增加 10 秒同名去重防刷屏
  • 流量统计的进程排行支持点击跳转：Android 端直接打开对应应用的系统详情页，桌面端在文件管理器中定位程序文件
  • 通用设置中查找进程由开关新增按需开启，端口设置中新增外部控制端口自定义配置
  • 优化仪表盘启动按钮卡片与顶部启动开关的联动逻辑，首页启动时间小部件可选关闭
  • 完整移除应用侧默认 DNS 配置覆写与覆写规则集自动注入，完全遵循配置文件或托管脚本的 DNS 设置
  • 订阅下载遇到 TLS 握手失败时自动回退至内核下载
  • Android 最低支持版本下调至 Android 7.0，移除深色桌面图标切换开关并改用矢量自适应图标
  • 优化高刷新率激活时机、Android 17本地网络权限请求
  • Windows 安装包自动注册与清理内核进程防火墙入站放行规则
  • 优化应用冷启动性能：并行化配置加载、动态取色与校验计算，延后配置备份写入、Rust 库初始化与 Web UI 解压，桌面端偏好设置改为异步写入
  • 修复兼容模式恢复备份时产生重复订阅的问题，自动匹配相同订阅 URL 复用本地配置 ID 与名称，并保持同一备份内相同 URL 的独立订阅不被错误合并 by @iuuuuuuuu
  • 调整默认构建产物为精简版（Lite），原完整版改为通过 --standard 构建（带 -standard 后缀）
  • GitHub Actions 发布 Release 后自动触发 AUR 软件包更新 by @VillagerTom
  • 在各语言 README 文档中新增 Star History 趋势图 by @LancelotRar
  • 升级 Mihomo 内核与 Flutter 3.50.x 相关依赖及工具链等
