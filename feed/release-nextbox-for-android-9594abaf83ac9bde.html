NextBox for Android v1.1.0 发布

已发布 v1.1.0，以下为官方变更日志。

官方变更日志@

新功能
• 分流规则重做：一张「路由路径」图显示每个连接从上到下经过哪几步，改设置时路径跟着变；规则按直连、代理、屏蔽分页，添加时只选「加什么」和「去哪」：网站（常用服务一点即加，可一次粘贴多行域名）、应用（可搜索，也可手动输入包名）、IP
• 试一试：输入网址或选一个应用，看它在哪一步被接住、为什么
• 「活动」页点一条连接，可以直接把它的网站或应用加进规则
• 策略组：按地区、关键字或手动挑选一组节点，自动用最快的或手动选择，规则可以指向它
• 链式代理：2 到 8 个节点依次中转，拖动调整顺序；也可以长按节点选「经过其他节点连接…」
• 支持 NaiveProxy（HTTPS 和 QUIC），可以导入 naive+https:// 、naive+quic:// 链接
• 自动选择节点（可选，默认关闭）：当前节点连不上时换成能用的，一个都不通就不连接并说明原因
• 指定应用：可以「只代理选中的应用」或「排除选中的应用」，支持反选
• 节点可以拖动排序，或一键按延迟、名称、地区排列，更新订阅后保持顺序
• 备份和 NextBox for Windows 互通：两边导出的加密备份都能互相导入，导入前预览，可合并或全部替换
• 扫码或复制到订阅地址时添加为订阅；认识 clash:// 、sing-box:// 一键导入链接
• 打开 App 时自动连接（可选，默认关闭）
• 设置页重新排布；异常退出后可以复制错误信息反馈

修复
• Android 10–12（如 iQOO Neo5）点「指定应用」闪退
• 连着 VPN 时，服务器地址和 TLS 名称不一致的节点（Reality、CDN 中转等）测速超时
• 删除单个节点前没有确认

说明
• 「应用」规则和 NaiveProxy 节点，Windows 版暂时还不认识
• 加入 NaiveProxy 后安装包大约大了 4 MB

安装
• 一般手机下载 arm64-v8a；需要 Android 10 及以上
• 可以直接覆盖安装旧版本，节点和设置会保留

————————

New
• Routing rules redone: a route path shows the steps every connection passes from top to bottom and follows your settings; rules are split into direct, proxy and block pages, and adding one only asks what and where: websites (common services in one tap, many domains pasted at once), apps (searchable, or a package name typed by hand) or IPs
• Try it: type a website or pick an app to see which step catches it, and why
• Tap a connection on the Activity page to add its website or app to the rules
• Policy groups: nodes picked by region, keyword or by hand, the fastest used automatically or chosen by hand; rules can send traffic to them
• Chain proxies: 2 to 8 nodes in a row, drag to reorder, or long-press a node and pick "Connect through other nodes…"
• NaiveProxy (HTTPS and QUIC), including naive+https:// and naive+quic:// links
• Automatic node selection (optional, off by default): switches to a working node when the selected one does not answer; if none works it does not connect and says why
• Selected apps: proxy only the selected apps or exclude them; invert selection
• Drag nodes to reorder them, or sort by latency, name or region in one tap; the order survives subscription updates
• Backups are interchangeable with NextBox for Windows: either side imports the other's encrypted backups, with a preview and a choice to add or replace
• A scanned or copied subscription address is added as a subscription; clash:// and sing-box:// one-click links work
• Connect when the app opens (optional, off by default)
• Settings rearranged; after a crash the error details can be copied for a report

Fixed
• Crash when opening "Selected apps" on Android 10–12 (e.g. iQOO Neo5)
• While connected, latency tests timed out for nodes whose server address differs from their TLS name (Reality, CDN fronting)
• Deleting a single node did not ask first

Notes
• NextBox for Windows does not know "app" rules and NaiveProxy nodes yet
• NaiveProxy makes the APK about 4 MB larger

Install
• Most phones need arm64-v8a; Android 10 or later
• Installs over older versions and keeps your nodes and settings
