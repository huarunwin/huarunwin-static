应用介绍

订阅聚合、筛选与格式转换。汇集、整理和转换多个订阅，可按目标客户端导出格式；提供 Node.js 后端和代理客户端脚本运行方式。

Sub-Store 处理用户已有订阅，本身不提供代理节点或建立代理连接。官方 README 提醒 sub.store 域名并非项目所有；使用脚本重写或网页前端时应核对实际请求目标，避免将订阅数据误送到第三方。

运行方式：Node.js、客户端脚本。许可证：AGPL-3.0。
